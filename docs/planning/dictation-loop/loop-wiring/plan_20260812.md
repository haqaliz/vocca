## Task 1 — Core-owned pipeline decision (RED first)

- **New file**: `Sources/VoccaCore/DictationPipeline.swift` — the pure decision + async
  coordinator over the seams (all Core protocols): given
  `SessionEffect.ended(SessionOutcome)`, an `any ASREngine`, `any TextInjector`, `any
  TranscriptHolder` and a `MonotonicClock`, produce a `PipelineSurface`
  (`.idle` | `.transcriptHeld(HeldTranscript)` | `.reasonOnly(FailsafeReason)`):
  - `.cancelled` content → `.idle`, no transcribe, no inject.
  - `.completed` with empty text (`audio.samples.isEmpty` after transcription yields
    `text == ""`) → `.idle`, no injector call.
  - otherwise → `transcribe` (throws → `.reasonOnly(.transcriptionFailed)`),
    `inject` (`.widgetFailsafe` → holder already holds; surface `.transcriptHeld`),
    other rungs → `.idle`.
- **Tests (written first)**: `Tests/HarnessTests/DictationPipelineTests.swift` — decision
  table over every `Content` shape (completed/cancelled, empty/non-empty), transcribe
  throw, injector returning every rung, holder integrity (hold called exactly once on
  failsafe, never on success); uses `RecordingSource`-style doubles, `StubEngine`
  (`ASRTestDoubles.swift:48-97`) and a ledger `TextInjector` fake.
- **Validation**: focused green; full suite green.
- **Commit**: `Route ended sessions through a Core pipeline: cancel discards, empty skips, text injects`

## Environment & privacy

- No env vars. Zero-network invariant: the composed-loop tests never call network; the

- Models download only via the shipped manifest + `ModelStore` (Application Support).

## Edge cases & error handling

- Unprepared engine → `.modelUnavailable` notice; **the mic never opens** (readiness
  gate is above the machine).
- Cancelled session (Esc) → discard; the in-flight transcribe is cancelled, never
  injected.
- Empty text → no injector call (no paste of `""`).
- Ladder exhausts → `.widgetFailsafe` (journaled before `hold` returns).
- Transcribe throws → `.transcriptionFailed` notice; nothing held, nothing lost.
- Tap `.unavailable` (no grant) → logged, loop idle; recovery via grant notification is
  the TapHealthTimer's existing domain (not this plan).
- `AVAudioEngine.start()` failing → `CaptureStart.unavailable` → the machine's existing
  handling (session ends with the machine's reason; the widget never claims RECORDING).
