## Testing strategy

- Unit: projection mapping, reducer table (injected clock), waveform mapping, level
  conformance — headless, zero network.
- CI contract for views: compile + lints (window-server precedent — the smoke checklist
  is their first execution).
- Manual: `smoke-checklist` first-execution entry (waveform moves with voice).

## Environment & privacy

- No env vars; nothing leaves the machine. Reduce Motion read from
  `NSWorkspace.shared` at view build time (injected flag for tests).

## Edge cases & error handling

- OPENING must not show a waveform (no audio yet — `PRODUCT_SPEC.md:33-38`); the
  projection enforces it.
- RECORDING only from the machine's recording signal — a waveform over a dead mic is
  the spec's named lie (`:88`).
- DELIVERED → IDLE collapse must not drop a concurrently-presented FAILSAFE (the
  reducer's transition table handles the interleave; test it).
- Level source idle → silent bars, never a canned animation.
