## Design decisions (made here, justified, recorded)

**D1 — The C12 wiring lives in a new `ContextWiring.swift` recipe file, not inside `configure`.**
The `ConverseWiring.swift` precedent exactly: an `extension AppBootstrap` recipe
(`composeContextWiring`) + the composition's own file-local types, and `configure`'s change is
the recipe call + the root slots, reviewable in one screen. Justification: (a) the G5 pin — the
`AppBootstrap.swift` diff stays additive and small; (b) the probe contract — the recipe is
probe-safe by construction: the consent store's read is FileManager-only (an absent store is a
silent empty), the provider is constructed, never read from by the probe path (the composed
default is `NullContext`, which reads nothing); (c) testability — the recipe is constructible
over fakes from `HarnessTests` and from the probe (the `SpeechDrive` precedent).

**D2 — Provider resolution is a root slot, consent-gated, per turn.** The composition assigns
the root a context-resolution slot (the `converseDriver` shape: a `?`-typed slot assigned after
construction, `:524-540`). Its call surface, per turn and for the focused app: read consent for
the focused bundle ID first — declined ⇒ empty snapshot, provider never invoked; Secure Input ⇒
empty snapshot; consented ⇒ the provider's snapshot. Nothing on the dictation path calls the
slot — C12's consumers are the tests, the indicator fold, the BYOK grant field (via
`byok-context-grant`) and C13 later. The "loop never depends on context" claim is structural
(the pinned files name no context type) and asserted (a throwing stub provider leaves a composed
dictation cycle byte-complete).

**D3 — The indicator fold rides the composition, not the reducer.** The wiring folds the badge
value into the widget store through the widget-indicator aspect's shipped fold surface, the
egress-fold shape (`AppBootstrap.swift:557-569`): resolved at wiring time and re-folded when the
focused app's consent state changes (the kill switch and consent edits both re-fold). The badge
state, its copy and its fold cases are `widget-indicator`'s — this aspect delivers the fold
*call*, never a reducer edit. The probe's default folds the safe direction (no consents ⇒
unlit) so the interposer run is byte-for-byte correct before any task lands.

**D4 — Kill-switch routing is a root surface with mid-turn semantics (M9).** The menu-bar row
and the Settings control call a root method the composition wires; throwing it: (a) marks the
composition revoked — the resolver answers empty from then on and the provider is not called
again, (b) discards the in-flight snapshot (context is never persisted, so the discard is
total — `prd.md:117-118`), (c) clears the indicator fold in the same call. The surface's
*semantics* are asserted here; the row/copy are `widget-indicator`'s. Kill switch ≠ blanket
allow: it is a revoke, never an invitation to grant.

**D5 — Resolution failure degrades to the empty snapshot, never breaks the loop.** The resolver
is best-effort with the adapter's own timeout discipline (the AX timed-call precedent, `prd.md:150-151`);
a provider throw answers the empty snapshot (the `NullContext`-style honesty, R1) and the
composition records nothing — no transcript text, no selection text, no timestamps (M10). The
dictation cycle is unaffected by construction: it never calls the slot.

**D6 — PROBE-CONTEXT drives the composed default under the interposer (M11).** A new drive
`exerciseContext()` composes the wiring recipe over the shipped defaults — `NullContext` (or the
shipped `AccessibilityContext` constructed, never read, per the module-witness rule below), the
real consent store over a **temporary directory**, the root — reports deterministically
(`provider=null reads=0 consentStore=absent indicator=unlit`-shaped), and mints the module
witness **by the call**. The zero-network suite asserts the verbatim post-condition + a
guard-the-guard, and the placeholder list's `VoccaBootstrap.self`-shaped entry is replaced by
the drive's minted witness per the `SpeechDrive` precedent. **Module-coverage note:** with
`VoccaContext` in the manifest (added by `accessibility-context`), the cross-check demands its
witness; the drive mints it via the composed default's type when the seam aspect placed
`NullContext` there, else by constructing the adapter (construction-only, never a read) —
decision taken from the landed sibling, recorded, never improvised.

**D7 — The G5 re-anchor is a dedicated commit immediately after the wiring commit.** The D8
contract of the C11 wiring, applied to C12 (R4): the rationale is written here before any edit,
the wiring is the **one** `AppBootstrap` commit of the aspect, the re-anchor commit recomputes
the digest from the tree and edits only the pin's third row, and the two commits are reviewed as
one PR. The wiring commit's red pin is the pin **working** (its own words, `:341-344`).
