## Phases

### Phase 1 — The pipeline streaming route and the permanent guard (S1, S2)

- **Goal:** the seam's `stream(_:)` gains a real consumer; partials can reach a widget-only
  sink; the guard "zero injection before the final" is pinned by test across the closed
  route set.
- **RED first:** write `Tests/HarnessTests/DictationPipelineStreamingTests.swift` (new file,
  license header) driving new `VoccaCore` surface:
  1. A `PartialTranscriptSink` protocol (new, in `VoccaCore`):
     `func presentPartial(_ partial: String)` — widget-only by construction (the pipeline
     holds it only to emit; the composition root wires it to the widget store).
  2. `DictationPipeline` gains `routeStreaming(chunks:target:sessionID:)` — public, mirroring
     `route`'s contract: consumes `engine.stream(chunks)` **unconditionally** (the batch
     default makes degradation structural — no branch on `supportsStreaming` anywhere in the
     pipeline), emits each `isFinal == false` transcript's text to the sink, and routes the
     one `isFinal == true` transcript through the existing cleanup → inject decision table
     (same cancellation re-checks, empty-text guard, failsafe routing, span + finalize rows).
     The pipeline gains optional `partialSink:` in `init` (nil default = byte-for-byte
     today; a B2-style test pins the nil-sink batch route is unchanged).
  3. Tests, all with an injector double:
     - **The guard (load-bearing):** a streaming stub (yields partials then one final) —
       zero injector calls before the final; exactly one injector call with the final text.
     - Batch stub through the same route: zero partials, zero sink touches, one final,
       identical outcome to the batch route.
     - Cancellation before the final: `.aborted`, nothing injected, no sink touch after
       cancellation.
     - Empty final: `.emptySkip` (no injector call).
     - Throwing stream: `.reasonOnly(.transcriptionFailed)`, sink untouched.
     - Post-cleanup cancellation: finalizes `.aborted`, injects nothing.
  4. A no-branch pin test (the `EngineSwapTests` pattern): the streaming test source contains
     no `supportsStreaming` reference — the degradation is the seam's default, not a caller
     branch.
- **Files:** create `Sources/VoccaCore/PartialTranscriptSink.swift` (stdlib-only),
  extend `Sources/VoccaCore/DictationPipeline.swift`, create
  `Tests/HarnessTests/DictationPipelineStreamingTests.swift`, extend `ASRTestDoubles.swift`
  with a streaming stub (partials then final) + a `ProbeEngine`-style counting injector
  double if none exists.
- **Validation:** `swift test --filter DictationPipelineStreamingTests`, then the full floor
  script. The suite must stay green with a nil sink (byte-for-byte today).
- **Commit:** `Route streaming partials to a widget-only sink with the zero-injection guard`

### Phase 2 — Widget partial state (S3)

- **Goal:** the widget can show provisional text — bounded, reduce-motion-safe, and only

- **RED first:** extend `Tests/HarnessTests/WidgetStateReducerTests.swift`:
  1. `WidgetReducerState.partialText: String?` + `WidgetAction.partial(String)` — the closed

     fail to compile before the reducer handles the new case).
  2. The fold: `.partial(text)` sets `partialText` (bounded — cap at a named
     `WidgetTiming.maxPartialCharacters`-style constant, e.g. 200 chars, truncation is the

  3. Reduce Motion: the reducer stores the text regardless; the *view* renders static under
     reduce motion (view-side, existing pattern — the reducer test pins that the state
     carries the text so the view can choose).
  4. A test asserting partials never survive into DELIVERED (the injected final is the only
     text that matters there).

## Edge cases

- Cancellation anywhere in the stream (before final, during cleanup, after final) — every
  row of the closed set finalizes a record and injects nothing.
- Truncation of a long partial is the reducer's answer (bounded state); the pipeline emits
  full partials.
- Batch engines: the seam's default yields one final — the sink is never touched.
- The widget must never imply finality: partial text is provisional by construction
  (`isFinal == false`), and nothing in DELIVERED carries it.
