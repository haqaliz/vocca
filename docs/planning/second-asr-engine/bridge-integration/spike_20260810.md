**Verdict:** the macOS slice is a true universal binary — **both** arm64 (Apple Silicon) and
x86_64 (Intel) are present and `SupportedPlatform = "macos"`. No missing-arch flag; the
Intel-Mac break the plan feared would need a decision is a non-event for this artifact.

## 3. Module facts the binary target depends on

- The framework's module map declares **`framework module whisper`** — `import whisper`
  resolves; headers exposed: `whisper.h`, `parakeet.h`, `ggml.h`, `ggml-alloc.h`,
  `ggml-backend.h`, `ggml-metal.h`, `ggml-cpu.h`, `ggml-blas.h`, `gguf.h`.
- The module `link`s `c++`, `Accelerate`, `Metal`, and `Foundation` — the C-ABI spike
  test needs nothing beyond `import whisper`.

## 4. The exact `.binaryTarget` declaration to pin

No `.package` entry is needed — a remote binary target resolves without one (SwiftPM
fetches the zip directly; the plan's "`.package` entry for whisper.cpp (binary only)"
is not required by the manifest grammar, and adding one would mis-declare a source
repository we do not consume). The pin goes inside `targets:`:

```swift
.binaryTarget(
    name: "WhisperCpp",
    url: "https://github.com/ggml-org/whisper.cpp/releases/download/v1.9.2/whisper-v1.9.2-xcframework.zip",
    checksum: "af74fed13ea7f2d5ca2a39d9f58ec177713fafd7cab63aef4e27b79f3ceca80b"
),
```

`"WhisperCpp"` is added to `VoccaASR`'s `dependencies`.

## 5. Notes and non-events

- The checksum was computed from the downloaded artifact (`shasum -a 256`), not copied
  from any doc — the plan's anti-pattern, avoided.
- Metal: the artifact embeds Metal shaders at build time (`GGML_METAL_EMBED_LIBRARY` per
  the PRD); a hosted runner with no GPU still links and runs on CPU. Untested here (no
  hosted runner) — recorded, not claimed.
- dSYMs ship in the zip for every slice; they are part of the artifact's checksum, which
  the pin covers.
