## 2. Implementation phases

### Phase 1: Pin the artifact (spike-first — the riskiest unknown)

- **Goal:** obtain `whisper-v1.9.2-xcframework.zip` from
  `https://github.com/ggml-org/whisper.cpp/releases/tag/v1.9.2`, verify it, and compute
  its SHA-256. Verify the macOS slices (must include arm64 + x86_64 — inspect via
  `lipo -info` / `unzip -l` before pinning).
- **Prerequisites:** none.
- **Files to create/modify:** none yet (spike artifact only; the checksum feeds
  Phase 2).
- **Validation:** `shasum -a 256 <zip>` matches what the implementation pins;
  `lipo -archs` shows arm64 + x86_64 macOS slices. Record the artifact size and checksum
  in `docs/planning/second-asr-engine/bridge-integration/spike_20260810.md`.
- **Commit message:** `Record the whisper.cpp xcframework spike: artifact, slices, checksum`

## 4. Testing strategy

- `WhisperCSpikeTests` is the only new test; it must run in CI headless (module
  import + constants + params struct — no GPU, no model).
- Full suite stays green at each commit (any warning fails).
- The `PackageManifest.swift` guard may need updating if it enumerates dependencies —
  check and extend if so.

## 5. Environment & privacy

- The XCFramework is fetched by SPM at resolution time (a build-time fetch, not an
  app runtime call — the zero-network invariant concerns the shipped app's runtime;
  the C6 interposer test drives the probe binary, which does not resolve packages).
- No env vars, no secrets. The checksum is committed.

## 6. Edge cases & error handling

- Checksum mismatch at pin time → stop: never guess a checksum; re-download and
  re-verify from the release asset.
- Hosted-runner build failure of the binary target → record in the spike doc and
  surface at the checkpoint; do not silently switch to a different integration path.
- x86_64 slice missing → flag at the checkpoint (arm64-only would break Intel Macs —
  acceptable for P0 if recorded, but must be a decision, not an accident).

## 7. Agent execution notes

  computes it.
- If the release asset URL pattern differs from the research (e.g. tag renamed),
