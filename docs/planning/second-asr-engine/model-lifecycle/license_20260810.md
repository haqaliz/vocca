## What was checked (live, 2026-08-11)

1. **The HF repository's license field** — https://huggingface.co/ggerganov/whisper.cpp
   - Finding: the repo's metadata declares **`License: mit`**.
   - The model card describes the contents: *"OpenAI's Whisper models converted to ggml
     format for use with whisper.cpp"* — i.e. this repo is the conversion/redistribution
     channel for OpenAI's Whisper weights in ggml form, not an independent model.
2. **whisper.cpp's LICENSE, fetched from the primary source** —
   https://raw.githubusercontent.com/ggml-org/whisper.cpp/master/LICENSE

3. **ggml's LICENSE** — upstream https://github.com/ggml-org/ggml (already recorded in
   `THIRD_PARTY_NOTICES.md` as MIT by an earlier wave; this record did not re-fetch it —

## OPEN item — the converted weights' own license provenance (founder's judgment)

The HF repo's `License: mit` field is the distributor's declaration about the files it
hosts, and the upstream whisper.cpp repo treats the conversion pipeline as MIT. The
underlying OpenAI Whisper model weights are widely known to be MIT-licensed per OpenAI's
original release — **not re-verified live by this record** — which is the usual basis on
which the conversion can be MIT-redistributed at all. The question this record leaves
open for the founder:

- Does the HF repo's `License: mit` field settle the weights' license for Vocca's
  purposes, or does the founder want an additional primary-source check against
  OpenAI's Whisper repository (https://github.com/openai/whisper, MIT) recorded before
  sign-off?
