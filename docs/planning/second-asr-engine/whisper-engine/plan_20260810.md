## 1. Project setup checklist

- Package.swift dependency on the whisper binary target must exist (`bridge-integration`
  Phase 2). Verify before starting: `import whisper` compiles in a scratch test.
- C API facts the plan assumes (verified in the research): `WHISPER_SAMPLE_RATE 16000`;
  `whisper_init_from_file_with_params(path, cparams)`; `whisper_full(ctx, params,
  samples, n)`; `whisper_full_n_segments` / `whisper_full_get_segment_text`;
  `whisper_free`; `whisper_full_default_params(WHISPER_SAMPLING_GREEDY)`; params:
  `n_threads`, `language`, `no_timestamps`, `single_segment`. No callbacks needed for
  batch.
- Swift 6 shape: the actor owns the `OpaquePointer`; C pointers confined to the
  actor's isolation domain; no `@unchecked Sendable` anywhere.

## 2. Implementation phases

### Phase 1: Headless decision files (RED first — no C API needed)

- **Goal:** the pure, testable core: identity, load state, transcript mapping,
  parameters — all built and tested against abstract inputs.
- **Prerequisites:** `bridge-integration` merged (not strictly required for this
  phase, but land it first anyway — the seam lint needs the module).
- **Files:**
  - `Sources/VoccaASR/Whisper/WhisperCppEngineIdentity.swift` —
    `enum WhisperCppEngineIdentity { static let whisper = EngineIdentity(id:
    "whisper-large-v3-turbo", displayName: "Whisper turbo", isLocal: true) }` (id
    exactly as shipped in `EngineIdentity.swift:28`'s doc).
  - `Sources/VoccaASR/Whisper/WhisperCppParameters.swift` — value type: threads
    (default `min(8, cpuCount - 2)`), language (nil = auto), tier
    (`whisper-turbo` / `whisper-turbo-q5_0`), mapped to C params in the bridge.
  - `Sources/VoccaASR/Whisper/WhisperTranscriptMapper.swift` — pure mapping from
    `[WhisperSegment]` (headless value: text, start/end seconds, token log-prob
    optional) to `Transcript` + `[TranscriptSegment]`; decides confidence (nil or
    derived), audioDuration from the buffer, `missingSampleCount` passthrough.
  - `Sources/VoccaASR/Whisper/WhisperLoadState.swift` — load-state decisions
    (unloaded/prepared/failed) mirroring `ParakeetLoadState`.
  - `Tests/HarnessTests/WhisperCoreTests.swift` — **RED first**: mapper cases
    (empty segments → empty transcript; ranges; confidence policy), identity
    constancy, load-state transitions.
- **Validation:** targeted `swift test --filter WhisperCoreTests`; full suite green.
- **Commit message:** `Add the headless whisper core: identity, load state, transcript mapper, parameters`

- **Files:**

    `Tests/HarnessTests/SwiftSourceScanner.swift`.
  - `Tests/HarnessTests/WhisperSeamTests` also asserts `VoccaASR`'s module boundary
    still holds (imports only `VoccaCore`).
- **Validation:** the lint passes; `swift build` is clean (the bridge compiles).
- **Commit message:** `Confine the whisper C ABI to one file, in the two-sided seam form`

### Phase 3: The engine actor (RED → GREEN)

- **Goal:** `WhisperCppEngine` conforms to `ASREngine`: identity, `supportsStreaming =
  false`, `prepare()` (store-driven load-once), `transcribe` with empty-buffer early
  return and attributable errors.
- **Prerequisites:** Phases 1–2.
- **Files:**
  - `Sources/VoccaASR/Whisper/WhisperCppEngine.swift` — `public actor
    WhisperCppEngine: ASREngine`; init takes `store: ModelStore`, `manifest:
    ModelManifest`, `transport: any ModelTransport`, `clock: MonotonicClock`,
    `parameters: WhisperCppParameters`. `prepare()`: `try await
    store.downloadIfMissing(manifest:transport:)` then bridge context creation
    (model path = version dir + manifest file name); load-once idempotent.
    `transcribe`: empty-buffer early return (valid empty Transcript); else bridge
    `whisper_full` + mapper; errors map to `VoccaError.transcriptionFailed(identity,
    underlying:)`; missing model → `modelUnavailable(identity, reason:)` — the
    ParakeetEngine error-shape.
  - `Tests/HarnessTests/WhisperEngineTests.swift` — **RED first**, mirrors
    `ASREngineSeamTests` + `ParakeetCoreTests`: attribution (every transcript
    `engine == identity`), empty-buffer policy, prepare idempotence, error mapping
    (store failure → `modelUnavailable`; bridge failure → `transcriptionFailed`),
    offline (transport stub never called when model present; never called during
    `transcribe`).
- **Validation:** full suite green, any-warning-fails clean; targeted filter runs.
- **Commit message:** `Add WhisperCppEngine: the second ASREngine implementation`

## 3. File-by-file build order

`WhisperCppEngineIdentity` → `WhisperCppParameters` → `WhisperTranscriptMapper` →
`WhisperLoadState` → tests (Phase 1) → `WhisperCAPI.swift` + seam lint (Phase 2) →
`WhisperCppEngine.swift` + engine tests (Phase 3) → ARCHITECTURE.md (Phase 4).

## 4. Testing strategy

- Unit: `WhisperCoreTests`, `WhisperEngineTests` (stub store/transport/clock — the
  `ModelTransportTestDoubles` / `ASRTestDoubles` patterns).
- Lint: `WhisperSeamTests` (family confinement, module boundary).
- Real-engine runs are NOT in this aspect (fixture-harness owns them, env-gated).
- Suite command: `Scripts/test-with-floor.sh` after each phase.

## 5. Environment & privacy

- No network in any test; the engine's only transport contact is the injected store
  (and none during `transcribe`).
- `isLocal = true` — no egress badge anywhere.

## 6. Edge cases & error handling

- Empty buffer → valid empty transcript (pinned by the seam's policy).
- Model absent → `modelUnavailable` with a clear reason (mirror Parakeet).
- `prepare` called twice → idempotent (second call no-ops).
- Bridge context creation failure (corrupt model file) → `transcriptionFailed` with
  underlying error intact; the actor stays usable (next `prepare` retries).
- Whisper's C API is single-threaded per context: the actor serializes all access.
