# Aspect spec — `fixture-suite`

Parent PRD: [`../prd.md`](../prd.md) · Capability C2 · Phase P0
Depends on: `asr-seam`, `model-downloader`, `parakeet-engine` (all committed)

---

## Problem slice

The C2 acceptance names a fixture suite with WER tolerances and the network down
(`CAPABILITY_ROADMAP.md:60`), and nothing that computes a WER exists. This aspect ships the
measurement: the scorer, the harness, the fixtures, and the honest boundary of what CI can
run — with the F1 spike's verdict still **pending**, the real-engine numbers are
env-gated, and the seam-level claims run everywhere.

**User outcome:** the number the P0 gate is judged on becomes measurable: "this engine
transcribes these fixtures within this tolerance, offline" — reproducible on any machine
with a model, and provably correct at the seam level on every CI run.

**The honesty line (stated, not hidden):** a WER run against the real Parakeet engine needs
the model; the model's CI availability is the pending F1 verdict. So the suite is built in
two halves: the scorer and harness are pure and run everywhere; the real-engine run is
`VOCCA_MODEL_DIR`-gated and skips visibly (XCTSkip, not silence) without a model. The
fixtures themselves are TTS stand-ins until the founder's recordings land (F2).

## In scope

- **Five fixtures + goldens** in `Tests/Fixtures/` (TTS stand-ins, deterministic, labeled in
  `FIXTURES.md`; the founder's recordings replace them under F2): `clean.wav` (~10 s, the
  existing spike clip), `accented.wav` (~10 s, a different voice — the stand-in for the
  founder's accent register), `noisy.wav` (~10 s, clean + deterministic synthetic noise,
  fixed SNR, generated once and checked in), `sixty-second.wav` (60 s), `two-hundred-ms.wav`
  (a single word). Each with a `.txt` golden.
- **`WER` scorer** (pure, in `Tests/HarnessTests/`): word-level, normalized (lowercase,
  punctuation-stripped), Levenshtein over words, empty-reference rule; table-tested against
  every edit class.
- **`ASRFixtureSuite` harness** (in `Tests/HarnessTests/`): discovers fixtures under
  `Tests/Fixtures/`, loads 16 kHz mono wavs into `AudioBuffer`s, runs a given `ASREngine`,
  computes per-fixture WER, returns results. Parameterized tests run it over the stub
  engines — including an *imperfect* stub whose WER is asserted to match the computed
  expectation, so the plumbing is proven end-to-end without a model.
- **`ParakeetEngineWERTests`** — env-gated (`VOCCA_MODEL_DIR` = a store-shaped version
  directory): builds the real engine (store rooted at the model's parent, the shipped
  manifest), runs the five fixtures with the provisional tolerances (clean ≤ 10%,
  accented ≤ 12%, noisy ≤ 20%, 60 s ≤ 10%, 200 ms ≤ 1 substitution), asserts
  `ModelHub.offlineMode == true` after engine init, and asserts `Transcript.engine ==
  ParakeetEngineIdentity.parakeet` on every result (the identity clause). Skips with a
  naming message when the env var is absent.
- **`Scripts/provision-asr-fixtures.sh`** — generates a Vocca-shaped model install from an
  existing model directory (copies the SDK-required files under
  `<root>/<engineID>/<version>/<sdkDirectory>/`, writes the verified marker, computes the
  SHA-256 manifest, writes it to `Sources/VoccaASR/Models/Manifests/`), and prints the
  `VOCCA_MODEL_DIR` value for the env-gated test. This is what makes SMOKE step 17 and the
  CI cache step automatable.
- **Docs:** `FIXTURES.md` (provenance, tolerances, the stand-in labeling), the CI model-cache
  step's two documented paths (GO → cache in ci.yml; NO-GO → the env-gated test skips and
  the founder runs it) — the wiring itself lands with the spike verdict.

## Acceptance criteria (tests written first)

1. **WER scorer**: exact match → 0; each edit class (substitution, insertion, deletion)
   → its exact value; case and punctuation do not count; empty reference → 0 iff the
   hypothesis is empty, else 1.
2. **Harness plumbing**: the imperfect stub's per-fixture WER equals the computed
   expectation, over all five fixtures, through the real loader (wav → `AudioBuffer` →
   engine → `Transcript` → scorer).
3. **Parameterization**: the same test body runs over two stub identities and attributes
   each transcript to the right engine (the C3 swap shape).
4. **Env-gating**: without `VOCCA_MODEL_DIR` the real-engine test skips with a message
   naming the variable; with it, the five fixtures meet the provisional tolerances, the
   offline flag reads true, and every transcript carries the Parakeet identity.
5. **Provisioning**: the script, run against a directory of known bytes, produces the
   marker, the manifest (correct digests, `sdkDirectory`), and a loadable layout — verified
   by the suite against a temp copy.
6. **Tolerance mechanism is fixed**: the provisional numbers live in exactly one place
   (the env-gated test), and `FIXTURES.md` documents where the founder's first run sets
   them.

## Open questions / risks

- **The stand-ins' WER against the real engine is unrepresentative** (TTS audio is
  unnaturally clean) — the provisional tolerances may be too tight or too loose; that is the
  point of "adjusted from the first real run", and the numbers live in one place.
- **Noisy fixture SNR** — provisional at a fixed value; recorded in `FIXTURES.md`.
- **The 200 ms fixture** — a single word at ~200-300 ms; the real-engine tolerance is
  "at most one substitution" while provisional.
