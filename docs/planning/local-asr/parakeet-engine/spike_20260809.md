## 2. SDK facts the engine design must honour (the README's quick start was simplified)

| Fact | Detail | Consequence |
|---|---|---|
| `AsrManager` is a **Swift actor** | `public actor AsrManager` | Sendable by construction — holding it in a Vocca actor is clean; the C2-B worry is resolved |
| Batch API | `transcribe(_ samples: [Float], decoderState: inout TdtDecoderState, language: Language?) -> ASRResult` | `TdtDecoderState(decoderLayers:) throws`; `ASRResult: Codable, Sendable` with `public let text: String` — no segments/confidence on the batch result |
| Manual load | `AsrModels.load(from:configuration:version:encoderPrecision:encoderComputeUnits:progressHandler:)` | the Vocca path; `encoderPrecision: .int8` is the default for v3 |
| **The layout rule (the load-bearing finding)** | `load(from: D)` finds files at **`<D.parent>/<repo.folderName>/`** — folderName is `parakeet-tdt-0.6b-v3`; `loadModelsOnce` also `createDirectory`s D | Vocca's `<version>/` file home does **not** match; the files must live under a `parakeet-tdt-0.6b-v3/` subdirectory of the version dir, and the engine loads with `D = <version>/parakeet-tdt-0.6b-v3` |
| The HF repo is a **tree of directories** | `Encoder.mlmodelc/` etc. are directories containing `model.mil`, `coremldata.bin`, `metadata.json`, `weights/…`; the repo ships many variants; TDT v3 needs Preprocessor, Encoder, Decoder, JointDecisionv3 + vocab/config | the manifest's file names must be **nested paths**; the store/downloader must create intermediate directories and scan recursively |
| Compute-unit defaults | Preprocessor `cpuOnly`, Encoder `cpuAndNeuralEngine` | matches the architecture's ANE plan |

## 3. The verdict

**Local: GO for everything local.** Build clean under strict concurrency; warm load 0.1 s;
RTF ~0.012; 470 MB artifact; offline enforcement structural; manager Sendable; layout
resolved by the plan amendment below.

**Runner: NOT YET MEASURED — the one open question.** The hosted-runner half
(`.github/workflows/asr-spike.yml`, `workflow_dispatch`) needs the branch pushed and a human
to trigger it. The question it answers: can CoreML load/run Parakeet on a macos-15 VM with no
ANE, and at what RTF, within the headless job's 20-minute budget (FluidAudio build + 470 MB
download + compile + five-fixture transcription)? **Until that run happens, the CI-gated
fixture suite's verdict is PENDING, not GO** — and the fallback is already designed and
documented: the real-engine suite on founder hardware (SMOKE_CHECKLIST), seam tests in CI.
The engine work below does not wait on it.

## 4. Plan amendments this record forces (all recorded here first)

1. **`model-downloader` extension (new phase in this plan): the SDK-shaped layout.**
   `ModelManifest` gains an optional `sdkDirectory: String?`; when set, the store writes every
   file under `<version>/<sdkDirectory>/` (the marker stays at `<version>/`). Manifest file
   names may be nested paths (`Encoder.mlmodelc/model.mil`): the downloader creates
   intermediate directories before writing `.part` files, the commit's rename crosses them,
   and `isPresent`'s `.part` scan and the immutability snapshot become **recursive** — the
   "a `.part` anywhere means not present" promise must survive nesting.
2. **The engine's load call** is `AsrModels.load(from: <version>/<sdkDirectory>)` — by the
   SDK's own rule this resolves to exactly the files' home. `sdkDirectory`'s value is
   manifest *content* (generated from the real download), not machinery.
3. **The manifest content** (the real file list + digests for TDT v3 int8) is generated from
   the first real download per `SMOKE_CHECKLIST.md` step 17 — the spike has not downloaded it
   (the model was already cached on this machine); the file set is `ModelNames`'
   required list for `.v3`/`.int8`.
4. **The 470 MB measurement** corrects the "≈600 MB vs ~2 GB" open question:
   `PRODUCT_SPEC.md:166`'s number should become the measured 470 MB in the fixture-suite
   docs task.
5. **RTF note:** the docs' ~24× (`ROADMAP.md:14`, RTF 0.042) is conservative on M4 Max;
   measured 0.0122. Recorded, not propagated — C7 owns the numbers.
