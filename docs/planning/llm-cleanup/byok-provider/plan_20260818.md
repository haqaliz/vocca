### 1.1 Design decisions — the spec's open questions, closed here

- **Shared vocabulary already exists** (`ollama-provider` owns it): `LLMProviderError`
  (`.malformedResponse`/`.emptyResponse`/`.keyUnavailable`/`.unauthorized`) and
  `CleanupPrompts` (`.byokSystem`). This aspect **imports** them; it does not redefine them.
- **`KeyProvider` is a local seam** beside the provider (the `ModelTransport` precedent — the
  seam lives in the module that owns the family). `protocol KeyProvider: Sendable { func
  key() throws -> String? }` — nil = absent.
- **`SystemKeychainKeyProvider` is the one file in `Sources/` permitted to name the
  `Security`/`SecItem`/`kSec` family.** Item `kSecClassGenericPassword`, service
  `dev.vocca.Vocca`, account `byok-key`, `SecItemCopyMatching`; returns the password string or
  nil; throws on any `OSStatus` other than `errSecItemNotFound`/`errSecParam`(absent). Pure
  translation — executed by nothing in CI (the `SystemPasteboard` precedent). A new H7-style
  Security family row in `InjectionSeamBoundaryTests` (tree-wide scan: Security appears
  nowhere else in `Sources/`, so no per-module scoping needed — unlike FileManager).
- **BYOK request shape (v1 contract, `prd.md` Risks):** OpenAI-compatible chat completions,
  POST to the configured `endpoint`; body `{ "model": <model if set>, "messages": [
  {role:"system", content: CleanupPrompts.byokSystem}, {role:"user", content: transcript} ] }`;
  header `Authorization: Bearer <key>`. Decode `choices[0].message.content`. A `model == nil`
  omits the field (some endpoints default); documented as the v1 contract.
- **Provider is a Sendable struct** over `endpoint: URL`, `model: String?`, `keyProvider: any
  KeyProvider`, `transport: any LLMTransport`. Declares `requiresNetwork = true` and
  `budget = .seconds(5)`. No config loading here — `cleanup-config` builds it.
- **Failure mapping (the extended taxonomy):** key `nil` ⇒ `.keyUnavailable`; keyProvider
  throws ⇒ rethrow; `serverStatus(401|403)` ⇒ `.unauthorized` (no retry); `serverStatus(500)`
  ⇒ rethrow `.serverStatus`; malformed/empty/whitespace ⇒ `.malformedResponse`/`.emptyResponse`.
  Transport errors pass through.

## 4. Testing Strategy

- All headless: `StubKeyProvider` (return/throw modes) + `StubLLMTransport`. No real Keychain,
  no real network — the adapter is executed by nothing in CI; the founder's BYOK smoke step is
  its first run.
- B8 is the unit's sharpest edge: the key-hygiene sentinel sweep across logs + error
  descriptions on every failure path.

## 5. Environment & Secrets

- The key is never in a log or error; the `Authorization` header carries it on the wire only
  (asserted in B2). No secrets in the repo; the real key lives only in the user's Keychain.

## 6. Edge Cases & Error Handling

- Key absent / keychain locked / 401 / 403 / 500 / unreachable / malformed / empty /
  whitespace — every path throws (the chain falls back), no retry loop, no prompt, no silent
  skip. `unauthorized` is distinct from generic `serverStatus` (a wrong key is a user error).
