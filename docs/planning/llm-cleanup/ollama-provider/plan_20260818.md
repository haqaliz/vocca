### 1.1 Design decisions — the spec's open questions, closed here

- **Shared vocabulary lives here and is owned here.** `Sources/VoccaText/LLM/CleanupPrompts.swift`
  (`enum CleanupPrompts { static let ollama: String; static let byokSystem: String }` — byte
  constants, the copy-family discipline) and `Sources/VoccaText/LLM/LLMProviderError.swift`
  (`enum LLMProviderError: Error { case malformedResponse, emptyResponse, keyUnavailable,
  unauthorized }`). The `byok-provider` aspect imports these; it does not redefine them. This
  aspect lands first so the vocabulary exists for `byok-provider` (sequencing note in the
  spec's "parallel" line: the shared files couple them, so they run in sequence).
- **The prompt is cleanup-not-creativity, pinned.** `CleanupPrompts.ollama` instructs: rewrite
  the dictated text into clean, correctly punctuated prose; preserve meaning, names, code
  identifiers, numbers, and spelling exactly; remove fillers and stumbles; output only the
  cleaned text with no preamble or explanation. The provider appends `\n\nDICTATED TEXT:\n` +
  the transcript. Byte-tested.
- **Provider is a Sendable struct** over injected `endpoint: URL`, `model: String`,
  `transport: any LLMTransport`, `prompt: String = CleanupPrompts.ollama` (the
  `ShippingRulesCleanupProvider` shape). Declares `requiresNetwork = true` and
  `budget = .seconds(5)` (M1). No config loading here — `cleanup-config` builds it.
- **Endpoint pathing:** the provider posts to `endpoint.appendingPathComponent("api/generate")`
  (default endpoint `http://localhost:11434` ⇒ `.../api/generate`), JSON body
  `{ "model": ..., "prompt": ..., "stream": false }` (`CAPABILITY_ROADMAP.md:137`).

## 4. Testing Strategy

- All headless over `StubLLMTransport` (from `llm-transport`). Request-shape assertions read
  the stub's recorded-request ledger. No real network — the real Ollama run is a smoke step
  (`root-wiring` M10).
- B4 is the load-bearing degrade test: every failure mode throws, so the chain
  (`cleanup-chain`) can fall back honestly.

## 5. Environment & Secrets

- None. `CleanupPrompts`/`LLMProviderError` are shared; the BYOK provider consumes them.

## 6. Edge Cases & Error Handling

- Decode failure / missing `response` key / empty / whitespace → `.emptyResponse` /
  `.malformedResponse` throws; never a partial string, never a retry.
- Non-2xx from the transport surfaces as `LLMTransportError.serverStatus` (rethrow); the
  provider does not reinterpret it.
- The caller's budget race (M1) is the only timeout; the provider is cancellation-cooperative
  (its `await` on the transport propagates `CancellationError`).
