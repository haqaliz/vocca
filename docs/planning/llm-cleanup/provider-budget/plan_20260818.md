### 1.1 Design decisions — the spec's open questions, closed here

- **Default lives in a protocol extension, not the protocol declaration.** `var budget:
  Duration { get }` in the protocol; `extension CleanupProvider { public var budget: Duration
  { .milliseconds(10) } }` next to the `requiresNetwork` default (`CleanupProvider.swift:61-65`).
  A conformer that says nothing costs 10 ms — the C5 numbers are untouched by default.
- **The private constant goes away.** `DictationPipeline.cleanupBudget`
  (`DictationPipeline.swift:108-113`) is replaced by reading `provider.budget` at call time;
  the value flows into `CleanupContext.budget` as today (`:328-330`). Verify with grep that
  the constant has no other consumer before removing it.
- **Rules declares, does not default** (the B10 contract, `ShippingCleanup.swift:29-31`):
  `public var budget: Duration { .milliseconds(10) }` beside the declared `requiresNetwork`.

## 6. Edge Cases & Error Handling

- A provider declaring a *shorter* budget than the default (should not happen; the race
  honors whatever is declared — no clamping).
- `budget == .zero` (pathological): the watcher's first `clock.now - start` check is already
  `>=` — the race degrades immediately; no division or negative-duration code exists. No
  special handling needed, but the B9 pair's double may not need to test it.
- Cancellation: unchanged — the watcher throws, `try?` routes to raw, span recorded, and the
  post-cleanup re-check (`:262-267`) still gates injection on Esc.
