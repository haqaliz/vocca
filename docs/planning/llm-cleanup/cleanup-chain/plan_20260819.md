### 1.1 Design decisions — the spec's open questions, closed here

- **The synthetic transcript's exact init.** The LLM stage receives
  `Transcript(text: base, segments: [], engine: transcript.engine,
  isFinal: transcript.isFinal, audioDuration: transcript.audioDuration,
  missingSampleCount: 0)` — the original transcript's engine/isFinal/duration are carried
  (only `text` is consumed by either provider today), and `missingSampleCount` is **zero** per
  `spec.md:94-96`: the synthetic transcript is a text transform, not a claim about captured
  audio — it must not claim samples it doesn't have.
- **Cancellation rethrow mechanism.** In the LLM stage's `catch`, the chain re-checks
  `Task.isCancelled` and rethrows `CancellationError()` before falling back to `base`
  (`spec.md:37-41`). The real flows that cancel the LLM stage (the pipeline's budget race and
  Esc) cancel the task, so `Task.isCancelled` is true when the transport throws
  `CancellationError`. A provider that throws `CancellationError` while the task is *not*
  cancelled degrades to `base` — the desired "never break dictation" behavior, and exactly
  what the spec pins.
- **Degrade is a return, never a rethrow.** The chain swallows the LLM stage's throw and
  returns the rules output (`spec.md:34-36`); the pipeline's raw-degrade is reserved for
  rules-stage failures.

## 6. Edge Cases & Error Handling

- **Empty/whitespace rules output** — skip the LLM stage, return as-is (B7).
- **LLM empty/whitespace output** — route to `base` (B4), the never-empty rule.
- **LLM throw** — return `base` (B3); the pipeline's raw-degrade stays reserved for
  rules-stage failures.
- **Cancellation** — rethrow `CancellationError` when the task is cancelled (B5); the
  pipeline's post-cleanup re-check (`DictationPipeline.swift:262-267`) is the backstop.
- **`llm == nil`** — pure rules passthrough (B1).
