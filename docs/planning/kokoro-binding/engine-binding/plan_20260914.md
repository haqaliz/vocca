## Phase 2 — GREEN: `KokoroEngine`

- **Goal:** the one-file conformance, test-first, headless legs pass.
- **File:** `Sources/VoccaSpeech/Kokoro/KokoroEngine.swift` (`import KokoroCoreML` +
  `import VoccaCore`; Foundation not required — check `SentenceChunker` is stdlib-only
  and keep the file dependency-lean):
  - `public final class KokoroEngine: SpeechSynthesizer, @unchecked Sendable` (the
    SystemSynthesizer warrant: all mutable state under one `Mutex`).
  - `public let identity: VoiceIdentity` — `engineID: "kokoro-82m"`, `voiceName: voice`.
  - `public init(modelDirectory: URL, voice: String, rate: Float? = nil)` — stores plain
    data only; **no port-engine construction** (purity pin 2).
  - State: `isCancelled`, `generation`, `inFlightContinuation: AsyncThrowingStream<AudioChunk, Error>.Continuation?`, `portEngine: KokoroCoreML.KokoroEngine?`, `portFailure: Error?` — under one `Mutex`.
  - `speak(_ text: String) -> AsyncThrowingStream<AudioChunk, Error>`:
    - `SentenceChunker.sentenceChunks(of: text)`; empty → empty stream (before any state/port touch).
    - Creates a producing `Task`; `onTermination` cancels it.
    - Per sentence: check `Task.isCancelled`/flag; construct the port engine lazily on the first non-empty sentence (outside the lock; memoize the result and any thrown error — a failed construction fails every subsequent speak with the same error); call `port.synthesize(text: sentence, voice: voice, speed: rate ?? 1.0)`; convert via the internal chunk builder; yield. `continuation.finish()` at the end.
  - `cancel() async`: under the lock — set `isCancelled`, bump the generation, take the
    in-flight continuation; outside — **`continuation.finish()` immediately** (the
    consumer's `next()` returns nil fast; the orphaned render result is dropped by
    generation, never yielded — the "no chunk after cancel" pin). Never call the port's
    own stop/interrupt API (the SystemSynthesizer doctrine).
  - Re-invoke: a new `speak` resets the flag (the SystemSynthesizer render-loop reset
    shape); the lazily-constructed port engine is reused.
  - `static func audioChunk(fromSamples samples: [Float]) -> AudioChunk?` — Float32
    little-endian bytes via `bitPattern`, 24000, mono, `duration = count/24000`; empty → nil.
  - Error mapping: absent models → a `KokoroEngineError` case carrying the directory
    (asserted in pin 4).
- **Validation:** `./Scripts/test-with-floor.sh --filter KokoroEngineTests` +
  `KokoroSeamBoundaryTests` green; full suite green.
- **Commit:** `kokoro-binding: the KokoroEngine conformance — RED headless pins, then GREEN (one seam file)`

## Environment & privacy

- `VOCCA_RUN_REAL_SPEECH` (presence), `VOCCA_KOKORO_MODEL_DIR` (presence; the extracted
  models directory). No new egress: the port's downloader is never called; the probe
  pins it.

## Edge cases

- `speak("")` must short-circuit **before** the port engine is constructed (probe purity).
- A cancelled-then-reinvoked speak with the port engine already constructed must render
  fully (the suite's third leg).
- If the port's `synthesize` throws mid-loop (per-chunk failure): the stream throws
  (documented in the test) — the seam contract says the stream may throw; the plan's
  behavior is: propagate, do not swallow, do not yield a partial sentence.
- The conversion must not produce a zero-duration chunk from a zero-length sample array
  (nil instead) — the per-chunk-duration > 0 pin depends on it.
