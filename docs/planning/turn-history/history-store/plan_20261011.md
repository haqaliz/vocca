## Decisions made in planning

- **D1 (module):** a new adapter module `VoccaConversation`, not a file in `VoccaBootstrap` —
  the recorded rule (`ModuleBoundaryTests.swift:106-113`): rooting a FileManager seam in the
  composition root would force permitting `AppBootstrap.swift`, which already names
  `FileManager`. The module is the third instance of the pattern (Vocabulary → Core; adapter →
  the module).
- **D2 (one file for the seam):** `Sources/VoccaConversation/ConversationHistoryStore.swift`
  holds `ConversationTurn`, `ConversationFileSystem`, `DefaultConversationFileSystem` and the
  actor — the `PersistentUsageStore.swift` precedent (the seam permits exactly one file).
- **D3 (truncation, recorded):** field caps truncate at `maximumTextCharacters = 2000` (the
  bubble's render cap value, reused). Refusing a long utterance would silently stop recording —
  worse than a disclosed, uniform bound. The divergence is recorded in the store's doc comment.
- **D4 (`onChange`):** `@Sendable (Int) -> Void`, default no-op, fired with the new count after
  `recordTurn` / `clear` / `load` — the menu condition fold's source (aspect 3). Testable by
  injection; no other plumbing.
- **D5 (the 9th seam):** key `"conversation"`, root `VoccaConversation`, permitted
  `["ConversationHistoryStore.swift"]`; widen `InjectionSeamBoundaryTests`' exact-set pin and
  the mirror pin in `ReplyRenderingInvariantTests:227-247`.

## Testing strategy

All offline, temp directories through the injected seam; no network, no child, no real
Application Support path in tests. Counterfactual mutations recorded and reverted for any test
that passes on first run (e.g. eviction→refusal must redden H4; a timestamp field must redden
the byte pin). Manual: none (SMOKE 167 is aspect 4's).

## Environment & privacy

No env vars; the store is the only conversation-text file and the byte pin is its shape. `load()`
never writes (the usage-store contract). No egress surface exists in the module.

## Edge cases

Empty file / missing file / unreadable file → empty history, never a throw; hand-edited
oversize file → newest 50 kept (recorded); duplicate/blank rows → skipped; `clear` on a missing
file → succeeds; `markLastTurnInterrupted` with zero turns → no-op; truncation exactly at the
bound; UTF-8 multi-byte truncation must not split a scalar (pin it).
