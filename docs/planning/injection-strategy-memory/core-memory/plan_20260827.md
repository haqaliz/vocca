- **RED first:** write `Tests/HarnessTests/StrategyMemoryProjectionTests.swift`:

  - The demotion rows (9–11, 15): demoted with a future window → dropped; `now == window`

  - The guarantee rows (12–14): all three real rungs demoted → `[.clipboardPaste]`; clipboard

  - The eligibility rows (18–20): `reprobeEligibility` — false for a non-demoted rung, false
    before the window, true at/after it, false for a demoted rung without a window.
  - The single-source scans (21–22): the literal `604_800` appears exactly once under

### Phase 3 — The record fold (spec M5/M6)

- **Goal:** `record` — demote-on-fail, the failsafe residual, verified promotion, re-probe
  restore/re-demote with a fresh window, and the rung-0 identity.
- **RED first:** write `Tests/HarnessTests/StrategyMemoryRecordTests.swift` (spec tests
  23–40). Build results by hand exactly like the Phase C fault-injection suite
  (`InjectionResult(rung:attempted:verified:elapsed:)` — `elapsed: .zero` is fine, the fold
  never reads it). The load-bearing rows:
  - demote-on-fail (23, 26): AX fails → clipboard wins → AX demoted with
    `reprobeWindows == now + 604_800`; failsafe winner → every attempted rung demoted.
  - winner rows (24–25): each real winner never demoted; post-winner trace entries untouched.
  - invariant rows (27–28, 39): clipboard/failsafe never demoted — including the closed-matrix
    property `testRecordNeverProducesClipboardOrFailsafeInDemotedRungs` over every winner ×
    trace row the ladder can produce.
  - identity rows (29–30): `attempted == []` (the rung-0 shape) → returned strategy equals the
    input; a non-AX winner absent from the trace → identity.
  - promotion rows (31–34): unverified AX success does NOT promote (X1); verified AX on a
    non-allowlisted app promotes and the next projection includes AX; AX on an allowlisted app
    leaves the flag false; promotion preserves the rest of the strategy.
  - re-probe rows (35–37): a re-probed rung that succeeds is restored (removed from
    `demotedRungs`, window dropped); one that fails re-demotes with a fresh window (not
    eligible again until `now + 604_800`); an unattempted demoted rung keeps its window.
  - contract rows (38, 40): the window written is `now + StrategyMemoryTargets.reprobeWindowSeconds`
    (the single source in use), and the `attempted:` parameter — not `result.attempted` — is
    the demotion input.
- **Files:** add `record(result:attempted:now:allowlisted:into:) -> InjectionStrategy` to

## Edge cases

- `now == window` exactly is **eligible** (inclusive; pinned both directions).
- A demoted rung with no window entry is never re-included (tolerant-decode strays stay on
  clipboard; the store aspect inherits this).
- A winner absent from the trace: nothing demoted, no guess (caller-error defense).
- An unverified AX "success" never promotes (X1) — the pure fold refuses to trust a malformed
  row.
- A re-probe that succeeds restores even if its window had not elapsed (the projection could
  never have offered it; the success is still the truth).
- Hand-built invalid state (clipboard in `demotedRungs`): the projection still never drops
  clipboard — the never-empty guarantee holds against corrupt state, not just valid state.
- `record` mutates only the fields it owns; other demotions and their windows survive a fold.
