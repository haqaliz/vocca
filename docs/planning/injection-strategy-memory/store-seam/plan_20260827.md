### 1.1 Design decisions — the spec's open questions, closed here

- **File name: `strategies.json`** (`ARCHITECTURE.md:580` names it; the PRD R9 uses the same
  name — no docs amendment needed, consistent with `cleanup-config.json`/`dictionary.json`).
  The file URL is always `<directory>/strategies.json`; temp suffix `.tmp`; load never reads the
  temp.
- **Both stores are actors.** Stateful by design (the held set between `load()` and
  `update`/`save`), so an actor is the honest Swift 6 shape — the `LatencyLedger` precedent. The
  doc comment states the concurrency contract: single process; `load()` once at launch (the
  custody-chain load); every persist is the whole held set, atomically renamed, so a racing pair
  of updates ends with one complete file and the in-memory set carries the other entry forward.
- **Cap: refusal, never eviction** (`spec.md` Isolation decisions). `update` of a **new** bundle
  ID at capacity returns `false` (and persists nothing); updates of known apps always succeed.
  `load` and `save` are uncapped (the file is what it is; `save` is the deliberate reset/edit
  write). Capacity is constructor-injected, defaulting to the Core-owned constant
  `InjectionStrategyStoreConstants.maximumRememberedApps = 512` — the `LatencyLedger.swift:50`
  value, in exactly one file, pinned by a single-source scan.
- **Schema: versioned top level, element-wise tolerant.** `{"version": 1, "strategies":
  [<InjectionStrategy>, ...]}`. The version wrapper is this aspect's own private Codable struct
  in the adapter file; the elements are `core-memory`'s `InjectionStrategy`. `version` missing or
  ≠ 1 → one loud log + empty. Decode is the dictionary's element-wise path:
  `JSONSerialization` top level, one `JSONDecoder` per element, one loud log per skipped element.
  Encode: strict `JSONEncoder` with `.sortedKeys` (byte-stable, hand-editable, the dictionary's
  rationale).
- **`update` throws on persist failure, returns `Bool` for the refusal.** The throw is the
  honest surface for "the file was not updated" — `memory-order`'s detached-task recorder catches
  and logs it (T-2's wiring half, not this aspect's). The ephemeral store never throws.
- **The store's logger is injectable** (`log: @Sendable (String) -> Void`), defaulting to
  `Logger(subsystem: "dev.vocca.Vocca", category: "strategy-memory")` — the dictionary's shape.
  Tests inject the shared `LogCollector` (`DictionaryStoreTests.swift:376`) and assert exact
  counts.
- **Default location resolution:** the journal's defensive fallback
  (`FileSystemJournalStore.swift:54-60`) pointed at `Vocca/strategies.json`; the
  `init(directory:)` shape so tests pass temp dirs.

### 3.1 The protocol — `Sources/VoccaCore/StrategyMemory/InjectionStrategyStore.swift`

```swift
public protocol InjectionStrategyStore: Sendable {
    /// The strategies held, loaded from the store's backing (the empty set on first run).
    /// Never throws. For the persistent store: missing → empty silently; corrupt → the readable
    /// remainder with one loud log per skipped element; the file is never rewritten.
    func load() async -> [InjectionStrategy]

    /// Upsert `strategy` by its bundle ID into the held set and persist.
    /// Returns `false` when at capacity and `strategy` is a new app — a loud refusal, never an
    /// eviction; the file is untouched. Updates of known apps always succeed. Throws when the
    /// persist fails (the caller owns the fire-and-forget and must log — T-2).
    func update(_ strategy: InjectionStrategy) async throws -> Bool

    /// Replace the whole held set and persist — the reset-learned and future editing paths.
    /// Deliberate wholesale writes are not subject to the learning cap.
    func save(_ strategies: [InjectionStrategy]) async throws
}

public enum InjectionStrategyStoreConstants {
    /// The cap on remembered apps (PRD S1): at this many held strategies, `update` of a *new*
    /// bundle ID is refused loudly — never evicted. The `LatencyLedger` cap-512 value, in
    /// exactly one place, pinned by a single-source scan.
    public static let maximumRememberedApps = 512
}
```

The doc comment states the concurrency contract (single process, load-once, whole-set atomic
persists) and the privacy constraint (bundle IDs, rung identifiers, integer epoch seconds — no
text). No `Foundation` import, no `Data`, no `URL`, no `JSONEncoder` — `CoreBoundaryTests` stays
unedited and green.

### 3.2 The ephemeral store — `Sources/VoccaInject/Memory/EphemeralInjectionStrategyStore.swift`

`public actor EphemeralInjectionStrategyStore: InjectionStrategyStore` — `init(capacity: Int =
InjectionStrategyStoreConstants.maximumRememberedApps)`. Holds `[String: InjectionStrategy]`
keyed by bundle ID. `load()` returns the held set (initially empty); `update` applies the cap
(refusal `Bool`, no throw — nothing can fail in memory); `save` replaces wholesale. No
`Foundation` import. Executed by every headless test (PRD R1's "EphemeralStore in every headless
test").

### 3.3 The persistent store — `Sources/VoccaInject/Memory/PersistentInjectionStrategyStore.swift`

Three declarations in the one file (the seam's one `FileManager`-naming file, mirroring
`FileSystemDictionaryStore.swift`'s one-file shape):

- `public protocol InjectionStrategyFileSystem: Sendable` — `createDirectory(at:)`,
  `write(_:to:)`, `moveItem(at:to:)`, `read(_:) -> Data?`, `fileExists(atPath:)` — the
  `DictionaryFileSystem` shape; the seam the tests inject their doubles through.
- `struct DefaultInjectionStrategyFileSystem: InjectionStrategyFileSystem` — the one place in
  the module that spells `FileManager`; `moveItem` implemented as
  `FileManager.default.replaceItemAt(destination, withItemAt: source)` — **not** `moveItem`,
  which refuses an existing destination (the regression lesson,
  `FileSystemDictionaryStore.swift:60-66`). Raw translation only, no decisions.
- `public actor PersistentInjectionStrategyStore: InjectionStrategyStore` —
  - `init(directory: URL, capacity: Int = ..., fileSystem: InjectionStrategyFileSystem =
    DefaultInjectionStrategyFileSystem(), log: @escaping @Sendable (String) -> Void = ...)` (the
    log default routes to `Logger(subsystem: "dev.vocca.Vocca", category: "strategy-memory")`);
    `init()` resolving Application Support with the journal's defensive fallback, pointed at
    `Vocca/strategies.json`.
  - The version wrapper: `private struct StrategyFile: Codable { let version: Int; let
    strategies: [InjectionStrategy] }` — encode writes `version: 1`; decode reads it for the
    version check.
  - `static func encode(_ strategies: [InjectionStrategy]) throws -> Data` — strict
    `JSONEncoder`, `.sortedKeys`, wrapped in `StrategyFile` (in-memory strategies are trusted —
    "a save only ever writes a state the app itself produced").
  - `static func decode(_ data: Data, onInvalidElement: @Sendable (String) -> Void) ->
    [InjectionStrategy]` — top level via `JSONSerialization`; not an object → one loud log +
    empty; `version` missing or ≠ 1 → one loud log + empty; per element, one `JSONDecoder`
    decode, each failure → one loud log + skip. The element-wise path is what makes a mixed file
    decodable without a throw.
  - `load()` — non-throwing: file absent → `[]` silently; unreadable → one loud log + `[]`;
    otherwise `decode` with `onInvalidElement` wired to the injected log. Replaces the held set
    and returns it. Never rewrites the file.
  - `update(_:)` — cap refusal for a new bundle ID at capacity (return `false`, no write);
    otherwise upsert the held set and persist the **whole set**: create-directory, encode,
    temp-write `<dir>/strategies.json.tmp`, rename over the final name. Throws on any
    persist failure.
  - `save(_:)` — replace the held set, persist the whole set atomically; uncapped.

## 6. Edge Cases & Error Handling

- **Corrupt file on disk** — bad elements: skipped with exactly one loud log each, the rest
  loads (S5). Top level not an object: one loud log, `[]`, file never rewritten (S6). Unknown or
  missing version: one loud log, `[]`, file never rewritten (S7, X5).
- **Torn save** — the temp write lands, the rename throws: `update`/`save` throw, the committed
  file keeps the previous content, the leftover `.tmp` is never readable (S2); pinned also by the
  planted-tmp test (S8) and the recorded pair (S1/S3).
- **File deleted between load and update** — harmless by construction: the persist never reads
  the prior file (create-dir, temp-write, rename are independent of prior existence). The save
  path is the dictionary's, already proven there; no dedicated test needed beyond the round trip.
- **Cap saturation** — new app refused loudly (`false`, no write, held set unchanged, file
  unchanged — S10/S11); known apps always succeed; deliberate `save` bypasses the cap (S12).
- **Directory absent or uncreatable** — save/update creates it (`withIntermediateDirectories:
  true`); a refusing double makes `update` throw, and the throw is the contract (S13).
- **Empty set** — missing file → `[]` silently (S4); `save([])` writes the empty strategies
  array and a fresh load returns `[]` (S14).
- **Strict concurrency surprises** — actors with `Sendable` strategies; `@Sendable` on the log
  closure and the seam protocol. Any isolation surprise means a design deviation — stop and flag.
- **Warning-as-failure** — unused parameters in doubles fail CI; keep doubles minimal and used.
- **Name collisions** — grep before creating (§1).
