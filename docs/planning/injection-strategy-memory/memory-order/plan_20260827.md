### 1.1 Design decisions — the spec's open questions, closed here

- **Second factory, not a parameter.** `ShippingLadder.make` keeps its exact signature and
  behavior (byte-for-byte for existing callers); `ShippingLadder.makeWithMemory(memory:handoff:clock:)`
  is the new public factory. The memory instance fills three slots inside it: the order, the
  `AccessibilityRungStrategy` allowlist, the injector's recorder.
- **The recorder is the memory instance itself** — one object, three roles (spec §Isolation).
  `LadderInjector` gains `recorder: (any InjectionStrategyRecording)? = nil`; nil ⇒ byte-for-byte
  today's injector, so the ~two dozen existing `LadderInjector` construction sites compile and
  behave unchanged (the `PartialTranscriptSink` optional-seam precedent).
- **`contains(bundleID:)` includes window-elapsed candidates** — the promotion-deadlock finding
  (spec §Isolation). Both `orderedRungs` and `contains` call Core's one eligibility decision, so
  the AX rung's own gate (`AccessibilityRungStrategy.swift:98-100`) passes exactly the apps the
  projection offers AX to. This is the aspect's **highest-risk edit** (see §7).
- **Hostile seed folds at load, launch-minted** (Core's `seeded(hostileBundleIDs:now:)` merge);
  learned entries win. Re-probe window constant `604_800` s consumed from Core, never re-declared.
- **The probe's drive wires the memory-backed order** over a temp-directory store with no file;
  the report gains `strategy=absent`; `expectedCycleLifecycle` extends via the guard-the-guard
  tests. The probe's own cycle still composes its own `LadderInjector`
  (`DictationCycleDrive.swift:379-389`) — that is where the field joins.
- **The custody chain's ladder assembly is extracted** into a testable static
  (`AppBootstrap.assembleShippingLadder(...)`) so "store → load → memory → ladder" is pinned
  headless, not asserted by comment (`AppBootstrap.swift:134-143`).

## 4. Testing Strategy

- **All R2–R6/R8 acceptance tests run headless in CI** (the rare aspect with no TCC/
  Accessibility/microphone dependency — the ladder decision and the memory are pure over injected
  seams). T2 drives the *real* `InjectionLadderDecision.decide` through the real `LadderInjector`
  with fake rung strategies — the fault-injection suite's hand-built `InjectionResult` pattern
  (`InjectionResult.swift:43-50`).
- **Time is injected everywhere it matters:** the re-probe window (T3, T5, T6) via the memory's
  `now` supplier; the ladder's own clock stays the shipped `MonotonicClock` — the two never mix
  (wall-clock epoch seconds for the strategy, monotonic `Duration` for the ladder).
- **The fire-and-forget claim is pinned mechanically:** T13's gated store proves the injector
  returns before the persist completes; T14 proves the next projection reads the in-memory apply,
  not the disk; T15 proves the chained funnel orders rapid writes.
- **The zero-network probe is the whole proof of the default path (G4):** T18 — zero
  `connect(2)`, `strategy=absent`, `rung=clipboardPaste` unchanged; the guard-the-guard test
  refuses a weakened probe the way it already refuses one today (`ZeroNetworkTests.swift:948-957`).
- **Load-bearing tests:** T5 (learned promotion reaches AX *and* its gate) and T16 (one instance,
  three slots) — the two halves of R6; T4 (seeded hostile) — the R5 user promise; T13 (injector
  never awaits) — the T-2 latency claim.

## 6. Edge Cases & Error Handling

- **Default path stays zero-network** — absent `strategies.json` ⇒ silent empty ⇒ C4 ordering;
  the interposer sees zero `connect(2)` (G4).
- **Rung-0 refusals and `bundleID == nil`** write nothing (T11) — Secure Input and no-focused-
  field results have no attempted rung to demote (`SMOKE_CHECKLIST.md` step 27).
- **The catch residual** (handoff refused custody, `LadderInjector.swift:84-88`) still routes
  through the seam — its `attempted == []` derives the same nil mutation.
- **Corrupt `strategies.json`** — `store-seam`'s tolerant load (loud log, never rewritten, never
  fatal); the memory just sees an empty/partial snapshot (X5, enforced by the store's tests).
- **Racing persists** — the chained funnel (T15) prevents a stale snapshot overwriting a newer
  one; the chain's awaits live inside detached tasks, off the latency path.
- **A promoted app later fails AX** — the ordinary demote path applies (T2 machinery); the
  promotion is re-probe-verified, never sticky past a real failure.
- **Seeded hostile + learned conflict** — the load-time merge is learned-wins (T9); a verified
  Docs promotion survives relaunch.
- **Never-empty / widgetFailsafe** (T7/T8) — the projection's closed-space invariants, X3 closed
  by construction (clipboard exempt) and by contract (failsafe never in a strategy).
- **Probe-exit race with the persist** — the probe asserts only the read side
  (`strategy=absent`); the write side's proof is T13/T15, never a probe assertion that could flake.
