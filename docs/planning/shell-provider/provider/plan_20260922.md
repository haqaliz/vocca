2. **RED** — `ShellProviderTests`:
   - `toolIDs` == registry ids;
   - `describe` derives the sentence from the argv (a planted argv appears verbatim; an
     authored clause cannot hide it); parameter values rendered `key = value`, sorted,
     sanitised (a control char cannot forge a dialog line — the MCP sanitisation precedent);
   - absent `readOnly` → `BlastRadius.destructive`; declared `true` → `.readOnly`;
   - unreadable/missing parameter values → the refusal sentence **keeping the destructive
     radius**;
   - unknown command id → refusal value, never a throw;
   - invoke returns the engine's outcome (call-logged engine); never throws; never
     constructs an `ActionConfirmation`.
3. **GREEN** — `ShellProviderSentences` + `ShellProvider` (actor; nonisolated `toolIDs`
   fixed at construction; describe pure; invoke forwards to the engine).
4. **REFACTOR** — add the five Family-A rows in `ActionSeamBoundaryTests`; lint + boundary
   suites green.
