## Goal

`ShellExecutor` — the subprocess engine: fixed argv (no shell), bounded injected-clock
timeout (30 s ceiling, wait-count so a spin loop cannot pass), no orphan
(`kill(pid, 0) == -1 && errno == ESRCH`), bounded output capture, exit-code mapping,
failure as returned values, scrubbed environment.

## Prerequisites

- `command-registry` shipped (not consumed here — the engine is registry-agnostic).
- The transport-permit widening (provider aspect step 1) committed, permitting the
  execution file to name `Process` with its D2 answer.

## Files to create/modify

- `Sources/VoccaActions/Execution/ShellExecutor.swift` — the engine
- `Sources/VoccaActions/Execution/ShellExecutionResult.swift` — bounded result/outcome shape
- `Tests/HarnessTests/ShellExecutorTests.swift` — the hostile battery
- `Scripts/test-with-floor.sh` — floor raise (growth commit)

## Implementation steps

1. **RED** — `ShellExecutorTests`:
   - benign `/bin/echo` runs; success + exit code read back;
   - `/bin/false` → `failed` with the bounded `shell.exitCode` key;
   - a seeded sleeping child under the injected clock reaches 30 s, is terminated, outcome
     `failed`, never a hang (the clock is injected; the wait is counted);
   - **no-orphan**: after termination `kill(pid, 0) == -1 && errno == ESRCH` on the real
     child (zombies answer `kill(pid,0)` successfully — ESRCH is the exact assertion);
   - flood child capped at the 4 KB output bound, still terminates normally;
   - every failure path is a returned value, never a throw.
2. **GREEN** — `ShellExecutionResult` + `ShellExecutor` over `Process` (executableURL +
   arguments, never `/bin/sh -c`; injected `Clock`/wait-count loop; terminate + reap;
   bounded output capture; scrubbed env).
3. **REFACTOR** — align the reason-key vocabulary with `ActionOutcome`'s bounded keys;
   lint + boundary suites green.
