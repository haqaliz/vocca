# Implementation Plan: evidence-logging

**Date:** 2026-09-02 · **Feature:** injection-matrix-record · **Spec:** `docs/planning/injection-matrix-record/evidence-logging/spec.md`

## Context for the executing agent

Swift 6 package; suite via `Scripts/test-with-floor.sh` (floor **1746** — `swift test` exits 0
when it discovers nothing, so the floor script is the only trustworthy gate; never run bare
`swift test` and call it green). Branch: `feat/injection-matrix-record/aliz`. Worktree:
`.claude/worktrees/feat-injection-matrix-record`.

House rules that bind this aspect:

- **Test-first:** RED before GREEN, always. No production code before its failing test.
- **`VoccaCore` stays logging-free** (stdlib imports only — a `Logger` import there fails the
  module-boundary lint). Pure vocabulary lives in Core; `os.Logger` adapters live in the module
  that owns the side effect.
- **`LadderInjector`'s slot pattern:** optional injected dependency, `nil` = prior behavior
  byte-for-byte (the `recorder` slot is the precedent, `LadderInjector.swift:57-58`).
- **Evidence is shape, not content:** no transcript text in any line, ever.
- **Zero-network invariant:** this aspect adds no network path; the probe test keeps passing.

## Phase 1 — Pure evidence vocabulary + formatter (RED first)

- **Goal:** `MatrixEvidenceEvent` + `MatrixEvidenceLine.format` in `VoccaCore`, exact-string
  tested.
- **Prerequisites:** none.
- **Files:**
  - Create `Sources/VoccaCore/MatrixEvidence.swift` — `public enum MatrixEvidenceEvent:
    Sendable, Equatable` with `.sessionOpened(mode: SessionMode)` and
    `.delivery(targetBundleID: String, result: InjectionResult)`; `public enum MatrixEvidenceLine`
    with `public static func format(_ event: MatrixEvidenceEvent) -> String`.
  - Create `Tests/HarnessTests/MatrixEvidence/MatrixEvidenceLineTests.swift` (dir exists? if
    not, create — the `Tests/HarnessTests/` layout mirrors modules).
- **Implementation steps:**
  1. Write the failing tests first (RED), one per event shape (spec A1):
     - `.sessionOpened(mode: .dictate)` → `session opened mode=dictate`
     - `.delivery` accessibility verified → `delivery target=com.apple.Notes rung=accessibility attempted: [accessibility] verified=true`
     - clipboardPaste unverified → `... rung=clipboardPaste attempted: [accessibility, clipboardPaste] verified=false`
     - keystrokeSynthesis → its line
     - failsafe outcome (`rung: .widgetFailsafe`) → its line
     - refusal (`rung: .widgetFailsafe, attempted: []`) → `... attempted: [] verified=false` —
       this is the step-92 artifact the checklist quotes (`attempted: []` with a colon — pin the
       exact spelling in the test).
  2. Implement `MatrixEvidence.swift` until the tests pass (GREEN). Keep `SessionMode`'s raw
     value rendering (check `SessionMode`'s existing `RawRepresentable`/description — reuse it
     rather than inventing a second spelling).
  3. REFACTOR: none expected; keep the enum minimal.
- **Validation:** `Scripts/test-with-floor.sh` green; the module-boundary lint (no `Logger` in
  `VoccaCore`) green.
- **Commit message:** `add the matrix evidence vocabulary and its line formatter`

## Phase 4 — Harness run log (shell, reviewable thin slice)

- **Goal:** `Scripts/injection-matrix.sh` appends one JSONL line per completed row and prints
  the run-log path.
- **Prerequisites:** none (independent of Phases 1-3; may be parallelized with Phase 3 — only
  one agent should touch the script at a time; if parallelized, keep the two file sets disjoint).
- **Files:**
  - Edit `Scripts/injection-matrix.sh`:
    - `RUN_LOG_DIR="${RUN_LOG_DIR:-$HOME/Library/Application Support/Vocca/matrix-runs}"`,
      `RUN_LOG="$RUN_LOG_DIR/<date>.jsonl"`, `--run-log <path>` override (PRD N1).
    - `log_run_row()`: after each row's tally, append one JSONL line: date, row name, rung
      observed (or `null` for refusals/skips), bytes matched (`true`/`false`/`null`), verdict
      (`pass`/`failed`/`skipped`/`voided`/`refusal`), note. Use `jq -nc` if jq is available,
      else a single-quoted hand-built JSON string with the note field escaped — keep it
      dependency-light and reviewable.
    - Print `run log: <path>` at run start.
- **Implementation steps:**
  1. No failing-test-first possible for shell output, but the suite already runs the script's
     `--self-check`; keep it green. Add the function + calls; `sh -n` the script.
  2. Validate: `--self-check` green via the floor check; a manual dry append (`--run-log /tmp/x.jsonl`
     on a dry run must not corrupt; live rows are the founder's run).
- **Validation:** floor check green (harness tests included).
- **Commit message:** `give the matrix harness its promised run log`

## Testing strategy

- Unit: exact-line tests (A1), ladder-emission stub tests (A2), nil-slot via existing suite
  (A3), module-boundary lint (A4), harness `--self-check` + `sh -n` (A5). Floor 1746 (A6).
- Integration/manual: the lines observed via `log show` on the founder's machine during aspect
  `matrix-run` (steps 87-93 gestures); run-log file populated per row.
- Command: `Scripts/test-with-floor.sh` after every phase.

## Environment & secrets

- None. No env vars, no network, no credentials. (The `RUN_LOG_DIR` default is a user-level
  path under Application Support, alongside `strategies.json`.)

## Edge cases

- Refusal rows: `attempted: []` must render exactly (step 92 quotes it) — pinned in tests.
- Failsafe outcomes are *successful* under I1 (`ARCHITECTURE.md:199`) — the line must not
  imply failure; formatter renders the rung name only.
- `LadderInjector`'s handoff-refusal residual (the `catch` path building
  `rung: .widgetFailsafe, attempted: []`) also emits — one emission point covers it.
- A strategy that never changes writes no `strategies.json` — the log lines and run log are the
  evidence for steady-state rows; do not add a disk write to compensate (out of scope).
- Privacy: `privacy: .public` only because the line is shape-only; never interpolate the
  transcript into any line.
