## Flagged spec ambiguities (resolved here; record the resolution in the first commit)

1. **Env gate: one var or two?** The spec's acceptance cites `LatencyBenchmarkRealEngineTests.swift:84-96`
   — which is the **two-var gate** (`VOCCA_LATENCY_BENCH`, then `VOCCA_MODEL_DIR`) — while the
   spec body and PRD M1 name only `VOCCA_MODEL_DIR`. **Resolution: two-var gate, matching
   `:84-96` verbatim.** This harness records timed numbers (the key-up-cost row), so it is a
   latency measurement, not a WER measurement; the cited precedent is exactly this gate.
2. **Fixture list: five or six?** The spec names five fixtures; the loader discovers six
   (`spike-clip` is byte-identical to `clean`). **Resolution: drive the discovered set
   (`ASRFixtureSuite.loadFixtures()` verbatim, six rows).** A fixture that exists must be
   measured; the duplicate row costs one real transcription and is recorded as-is.
3. **Provisional equivalence tolerances: there is no existing table.** The whisper precedent
   (`tolerances_20260810.md`) is "seeded from Parakeet's table, not measured" — but equivalence
   has no table to seed from. **Resolution: ship a placeholder-seeded table in exactly one
   file (`ProvisionalEquivalenceTolerances`, all fixtures `0.05`, the `"clean"`-fallback
   shape of the WER runner), flagged in code and in the print output as PROVISIONAL-BY-DECISION
   until the founder's first run re-baselines it via the `tolerances_20260825.md:42-57`
   procedure.** The first run prints raw numbers beside the provisional verdict — the
   re-baseline decision is never made on the provisional verdict alone.
4. **Chunk size for the streamed run: no documented SDK minimum.** **Resolution: a
   single-sourced constant, `EquivalenceMeasurementTargets.streamChunkSamples = 16_000`
   (1 s at 16 kHz), pinned by a scan.** If the sibling adapter refuses it (an SDK minimum),
   raise it **in exactly that one file** and say so in the commit message — never silently.
5. **The sibling plan is not yet in the tree** (only `parakeet-streaming/spec.md` exists).
   This plan builds against the **seam** (`ASREngine.stream` + `transcribe`), which already
   exists, so nothing blocks; the env-gated test's streaming guard (below) makes a
   pre-sibling run record **VOID with a reason**, never a silent batch-vs-batch comparison.

## 2. Implementation phases (strict TDD — RED first, commit per phase)

### Phase (a) — The pure comparison + verdict-row machinery, headless

- **Goal:** the comparison, the token-diff shape, the verdict decision and the rendered rows
  exist as pure code over scripted strings; seeded unequal pairs produce FAIL. **A gate that
  cannot fail proves nothing** — the seeded-pair tests are this phase's guard-the-guard.
- **Prerequisites:** none (pure Swift, no engine, no env).
- **Files:**
  - Create `Tests/HarnessTests/EquivalenceMeasurement.swift` (license header from any existing
    test file) containing, all `enum`/`struct`, test-target-only:
    - `StreamedVsBatchComparison` — pure: `(batchText: String, streamedFinalText: String) ->
      EquivalenceRow`. `EquivalenceRow` carries `wer` (via the shipped `WER.compute`,
      reference = batch, hypothesis = streamed final), `exactEqual: Bool`, and
      `shape: TokenDiffShape`.
    - `TokenDiffShape` — `.identical`, `.prefixThenDiverge(commonTokens: Int)`,
      `.wholesaleDrift`. Mechanical rule: tokenize both sides with the same normalization as
      `WER` (letters + apostrophes, lowercased — reimplement the split locally, do not reach
      into `WER`'s private helper); identical → `.identical`; ≥ 1 shared leading token then a
      divergence → `.prefixThenDiverge(count:)`; first tokens differ → `.wholesaleDrift`.
      `.prefixThenDiverge` is the shape the roadmap's "only the tail is unprocessed" premise
      predicts; `.wholesaleDrift` contradicts it — the count is printed so the founder sees
      the actual shape, never a guessed boundary.
    - `EquivalenceVerdict` — `.pass`, `.fail`, `.void(reason: String)` — decided by a pure
      function over (row, tolerance, preconditions): over tolerance → `.fail`; within →
      `.pass`; **any** precondition unmet (suppression unreadable, engine not streaming,
      either side missing) → `.void(reason:)` — SMOKE rule 1: void, not fail.
    - `EquivalenceRunVerdict` — the go/no-go row over all fixtures: **GO** (every row
      `.pass`), **NO-GO** (any row `.fail`, naming the fixtures), **VOID** (no fails, any
      `.void`, naming the reasons). Pure, table-tested.
    - `ProvisionalEquivalenceTolerances` — **the one file** the placeholder table lives in:
      `["clean": 0.05, "spike-clip": 0.05, "accented": 0.05, "noisy": 0.05,
      "sixty-second": 0.05, "two-hundred-ms": 0.05]`, consumed with the
      `table[name] ?? table["clean"]` fallback shape of the WER runner. Doc-comment:
      PROVISIONAL-BY-DECISION placeholder; re-baselined via the
      `tolerances_20260825.md:42-57` procedure, in exactly this file.
    - `EquivalenceMeasurementTargets` — `streamChunkSamples = 16_000` (the 1 s chunk
      constant), in exactly one place.
    - The rendering: `EquivalenceRowRenderer` — the verdict table string (columns:
      fixture, WER, exact, shape, key-up cost, suppression), and
      `whisperExclusionNote` — the constant sentence the print output must carry:
      "whisper.cpp needs no equivalence run: its final equals batch by construction
      (repeated whisper_full on the growing buffer; the final is the last full decode)."
    - `EquivalenceRunResult` — the run's record: one `EquivalenceRow` + verdict + key-up
      cost + suppression per fixture, plus the summary verdict.
  - Create `Tests/HarnessTests/EquivalenceMeasurementTests.swift` — RED first, table-driven:
    equal pair → WER 0 / exact true / `.identical` / `.pass`; a seeded unequal pair (e.g.
    "the quick brown fox" vs "the quick red fox") → WER > 0 / exact false /
    `.prefixThenDiverge(2)` / `.fail`; a wholesale-drift pair → `.wholesaleDrift`; both-empty
    → `.identical`, WER 0 (the sub-minimum row); the summary table over mixed rows (one
    fail → NO-GO naming it; void-only → VOID; all pass → GO); the void reasons (suppression
    unreadable, engine not streaming, missing side); the renderer's row and table strings;
    a scan pinning `0.05` and `streamChunkSamples` to their one file (single-source);
    the whisper-note constant pin.
- **Validation:** `swift test --filter EquivalenceMeasurementTests` RED (does not compile →
    RED is "the types do not exist"), then GREEN; then full `./Scripts/test-with-floor.sh`;
    raise `MINIMUM_EXECUTED_TESTS` by hand in this commit if the count moved.
- **Commit:** `add the streamed-vs-batch equivalence verdict machinery`
