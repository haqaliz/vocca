**Goal:** `ParakeetEngine` reports `supportsStreaming == true` and implements `stream(_:)` behind the seam — the RED pins from Phase 1 turn GREEN. **Prerequisites:** Phases 1 and 2.

**Files to create/modify:**
- `Sources/VoccaASR/Parakeet/ParakeetEngine.swift`:
  1. `ParakeetEngine.swift:49` → `public nonisolated var supportsStreaming: Bool { true }`.
  2. `prepare()` (:141-160): additionally retain the loaded models — `private var models: AsrModels?` set at :147-150. The batch `manager`/`decoderState` path is untouched.
  3. New `nonisolated func stream(_ chunks: AsyncStream<AudioBuffer>) -> AsyncThrowingStream<Transcript, Error>` — the exact `StreamingStubEngine` shape (:172-184): build the `AsyncThrowingStream`, spawn `Task { await self.runStream(chunks, continuation: continuation) }`, and `continuation.onTermination = { @Sendable _ in task.cancel() }`.
  4. `private func runStream(...) async` (actor-isolated, mirrors `StreamingStubEngine.runStream` :197-238):
     - **Not-loaded guard:** `guard let models` else `continuation.finish(throwing: VoccaError.modelUnavailable(identity, reason: "the model is not loaded; call prepare() first"))` — mirrors `transcribe` :183-186. This is the one branch of the real adapter a headless test can execute.
     - **Session lifecycle:** construct `SlidingWindowAsrManager(config: .default)` — **SDK defaults only, per founder decision; never pass a custom config** — `try await manager.loadModels(models)` (the non-downloading overload, :145), `try await manager.startStreaming()`.
     - **Forward:** for each chunk, accumulate `totalSampleCount` and the last chunk's `missingSampleCount`; build a 16 kHz mono `AVAudioPCMBuffer` (standard `AVAudioFormat`, sampleRate 16 000, one channel; copy `chunk.samples` into `floatChannelData`; set `frameLength`) and `await manager.streamAudio(buffer)`. (Seam buffers are already 16 kHz mono — AudioBuffer.swift:37-48; no conversion needed. `AVAudioPCMBuffer`/`AVAudioFormat` are AVFoundation names, not FluidAudio names, and are permitted in this one file; add `import AVFoundation`.)
     - **Termination:** when the chunk stream ends: if `Self.isBelowSDKMinimum(sampleCount: totalSampleCount, sampleRate: AudioBuffer.interchangeSampleRate)` → `try? await manager.finish()` (call it so the SDK's recognizer task completes; **discard its result and ignore its throw** — the seam contract is absolute: a sub-minimum stream answers a single empty final, never throws) → yield `ParakeetTranscriptMapper.final(text: "", forSampleCount: totalSampleCount, engine: identity, missingSampleCount: lastMissing)` → `continuation.finish()`. Else → `let text = try await manager.finish()` → yield `ParakeetTranscriptMapper.final(text: text, …)` → `continuation.finish()`. **Exactly one final, from exactly one place.**
     - **Partials:** a concurrent consumer of `manager.transcriptionUpdates` (a child task of the same task group, or a sibling task cancelled together with the producer): for each `SlidingWindowTranscriptionUpdate` (confirmed or volatile alike), yield `ParakeetTranscriptMapper.partial(text: update.text, engine: identity)`. It never yields a final. If the updates stream ends on its own (SDK-side continuation cleared), the task simply ends — **termination is driven only by the chunk stream**, never by the updates stream, so the adapter cannot hang on a silent SDK.
     - **Cancellation:** on `Task.isCancelled` at any boundary → `continuation.finish(throwing: CancellationError())` — the double's shape (ASRTestDoubles.swift:202-204), which the pipeline's route already handles.
     - **SDK throw:** any error from `loadModels`/`startStreaming`/`finish()` (other than the sub-minimum path above) → `continuation.finish(throwing: VoccaError.transcriptionFailed(identity, underlying: error))` — mirrors `transcribe` :207-209. A stream that throws terminates by throwing; a caller's `for try await` then ends, which is the seam's legitimate failure shape (the batch default does the same at ASREngine.swift:102-104).
  5. **No `EngineTiming` recording on the stream path** — deliberate: the pipeline owns the ASR span (PRD technical considerations, `DictationPipeline.swift:211-227`), and all real numbers are the equivalence-measurement aspect's. The batch timing path (:192-203) is untouched.

Also flip-supporting rows as needed for the Phase 1 pin.

## 6. Edge cases and how each maps to the seam's contract

| Edge case | Behaviour | Contract anchor |
