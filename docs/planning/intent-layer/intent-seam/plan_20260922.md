## Edge cases to handle

- Empty utterance, whitespace-only utterance → `.none`.
- Utterance matching two tools equally → deterministic tiebreak, `.ask` when below
  threshold, `.toolCall` only when the top score clears it.
- Arguments text: the resolver builds the JSON text (may be nil for no-arg tools); the 4 KB
  `maximumArgumentsUTF8Bytes` bound is enforced at `ActionInvocation` construction —
  a resolver result that would exceed it is refused (`.ask`/`.none`), never truncated.
