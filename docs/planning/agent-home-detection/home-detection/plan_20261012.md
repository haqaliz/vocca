## Acceptance criteria (test-first)

- **A1** — with `homeDirectory: "/Users/aliz"`, a binary at
  `/Users/aliz/.opencode/bin/opencode` resolves `.detected(path: …)`.
- **A2** — with `homeDirectory: nil`, the check set is byte-identical to today
  (the 24 candidate-path checks); `homeRelativeCandidatePaths` is asked never.
- **A3** — order pinned: absolute trio → home dirs → PATH, name-major; the
  recording fake asserts the exact check sequence.
- **A4** — `homeRelativeCandidatePaths` pinned verbatim; every entry relative
  (no leading `/`, no `~`).
- **A5** — `AgentCLIDetection.swift` still imports nothing and names no
  `FileManager`/transport family (the existing file-lint test stays green).
- **A6** — the composition root passes the real home: a wiring/source test pins
  `NSHomeDirectory()` at the `detectAgents` call site.
- **A7** — a trailing slash on the injected home is normalised (one rule).

## Design

- `AgentCLIDetection.detect(catalog:fileExists:path:homeDirectory:)` — additive
  `homeDirectory: String? = nil`. `nil` → today's behaviour.
- `public static let homeRelativeCandidatePaths: [String] = [".local/bin",
  ".opencode/bin", ".bun/bin", ".cargo/bin", ".nix-profile/bin", ".volta/bin",
  "bin"]` (pinned; every entry relative).
- Resolution per candidate name: absolute `candidatePaths` → home-expanded dirs
  (only when a home is present) → PATH absolute components. First existence wins.
- Join rule: strip one trailing `/` from the home, then `home + "/" + component`.
- `AppBootstrap.swift` `detectAgents` (~:2300) passes `NSHomeDirectory()`.
