## Spec correction (found in planning)

The composed root that `configure` builds reads the **real** Application Support directory
(`AppBootstrap.swift:652-660`), so a `phrases=` count on the PROBE-INTENT-DEFAULT line would
depend on whose machine runs it. **`phrases` moves to PROBE-INTENT-PHRASE** (temp store).
The default line gains nothing else, and its `intentShellRows` stays machine-independent:
shell rows are refused at load, so the loaded table's shell count is 0 whatever the file
holds.
