# Plan: wiring (2026-09-25)

Source: `../prd.md` (R5, R6, R7), `./spec.md`. Prerequisites: phrase-resolver and
phrase-table-store GREEN.

## Overview

1. Widen `composeIntentWiring` to take a per-call resolver **provider**, with the existing
   `resolver:` form forwarding.
2. Flip the composed default to a provider over the real `IntentPhraseStore`.
3. Replace the root's fact carrier `intentResolver: (any IntentResolver)?` with
   `intentResolverProvider`, so the probe reads the type of what the run builds.
4. Land the safety acceptances.
5. Re-anchor G5 once.

## Decided in planning (agent calls, labelled)

- **The fact carrier (the spec's open risk).**
  `DictationLoopRoot.intentResolverProvider: (@Sendable @MainActor () async -> any IntentResolver)?`
  holds the **same closure** the wiring resolves through. The probe calls it once and reflects
  the dynamic type, so the fact is an effect of the run, not a literal. The old `intentResolver`
  slot is removed (one consumer: `IntentDrive.swift:246`).
- **G5 sequencing** follows the recorded precedent (intent-layer, shell-provider): GREEN lands
  with the single anticipated G5 pin failure, and REFACTOR recomputes it. Every other test is
  green at GREEN.
- **The PROBE-INTENT-DEFAULT `resolver=` field** changes in GREEN, in the same commit as
  the flip, because the composed fact changed. The probe aspect adds everything else.
