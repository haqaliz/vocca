## Phase 2: GREEN: the store

- **Files:** create `Sources/VoccaActions/Config/IntentPhraseStore.swift`:
  - `public struct IntentPhraseFile: Sendable, Equatable { version: Int; phrases: [PhraseIntentRow]; static let empty }`
  - `public enum IntentPhraseStoreError: Error { tooManyPhrases(Int), fileTooLarge(Int) }`
  - `public struct IntentPhraseStore: Sendable` with the caps (`maximumPhrases = 256`,
    `maximumFileBytes = 65_536`, `maximumPhraseLength = 256`, `maximumIDLength = 128`),
    `init(directory:fileSystem:log:)`, `static defaultDirectory(applicationSupport:home:)`,
    `load()`, `save(_:)`, `static encode(_:)`, `static decode(_:onInvalid:)`.
  - Decode path: size check → `JSONSerialization.jsonObject` → a dictionary with `version == 1`
    (as an exact `Int`, not a bool) and `phrases` as an array → per element, re-serialize it and
    `JSONDecoder().decode(RowDTO.self)`, where `RowDTO` has three `String`s. Then validate: non-empty,
    length caps, `!PhraseIntentResolver.normalized(phrase).isEmpty`,
    `providerID != ShellProvider.providerID`, and first-wins on the normalized phrase.
    Count the valid rows; if there are more than the cap, return `.empty` plus one log.
  - Encode: a `Codable` DTO, `JSONEncoder` with `.sortedKeys`.
  - Save: the caps check (count, then encoded bytes) → create directory → write `.tmp` → replace.
- **Validation:** `swift test --filter IntentPhraseStoreTests` is green, then the floor run.
- **Commit:** `phrase-table-store: GREEN — the tolerant, capped phrase store`

## Edge cases / failure safety

- Every failure is an empty table plus a log, never a throw on load. The effect is "voice
  resolves nothing", which is the safe direction.
- A save failure throws; there is no UI caller this slice, and tests assert it.
- The log text names the file and the row index, **never** the phrase text. Phrases may be
  personal; that follows the shape-only log precedent.
