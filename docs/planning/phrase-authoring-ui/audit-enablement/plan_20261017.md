# Implementation plan: audit-enablement

> Aspect of `phrase-authoring-ui` · Date 2026-10-17 · Strict TDD (RED → GREEN → REFACTOR).
> Spec: `docs/planning/phrase-authoring-ui/audit-enablement/spec.md`.
> Template: the **Shell commands** section (`ActionsTabPage.swift:86-104`,
> `ShellWiring.listCommands` `ShellWiring.swift:218-231`) is the exact precedent — a registry
> read → own row array → a `.…ConfigLoaded` fold → `toolRow(_:)`.

## Goal

Fix **F-A**: render `audit.count` (read-only) and `audit.clear` (destructive) as default-off
enablement rows in a new **Audit tools** section, so enabling them is not a hand-edit of
`action-config.json`.

## Decisions (from planning)

- **D-1 — toggle-only rows.** The section reuses `toolRow(_:)` for the toggle but **omits the
  arm/preview affordances** for the audit rows; `audit.clear` is destructive and arming it from
  the tab is out of scope (the voice path + the card is the run surface). The row carries the
  D2 copy and an explicit destructive warning on `audit.clear`.
- **D-2 — row source.** A `listAuditTools` closure on the action wiring
  (`Sources/VoccaBootstrap/ActionWiring.swift`), reading `AuditActionProvider.toolIDs` and each
  tool's radius from `provider.describe` — no discovery, no spawn (the F-A fix is a static
  list).
- **D-3 — default off, already handled.** The reducer's default-off fold for any
  `(providerID, toolID)` pair already works (`ActionsTabState.swift:270-292`); this aspect only
  adds the row source + section.

## Edge cases

- An audit row whose enablement exists in `action-config.json` from a prior hand-edit must
  reappear **on** (reapply enablement), not reset to off.
- `audit.clear` enabled → the copy warning is present, but the section still offers **no arm**
  (D-1).
- A stale audit row for a tool id no longer served: render it inert (the `servers` stale-row
  precedent) — do not crash.
