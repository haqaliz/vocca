## Edge cases & error handling

- A foreign providerID with a real toolID → describe's unserved sentence at
  `.readOnly`; invoke's `provider.unknownTool`. Fail closed, never a trap.
- An unknown toolID under the **own** providerID → unchanged (existing behavior).
- `arguments` are irrelevant to the guard (checked before parsing) — a foreign call
  must not parse or send anything.
