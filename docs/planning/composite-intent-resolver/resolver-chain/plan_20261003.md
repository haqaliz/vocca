## Testing strategy
Everything in CI is offline and injected; no model or network. Unit (Phases 1–3), wiring (4), end-to-end
(5), probe under interposer (6). Manual: none claimable — the keyword resolution rate stays unmeasured.

## Environment & privacy
No env vars, no new files on disk (one more field in an existing file), no network, no child process.

## Edge cases
Non-Bool switch → off + log; corrupt file → empty table + switch off; keyword arguments over 4 KB →
`.none` (existing); shell row present in catalog → filtered; empty displayName → raw-ID ask (recorded).
