(`Tests/HarnessTests/CleanupEvalHarnessTests.swift:835-855`) has no caller, nothing

This aspect makes the flow **runnable + documented + pinned**. It does **not** record
the corpus, answer the ballot, or produce the verdict — the founder's real F2 run is
aspect `cleanup-eval-f2`'s (`plan_20260901.md`), sequenced after this one.

**Ground facts (verified in the tree):**

- `printBallot(pairs:seed:printer:)` exists, prints `seed=0x<HEX>` then `## <name> [<class>]`,
  `A:`, `B:`, `answer: ` per pair in seeded presentation order — no caller.
- `parseAnswers` (`:807-830`) requires the first line `seed\t<hex>` where `<hex>` is
  bare uppercase hex: `UInt64(line.dropFirst("seed\t".count), radix: 16)`. Swift's
  radix parser rejects an `0x` prefix (`UInt64("0x1A", radix: 16) == nil`), so the
  ballot must print the **bare hex** or the founder's `answers.tsv` will not parse.
- `runReal` (`:860-913`) prints per-pair verdict rows, `preference=NN.N%`, per-class
  tallies, `RECORDED, not gated` vs 0.80 — already implemented and headlessly tested.
- The env-gated test (`:444-535`): skip without `VOCCA_CLEANUP_EVAL` (`:445-449`), env
  value IS the pairs dir (`:450`), set-but-missing dir hard-fails (`:452-458`), missing
  `answers.tsv` skips claiming "the first invocation prints the ballot" (`:459-463`),
  wav-without-model hard-fails (`:465-473`), wav substitution loads raw from `.raw.txt`
  first then replaces it with the engine transcript (`:475`).
- The headless stub-corpus pattern (B2, `:71-98`): `makeScratchRoot()` + `writeTriple`
  (`.raw.txt`/`.clean.txt`/`.class.txt`) + 20 pairs at the vacuity floor — already
  passing in CI, no founder recording, no env var.

## Goal

First `VOCCA_CLEANUP_EVAL=<pairs-dir>` invocation prints a seeded, side-blind ballot
whose seed round-trips through `parseAnswers`; second invocation prints the verdict
rows. `.raw.txt` is documented as the discovery requirement in the three F2 procedure
docs and pinned by a test where one is missing. Floor 1755 holds; branch green after
every task.

## Edge cases

- **Empty corpus / wav-only corpus** → `noPairsFound` stays (loader untouched; Phase 3
  pins it). A ballot is never printed for a corpus that cannot measure.
- **Corpus below 20 pairs** → `corpusBelowMinimum` (existing, untouched) — the
  env-gated first-invocation branch now reaches it and hard-fails instead of skipping.
- **Seed format mismatch:** `seed\t0x…` (0x prefix) or a pasted `seed=<hex>` verbatim
  (wrong separator) → `malformedAnswers` — the ballot's bare-hex spelling plus the
  documented `=`→`\t` substitution is the mitigation; Task 2.2's pin records why.
- **tie / noPreference rows** — accepted by the flow, excluded from the denominator by
  the scorer (already pinned); the flow test carries both so the round-trip is proven.
- **Second invocation, still no `answers.tsv`** — skip stays, but its message is now
  true ("the first invocation prints the ballot") and the ballot is on stdout.
- **Missing/unknown pair answers** → loud named errors (existing tests, untouched).
- **wav-without-model** → hard fail stays, now ordered before the ballot print.
- **Fresh seed per first invocation** — orders differ between ballots; the headless
  fixed seed stays reserved for the stand-in run's determinism.
