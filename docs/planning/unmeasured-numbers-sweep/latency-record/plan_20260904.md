## Environment & privacy

- Env per-run only: `VOCCA_LATENCY_BENCH=1`, `VOCCA_MODEL_DIR=<dir>`. Nothing exported
  globally. Zero network; models local; no audio/text leaves the machine.

## Edge cases

- **Throttled run = voided.** Any row printing `1 (SUPPRESSED…)` or `UNREADABLE` voids the
  whole run — re-run, never record (`SMOKE_CHECKLIST.md:1337-1340`).
- **Composite overclaim if the cleanup span is unnamed.** The printed `total` row must carry
  the cleanup status (`notPresent` for the nil-cleanup pipeline) in the row itself; Phase 1's
  test pins it, so a printer that drops the status cannot go green.
- **Contract-pin breakage = escalation, not silent amendment.** If
  `testFixtureDrivenCyclesLeaveExactRecordedSpansInOrder`, its streaming sibling, or the
  vocabulary pin fails at any point, the seeded contract or `SpanName` was touched — stop and
  escalate as a seam-contract change (PRD M7), do not amend the pin.
- **60 s substitution must be stated.** The suite has no 10-second clip; the composite is a
  60 s-fixture measurement and every record beside it says so
  (`SMOKE_CHECKLIST.md:1353-1354`) or the P2 gate reads it as a 10 s number.
- **No re-claiming.** Per-span and warm-start/re-warm numbers stay at
  `STATUS.md:208-213`; this aspect adds the composite row and the signed re-baseline only.
- **The composite is not a `SpanName`.** A fifth case would trip the vocabulary pin and the
  gate's closed-set logic; the printer labels its row without touching `LatencySpan.swift`.
