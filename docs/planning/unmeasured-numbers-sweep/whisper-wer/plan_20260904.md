## Context for the executing agent

Swift 6 package; the full-suite regression bar is `./Scripts/test-with-floor.sh`
(floor **1755**, `MINIMUM_EXECUTED_TESTS`). Real-engine runs are env-gated on
`VOCCA_MODEL_DIR` and **skip visibly in CI** — the skip is the tell-tale that the
gate is unset, and the founder's machine is the only execution environment.

**Filtered runs go through plain `swift test`, not the floor script.** A `--filter`
run executes ≪ 1755 tests, so `test-with-floor.sh --filter <Class>` always exits 1
on its own floor check (`Scripts/test-with-floor.sh:1450`). SMOKE 18 (Parakeet) was
recorded the same way (14.2 s filtered run, `tolerances_20260810.md:66`). Use the
floor script only for the full-suite bar after a tree change.

The record chain, in order of authority: `tolerances_20260810.md` is **the**
explanation of the per-engine WER mechanism (provisional tables, measure → margin →
sign → land, failing-run-re-baselines-not-relaxes); `tolerances_20260829.md` adds the
**measured-values table** (machine + artifact hashes + six figures), the
**step-102-first** ordering (`:59-72`) and the rule that a WER measured against
unverified bytes is **void** (`SMOKE_CHECKLIST.md:2147-2149`); `SMOKE_CHECKLIST.md`
step 104 is what happens to the numbers after step 19.

House discipline for this aspect: **records, never gates** — no gate passes as a
result of this unit; a blown tolerance re-baselines with data in hand, never relaxes
silently; a harness/engine crash or a digest mismatch is a defect (RED→GREEN, floor
holds); **no engine-parameter tuning of any kind** (out of scope, spec `:16-17`);
**no Parakeet re-run** — its six-fixture WER rows are recorded
(`tolerances_20260810.md:66`, 2026-09-01) and this aspect measures whisper only.

## Phase 3 — SMOKE 19: whisper's first real WER run + the streamed cycle (turbo)

- **Goal:** the six-fixture WER measurement on the real turbo engine — the row that
  turns "reasoning about the C library" into measurement
  (`WhisperCppEngine.swift:238-258`) — plus the streamed cycle, the short-audio
  rows, and the O(n²) cost row. Recorded, never gated.
- **Prerequisites:** Phase 1 (the WER run is void unless step 102 passed for the
  artifact it uses); Phase 2's whisper selection recorded (96/103 precede or
  accompany).
- **Files:** none modified by the measurement itself — the env-gated official run
  and the scratch driver (below, never committed) read the tree; the record lands in
  `docs/SMOKE_CHECKLIST.md` step 19 and `tolerances_20260829.md`'s measured-values
  table.
- **Steps:**
  1. **The official env-gated WER run** — the verdict half (passes the seeded
     table, attribution, offline via the stub transport):
     ```
     VOCCA_MODEL_DIR=<root>/whisper-large-v3-turbo/1 \
       swift test --filter WhisperCppEngineWERTests
     ```
     Expected: skip lifted; six fixtures evaluated against the provisional table
     (clean 0.10 / spike-clip 0.10 / accented 0.12 / noisy 0.20 / sixty-second 0.10 /
     two-hundred-ms at-most-one-substitution — `WhisperCppEngineWERTests.swift:42-49`);
     every transcript attributed to the whisper identity; no network (the transport
     is the stub). On a blown fixture the runner's violation error **carries the
     full WER ledger** (`RealEngineWERRunner.swift:57-62`) — that error is the
     measurement, not a failure.
  2. **The scratch driver** (uncommitted measurement tooling — create
     `Tests/HarnessTests/WhisperMeasurementScratchTests.swift`, delete it before any
     commit): loads the real turbo engine (the `WhisperCppEngineWERTests`
     construction verbatim), and prints:
     - **The per-fixture WER ledger** — the official runner prints nothing on a
       clean pass (`ASRFixtureSuite.evaluate` is silent), so the six numbers the
       record needs come from here: `WER.compute(reference:goldenText, hypothesis:
       transcript)` over `ASRFixtureSuite.loadFixtures()` — the six figures for the
       measured-values table.
     - **The streamed cycle** (SMOKE `:367-386`): one fixture's audio (clean)
       through `engine.stream` split into 1 s chunks (16,000 samples —
       `EquivalenceMeasurementTargets.streamChunkSamples`); print the partials
       (one per decode, each the growing buffer's segments) and the final, and
       assert the final == the batch transcript **text-for-text** (the
       by-construction claim, verified on real audio for the first time).
     - **Short-audio rows**: 0.2 s / 0.5 s / 1 s clips (trimmed from `clean.wav`)
       through **both** `transcribe` and `stream`; record what whisper does —
       transcribes / pads to empty / refuses-and-throws (`WhisperCppEngine.swift:240-258`).
     - **The cost row**: total streamed-decode time vs one batch decode of the same
       utterance on one fixture — the O(n²) observation
       (`WhisperCppEngine.swift:287-292`), recorded, never gated; no caller may
       assume key-up savings.
  3. Record the rows: the six WERs + machine (model id / chip) + artifact hashes
     (the step-102-verified `sha256`s) in `tolerances_20260829.md`'s table and the
     step-19 rows in `SMOKE_CHECKLIST.md`.
- **Fix rule:** a WER tolerance blown is **not** a defect — it re-baselines
  (Phase 5). A harness/engine crash, a streamed-final ≠ batch mismatch, or a
  short-audio **refusal-and-throw** IS a defect: refusal → RED test → GREEN with the
  measured sub-minimum constant in exactly one place, both paths
  (`WhisperCppEngine.swift:255-258` — the `ParakeetEngine.isBelowSDKMinimum`
  mirror, named by SMOKE 19 itself; that is the one sanctioned engine constant, and
  it is set only if the run measures a refusal, never pre-emptively). Floor 1755
  holds after any fix.
- **Edge cases:** a skipped test = env var not reaching the process → void, re-run;
  the sixty-second fixture in the streamed cycle would be ~60 full decodes — run
  the streamed cycle on the clean fixture only and put the cost row there; whisper's
  first decode happens on the first feed chunk (no accumulation threshold) — a
  refusal throws on the first iteration, honestly surfaced
  (`WhisperCppEngine.swift:250-258`).
- **Validation:** the official filtered run green with the skip lifted; the scratch
  driver's printed ledger recorded into the tolerance table and step rows;
  `./Scripts/test-with-floor.sh` (full suite) green.
- **Checkpoint:** stop here and report both tables (the six WERs + the streamed
  rows) to the founder **before** the q5_0 decision.
- **Commit message:** `record whisper's first WER run and streamed cycle (SMOKE 19)`

## Phase 5 — Re-baseline (SMOKE 104): measure → margin → founder-signed → land in exactly the two WER test classes

- **Goal:** the seeded-from-Parakeet whisper table becomes **measured** — with a
  measurement and a signature behind it, and the run recorded. This phase runs
  **whether or not step 19 cleared**: a real run that changes no number leaves the
  seeded table looking measured, which is exactly the dishonesty SMOKE 104 exists
  to close (`SMOKE_CHECKLIST.md:2122-2149`).
- **Prerequisites:** Phase 3 rows recorded (the measurement); Phase 4 disposition
  recorded; the step-102 verification passed for the artifact used (else the
  re-baseline is **void** — `:2147-2149`).
- **Files (the only ones that may change):**
  `Tests/HarnessTests/WhisperCppEngineWERTests.swift` **and**
  `Tests/HarnessTests/ParakeetEngineWERTests.swift` — both tables move together,
  because the two engines run the same suite and moving one alone hides a
  regression in the other (`tolerances_20260810.md:39-42`);
  `tolerances_20260829.md` (the signed row); `docs/SMOKE_CHECKLIST.md` (step 104).
- **Steps:**
  1. **Measure** — Phase 3's six figures, already recorded.
  2. **Margin** — the founder chooses a per-fixture margin (headroom for
     machine-to-machine spread; a fixture measuring 0.0 still gets a nonzero
     margin — a perfect TTS clip is not a perfect room, `tolerances_20260810.md:32-36`).
     The margin decision is recorded in the step-104 note.
  3. **Sign** — the founder signs the table; the record of the run that produced it
     (machine, model artifact hash from the step-102-verified manifest, date) is
     cited in `tolerances_20260829.md`'s measured row (`:54-57` — a number with no
     row behind it is a number nobody can check).
  4. **Land** — the signed numbers (measured + margin) replace the provisional
     table in **both** test classes, and only there. The mechanism doc's wording
     ("provisional", "seeded from Parakeet") in the two classes' doc comments is
     updated in the same edit — the tables and their claims move together.
  5. **Single-source scan check** — the tolerance-shaped rows (`"clean": …` through
     `"two-hundred-ms": …`) appear in **exactly** the two WER classes and nowhere
     else in `Sources/` or `Tests/` (the mechanism's single-source claim,
     `tolerances_20260810.md:3-6`); then run the scanner-family pins green
     (EquivalenceMeasurementTests' single-source rows, WarmStartRatioTests,
     SettingsCopyTests, HotkeyRecorderWiringTests) — a duplicated constant breaks
     them, and a re-baseline must not be the commit that drifts a number into a
     second home. Finally `./Scripts/test-with-floor.sh` full suite green, floor
     1755.
- **A blown tolerance → re-baseline, never relaxation:** a failing real run is the
  correct outcome; the fix is this same procedure with data in hand
  (`tolerances_20260810.md:43-45`). A tolerance is never raised without a measured
  WER + margin + the founder's sign-off behind it — and the step-104 row says the
  seeded table was replaced, so a "measured" table is never inherited silently.
- **Edge cases:** the two-hundred-ms bound is a **rule** (at most one substitution),
  not a WER ceiling — it is carried by the runner's `specialRules` in both classes
  and re-baselined the same way; if the founder declines the margin decision, the
  numbers stay provisional and the step-104 row records "not signed — table
  unchanged", which is a record, not a failure.
- **Validation:** both test classes carry the signed numbers; `swift test --filter
  WhisperCppEngineWERTests` still skips visibly without the env var (the gate is
  intact); the full floor run green.
- **Commit message:** `re-baseline the whisper WER tolerances from the first real run (SMOKE 104)`

## Testing strategy

- No new shipped tests except RED→GREEN fixes for defects the runs surface
  (digest mismatch → regenerated manifest; streamed-final mismatch → engine fix;
  short-audio refusal → the measured sub-minimum constant; a tier-keying symptom at
  95/103). The scratch driver is measurement tooling and is deleted before its
  record commit.
- Recorded numbers are rows in the smoke checklist + the tolerance files — never
  gate assertions. The "guard-the-guard" mechanism tests already prove the gates
  can fail.
- The floor (1755) is the bar after every task; `swift test --filter <Class>` for
  env-gated real runs only (see the context note on why the floor script rejects
  filtered runs).

## Environment & privacy

- Env per-run only: `VOCCA_MODEL_DIR=<root>/whisper-large-v3-turbo/1` (turbo runs),
  `VOCCA_MODEL_DIR=<root>/whisper-large-v3-turbo-q5_0/1` (q5_0 runs). Nothing
  exported globally; nothing committed reads the env. Zero network in every real
  run (stub transport; the store is a no-op on verified bytes); the Phase 2
  downloads are the app's shipping path, done once, through the founder's machine.
- The GGUF bytes and the app's model store stay on the machine; no audio or text
  egress anywhere in this aspect.

## Edge cases (cross-phase)

- **GGUF download friction:** slow/partial transfers stall Phase 1 — resumable
  `curl -L -C -`, then `shasum -a 256` against the license record's hashes; a
  digest failure at provisioning is M1's defect path, not a blocker; only the
  whisper half blocks.
- **Digest mismatch:** verdict lines from the verifier = regenerate the manifest
  from the provisioning run's own output, commit with provenance; never hand-edit.
- **A blown tolerance:** re-baseline (Phase 5), founder-signed, never silently
  relaxed; a miss on q5_0 is a recorded disposition, never a turbo-table change.
- **Skipped instead of run:** env var not reaching the process — void, re-run.
- **Streamed cycle:** final must equal batch text-for-text; a mismatch is a defect
  fix, and the cost row is recorded, never gated.
