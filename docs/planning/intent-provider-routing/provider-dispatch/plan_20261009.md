## Decisions made in planning
- **D1 (router shape):** `AppBootstrap.routeIntentWiring(audit: IntentWiring<AuditActionProvider>, agent: @escaping @Sendable @MainActor () -> IntentWiring<CodingAgentProvider>?) -> IntentWiring<AuditActionProvider>` in `IntentWiring.swift` (already permitted for the generic `ActionProvider` constraint, so no new lint row). It builds a new `IntentWiring` with the audit wiring's `resolve`, `executor`, `policy`; `spawnsSubprocess: false`; and a `performAction` that dispatches. The root slot type, `composeConverseIntentClosures`, the probes and every harness stay untouched. (Deviates from the PRD's "RoutedIntentWiring" naming — recorded.)
- **D2 (dispatch rule):** `invocation.providerID == CodingAgentProvider.providerID`, `agent()` non-nil → agent wiring's `performAction`; everything else → the audit wiring (it fails unserved providers closed, Phase 1).
- **D3 (agent wiring):** `IntentWiring<CodingAgentProvider>` built in the agent launch `Task` (after `root.agentWiring`/`root.agentExecutor` are set) with `composeIntentWiring(configStore:, provider: agentProvider, executor: agentWiring.executor, resolverProvider: <the same shared provider>, root:, activeProjectDirectory:)`, stored in a NEW root slot `agentIntentWiring: IntentWiring<CodingAgentProvider>?`. Same executor as `agentWiring` so the card, Confirm and the audit trail are one chain.
- **D4 (Q1):** confirmed from code — confirm has no session guard; nothing to change.

## Testing strategy
All offline, injected (`CountingAgentRunner`, temp stores); no real agent CLI, no network, no child spawned in CI. Counterfactual mutation evidence for every test that passes on first run. Manual: SMOKE only.

## Environment & privacy
No env vars, no new files on disk, no network, no child process by default. The utterance appears verbatim on the card before the click; the audit stores the approved sentence, never the raw blob.

## Edge cases
Agent side not yet composed → audit wiring's audited failure; agent row disabled/absent → the gate's "not enabled" refusal; placeholder + empty utterance → "Cancelled." pre-card; task text over 4096 bytes → refused, never truncated; card already up → existing refusal; Confirm sentence mismatch → re-prompt; foreign providerID with an audit tool id → fail closed, nothing deleted.
