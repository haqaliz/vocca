### Phase 4 — GREEN: `removeFillers` (B1)

- **Goal:** B1 rows pass; B10/B11/B12 stay green.
- **The stage, frequency-tuned, not blanket:**
  - Static fillers: `um`, `uh`, `er`, `hmm`, `you know` (two-word unit).
  - **"like" — the flank heuristic** (spec Open question 1): removed iff (preceded by utterance
    start, a boundary symbol, or a position vacated by an earlier removal this pass) **and** (followed
    by a pronoun from `{i, you, he, she, we, they, it}`). Survives as verb (`I like pizza`) and
    preposition (`it looks like rain`). Left-to-right single pass; earlier removals make later flank
    checks see the edited text — `"um you know like we are late"`: `um` and `you know` fall first, so
    `like` is utterance-initial when checked, and the row collapses to `we are late`. The exact flank
    set is the open item; the B1 rows are the only pinned surface.
  - **"so" — provisional, pinned only by B8's row 1:** removed iff sentence-initial **and** followed
    by a filler or a pronoun. This keeps the Open-question-1 survival shapes alive ("so that we can",
    "I think so", "and so on" — none pinned, all preserved) and makes `"um so like we need..."`
    collapse correctly. The open question stays open; do not add "so" rows.
  - **The cannot-corrupt rule (I5):** removal takes the filler span plus **exactly one adjacent
    space** (the preceding space if present, else the following) — never both, never two spaces.
    `("um kawa" → "kawa")`, `("pizza um and" → "pizza and")` — the B6 `noCorruptionRows` pin this.
  - Whitespace-only input is identity (B11 row 2 — do not trim). Filler words inside a protected
    token are never removed (a token containing `/ . - _ @` is one unit).

### Phase 6 — GREEN: `resolveSpokenCommands` (B4 + B9)

- Command words → symbols: `period` → `.`, `question mark` → `?`, `exclamation point` → `!`,
  `comma` → `,`, `new line` → `\n`.
- **N2 literal tokens** (whisper emits both spellings): a literal `.`/`?`/`newline` already-symbolic
  token is kept — attached (`done.`), standalone (`we are done . then we rest`), and the word
  `newline` → `\n`. **Word + symbol both present** (`period.`): the symbol wins, the word is dropped
  (B9 row 5 — provisional, Open question 4; the reversed shape `. period` is unpinned — do not add a
  row for it).
- **Spacing, the cannot-corrupt rule:** left-attaching symbols (`.`, `?`, `!`, `\n`) consume the
  following space; `comma` consumes the preceding space (`pause, we`). Exactly one adjacent space,
  never two.
- **False-positive guard (provisional, Open question 5):** a command word fires unless preceded by a
  determiner (`the`, `a`, `an`) — `"the period of the sine wave"` survives while
  `"we are done period then we rest"` fires (B4 row 5). Pinned only by B4/B9 rows.
- **Protection interplay:** commands never fire inside a protected token (`deploy-vocca.sh` is one
  unit, not a command site); the symbol may attach *after* a protected token
  (`aliz@vocca.dev.` — B6 row 1).
- **Validation:** full suite green; B4/B9 green; B1/B10/B11/B12 stay green.
- **Commit message:** `Resolve spoken punctuation commands and literal tokens in VoccaText`

### Phase 12 — GREEN: the protection class (B6)

- **The global guarantee (M2's "cannot corrupt text outside its match"):** a token is any

## 4. Testing Strategy

**The table → entry-point map.** Each of the spec's B-tables is one test method with a `struct Row {
let input: String; let expected: String }` array (the `InjectionLadderTests.swift:322` shape) and an
enumerated `XCTAssertEqual` loop. Because the spec's rows sometimes carry downstream effects (B4's
capitalized output, B7's capitalized output) and sometimes exclude them (B1 and B5 rows have no
terminal period), the tables drive the minimal composition that reproduces the spec's expected
strings — never more, never less:

| Table (spec) | Method | Entry point |
|---|---|---|
| B1 `fillerRows` | `testFillerRemovalRows` | `removeFillers` |
| B2 `segmentationRows` | `testSegmentationRows` | `{segmentAndTerminate, capitalizeSentences}` |
| B3 `capitalizationRows` | `testCapitalizationRows` | `capitalizeSentences` (rows 1–2); `{segmentAndTerminate, capitalizeSentences}` (row 3) |
| B4 `spokenPunctuationRows` | `testSpokenPunctuationRows` | `clean` |
| B5 `numberRows` | `testNumberRows` | `normalizeNumbers` |
| B6 `protectionRows` | `testProtectionRows` | `clean` |
| B6 `noCorruptionRows` | `testNoCorruptionRows` | `{removeFillers, normalizeNumbers}` |
| B7 `dictionaryRows` | `testDictionaryRows` | `{removeFillers, normalizeNumbers, applyDictionary, capitalizeSentences}` |
| B8 `combinationRows` | `testCombinationRows` | `clean` |
| B9 `literalTokenRows` | `testLiteralTokenRows` | `clean` |
| B10 `determinismRows` | `testDeterminismRows` | `clean`, N=5 + two independent sequences |
| B11 `boundaryRows` | `testBoundaryRows` | `clean` |
| B12 perf smoke | `testPerfSmokeUnderTheNamedBound` | `clean`, `perfSmokeBudget` |

- **Why the per-row/per-table staging exists:** B3's row 3 (`"we are late. it is fine"` →
  `"We are late. It is fine."`) needs segmentation for its terminal period while rows 1–2
  (`"i think"` → `"I think"`) must not get one; B7's composition puts the dictionary before
  capitalization because row 3 pins `"Hello world today"` → `"Hi today"`. The expected strings are
  the spec's, verbatim; the entry points are recorded here so a later agent cannot "simplify" a
  composition and break a row.
- **Honest reds, per commit:** Phase 1 — rule 1 against the new import (the only genuinely failing
  state a manifest+table move can produce; the coverage is *replaced*, not removed —
  `ModuleBoundaryTests.swift:261-262`). Phases 3/5/7/9/11/13 — their tables against the missing
  stage. Phases 10/12/14 greens never weaken an earlier pin.
- **Property-pin tables (B10/B11/B12):** pass from Phase 3 on and must never go red; they are the
  pure-function claim (totality, determinism, byte-preservation) and the perf bound, asserted rather
  than assumed — the spec's `## Isolation`.
- **CI executes the real thing** — the rare aspect with no TCC/Accessibility/microphone dependency:
  every row runs the shipped function headlessly, now and forever. The zero-network/probe suites

## 5. Environment & Privacy

- No environment variables, no external services, no new tooling, no new package dependencies.
- Privacy/local-first: the aspect is pure text — no IO, no clock, no network, no audio, no
  permissions. The offline-mode invariants and the interposer suites are untouched.
- No `Locale`/`NumberFormatter`/`String(format:)` anywhere in the function — output is
  byte-identical across machines and process invocations (determinism is the spec's, not an
  implementation wish).

## 6. Edge Cases & Error Handling

- **Swift 6 concurrency:** pure, nonisolated functions; value types; `ReplacementRule` is already
  `Sendable`. Nothing here can hit an isolation precondition; any isolation warning is a design
  deviation — stop and flag.
- **String edge cases:** empty input; whitespace-only (identity — never trimmed: the never-empty
  guard is the pipeline's, M4); unicode/accents/emoji/RTL (first-char capitalization is a no-op on
  caseless scripts — byte-preservation is the B11 assertion); embedded newlines; a 5,000-char
  unbroken token (totality row).
- **The token-protection class:** tokens containing `/ . - _ @` — no stage rewrites inside; internal
  `.` is not a boundary; sentence-initial first-char classes per Open question 8 (`/`-`-`-`_` allowed,
  `@` forbidden — `"My_repo"` pinned by B6).
- **Determinism:** explicit tables only; the B10 rows run N=5 plus two independently constructed
  call sequences — asserted, not assumed.
- **Warning-as-failure:** parameters never trigger the unused warning, so identity skeletons are
  safe; keep locals minimal and used. Any warning fails CI — the phase validation is the full script,
  not just the new file's tests.
- **Floor discipline:** no intermediate commit may drop the executed count (impossible here — the
  count only grows); the Phase-15 raise is the one deliberate, commented edit.
- **Provisional surfaces (do not extend):** the "so" and "like" flanks, the command context guard,
  unit-symbol rendering, decimals, the reversed word+symbol shape — all open questions 1–5, pinned
  only by the spec's rows; a new row needs the founder, not the agent.
