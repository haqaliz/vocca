## Edge cases

- Discover failure (server not executable, spawn refused): `failed(key)` state with the
  bounded key shown; the tab recovers to idle on retry.
- Editing a server whose tools are enabled: enablement rows keep their tool ids (stale-row
  tolerance, store-level).
- Removing a server: its enablement rows are removed with it (the store's save path) —
  pin this in the reducer test.
- The D2 copy appears at the moment of "Discover tools" (which spawns) — the copy pin
  must include the placement (a test that the discover button's section carries the copy).
