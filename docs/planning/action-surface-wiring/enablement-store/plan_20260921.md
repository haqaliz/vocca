## Edge cases

- `action-config.json` absent on first launch: empty config, no file created until the
  first save (the consent-store behaviour).
- Corrupt file: loud log + empty config; the next save overwrites it (recovery).
- Torn write: tmp file must not be visible as a committed ordinal/file name (name
  convention excludes `.tmp` — the audit store's precedent).
- Empty executablePath: refused at save (loud) — a server without a path is not a server.
- The `ActionConfigFileSystem` seam naming: if a boundary lint enumerates
  FileManager-naming surfaces per seam, add the new seam's row to the permit table.
