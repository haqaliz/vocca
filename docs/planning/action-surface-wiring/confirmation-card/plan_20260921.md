## Edge cases

- A card present when a new recording starts: kept (the session-in-flight refusal lives in
  the wiring, not the reducer — the card only appears when arming succeeded).
- Generation mismatch: the wiring's confirm closure is invoked with the stale token → the
  store refuses (no gate call) — the test pins this without the gate.
- Delivered-collapse timer while a card is showing: must not clear the card (a confirm
  needs no timer race).
