## Phase 1 — Fill the cask

- **Goal:** `homebrew/vocca.rb` points at the real release.
- **Files:** `homebrew/vocca.rb` — `version "0.0.0-PLACEHOLDER"` → `version "0.2.0"`;
  `sha256 "000…"` → the release's `SHA256SUMS.txt` value (fetch from the release page /
  `gh release view v0.2.0`); replace the `DO NOT PUBLISH THIS TO THE TAP YET` header block
  (`homebrew/vocca.rb:10-14`) with the ship record: version, sha256, release URL, date. The
  `caveats` stanza and `xattr` instructions stay untouched (still unnotarized).
- **Also verify** the `zap trash:` list against the real surface: list
  `~/Library/Application Support/Vocca` (recovery/, models/, strategies.json, …) and the
  Preferences/Saved-State plists. Correct only if a path is genuinely wrong; record the
  verification.
- **Validation:** `./Scripts/test-with-floor.sh` green (the CaskVersionTests guard from
  version-bump now passes against the real version); `git diff -- homebrew/vocca.rb`
  reviewed.
- **Commit:** `release-distribution: point the cask at the v0.2.0 release`

## Phase 2 — Publish to the tap

- **Goal:** the tap repo carries the cask.
- `haqaliz/homebrew-vocca` currently holds a README and no cask (`STATUS.md:931-933`).
  Clone it (checkout in a temp dir outside the worktree), add `Casks/vocca.rb` mirrored from
  `homebrew/vocca.rb`, commit, push. ⛔ **Checkpoint (founder):** confirm the tap repo
  exists/owned under `haqaliz` and the push is desired — the tap is public and this is the
  first public install surface.
- **Validation:** `gh repo view haqaliz/homebrew-vocca` shows the new file; the mirror is
  byte-identical to the source of truth.

## Phase 3 — Install proof on the founder's machine

- **Goal:** `brew install --cask haqaliz/vocca/vocca` works end to end.
- On the founder's Mac: `brew tap haqaliz/vocca` (if not already tapped) →
  `brew install --cask haqaliz/vocca/vocca` → `xattr -dr com.apple.quarantine
  /Applications/Vocca.app` → `open /Applications/Vocca.app` → menu bar item present →
  `pgrep -x Vocca` returns a pid. If a previous broken install exists, uninstall first
  (`brew uninstall --cask vocca`).
- ⛔ **Checkpoint:** record the exact commands + outputs. Failure is recorded with the exact
  error, never silently worked around (PRD R2) — the quarantine-deletion failure mode
  (`homebrew/vocca.rb:23-26`) gets called out by name if it appears.
- **Validation:** the recorded transcript shows install → launch → pid.

## Edge cases

- **Tap name resolution:** `brew tap haqaliz/vocca` requires the repo to be
  `haqaliz/homebrew-vocca`; if the org/name differs, the tap line changes — record the
  actual tap command used.
- **Homebrew version drift:** the `--no-quarantine` flag is gone (`homebrew/vocca.rb:20-22`)
  — if an error mentions it, that is a stale external doc, not a cask bug; record.
- **Quarantine deletion:** if the app was launched before `xattr`, macOS deleted it silently
  — reinstall and run the xattr line first; record the incident (it validates the caveat's
  existence).
