## 1. Design decisions already taken (do not relitigate)

- **Vocabulary lives in `VoccaCore`** (import-free): everything `VoccaUI` must consume and
  everything the rungs return. The decision function and `LadderInjector` live in
  `VoccaInject` (`ARCHITECTURE.md:100-104` names `VoccaInject/Ladder/`; the `TapHealthPolicy`
  precedent puts adapter-domain decisions in the adapter module, pure, tested over injected
  handles).
- **`TargetContext` has no `AXElementRef`** — `VoccaCore` imports nothing
  (`CoreBoundaryTests.swift:98-116`). The AX element is resolved inside `VoccaInject`.
- **`inject` returns `InjectionResult` always**; `rung == .widgetFailsafe` is a *successful*
  outcome under I1 (`ARCHITECTURE.md:193-199`). `VoccaError.injectionExhausted(attempted:)`
  is declared as the vocabulary case; the ladder does not throw it (the caller-facing
  contract is the result). No `transcriptLost` case ever.
- **The default rung order is pinned at C4**: allowlisted-AX → clipboard → keystroke →
  failsafe. The order is injected (`InjectionStrategyOrder`) so C8's per-app memory slots in
  without touching the decision. `ROADMAP.md:47` ("clipboard-paste primary, AX
  opportunistic") is satisfied because AX is only *first* for allowlisted bundle IDs — the
  default allowlist is empty, so clipboard is the de facto primary.
- **Secure Input**: the decision checks `TargetContext.isSecureInput` (set by the resolver
  at injection time in the adapters aspect) — pure, no Core seam needed. The rung-0 refusal
  happens before any rung is attempted (`attempted: []`).

## 3. The ladder — files to create in `Sources/VoccaInject/Ladder/`

`VoccaInject` becomes an adapter module in this aspect (Phase A below), then:

| File | Exports | Notes |
|---|---|---|
| `InjectionRungStrategy.swift` | `protocol InjectionRungStrategy: Sendable` — `var rung: InjectionRung { get }`, `func tryInject(_ text: String, into target: TargetContext) async -> RungAttempt`; `enum RungAttempt: Sendable, Equatable` — `case succeeded(verified: Bool)`, `case failed` | The seam between the decision and the rung adapters. `verified` carries AX read-back truth; the *decision* interprets (unverified = failure, `ARCHITECTURE.md:400`) |
| `InjectionStrategyOrder.swift` | `protocol InjectionStrategyOrder: Sendable` — `func orderedRungs(for bundleID: String?) -> [InjectionRung]`; `struct DefaultInjectionStrategyOrder` — allowlist check first, then `[accessibility, clipboardPaste, keystrokeSynthesis]`; failsafe is never in the *attempt* list — it is the decision's terminal | C8 slot-in point |
| `InjectionAllowlist.swift` | `protocol InjectionAllowlist: Sendable` — `func contains(bundleID: String) -> Bool`; `struct EmptyInjectionAllowlist` (C4 default) | Seeded list data lands in the adapters aspect |
| `InjectionLadderDecision.swift` | pure function: `decide(text:target:strategyOrder:rungs:[InjectionRung: InjectionRungStrategy]...clock:) -> InjectionResult` | The heart. Decision table below. No I/O, no system API, no clock of its own (`MonotonicClock` injected) |
| `LadderInjector.swift` | `public struct LadderInjector: TextInjector` — injects rung strategies + order + clock; runs the decision; resolves rung handles; **the failsafe terminal** hands `(text, reason)` to an injected `FailsafeHandoff` | One of `TextInjector`'s implementations (the rung strategies are the other surface — seam-discipline, `ARCHITECTURE.md:212`) |
| `FailsafeHandoff.swift` | `protocol FailsafeHandoff: Sendable` — `func hold(_ t: HeldTranscript) async throws` | Implemented by the journal (`failsafe-surface` aspect); at C4 the adapters aspect provides an in-memory conformance for tests/probe |

### The decision table (pinned by tests, written first)

| Input state | Decision |
|---|---|
| `target.isSecureInput == true` | Fail-safe immediately: `rung = .widgetFailsafe`, `attempted = []`, reason `.secureInput` (`ARCHITECTURE.md:382-384`) |
| `target.bundleID == nil` (nothing focused) | Fail-safe immediately: reason `.noFocusedField` (PRODUCT_SPEC.md:113) — before any rung |
| Rung succeeds with `verified: true` (AX) or plain `succeeded` (clipboard/keystroke) | Stop, return result with `rung` = that rung, `attempted` = the prefix trace |
| AX returns `succeeded(verified: false)` | **Counts as failure** — fall through (the silent-lie catch, `ARCHITECTURE.md:400`) |
| Rung returns `failed` | Record in `attempted`, try next rung in order |
| All rungs exhausted | Fail-safe: reason `.exhausted`, `attempted` = full trace |
| A rung is not in the injected strategy set | Skip it (C8's store may demote a rung to absent) |
| Any rung handle is missing from the injected map | Treated as failed (no implicit recovery — the map is the truth) |

`elapsed` is accumulated from the injected `MonotonicClock` (deltas, never a wall clock;
the negative-delta rule from `SessionMachine.tick()` applies).

## 6. Testing strategy

- Unit: the decision table + fault injection (the acceptance), vocabulary shape, holder
  lifecycle, boundary pins — all headless, all CI-runnable.
- Integration: the probe drive (Phase E) is the integration point until the loop wiring
  unit lands.
- Manual: none in this aspect (no system APIs). The adapters aspect carries the smoke
  steps.
- Zero-network: the probe drive is the new default-path exercise; the interposer asserts
  zero connections with the ladder running.
- **Test command:** `Scripts/test-with-floor.sh` — run after every phase; raise the floor
  in the same commit as the new tests.

## 7. Environment & privacy

- No env vars, no services, no network. The whole aspect is local and import-free in Core.
- Privacy: nothing new leaves the box; the transcript never leaves the process in this
  aspect (the journal is the failsafe aspect).

## 8. Edge cases & error handling

| Case | Behaviour |
|---|---|
| `isSecureInput` true | Fail-safe, `attempted: []`, reason `.secureInput` — an honest refusal, never a silent no-op (`PRODUCT_SPEC.md:111`) |
| No focused field (`bundleID == nil`) | Fail-safe, reason `.noFocusedField`, before any rung |
| AX silent lie (`verified: false`) | Counts as failure, falls through — the check that turns R1 into a caught failure |
| Rung missing from strategy map | Treated as failed; no implicit recovery |
| All rungs failed | Fail-safe, `.exhausted`, full `attempted` trace (C8's memory input) |
| Ladder exceeds budget | `elapsed` reports the truth; the ≤100 ms assertion is a suite gate, not a behaviour |
| Holder unavailable at hand-off | `LadderInjector` surfaces the error via the `FailsafeHandoff` throw; the Core contract documents that the journal implementation makes this effectively impossible (I1 floor) |

## 9. Agent execution notes

- **Checkpoints for the integrator:** after Phase B (the reviewed module move — read the
  diff), after Phase C (the fault-injection suite — the aspect's acceptance), after Phase E
  (probe green).
- **Likely iteration:** the exact arities of `decide(...)` and `RungAttempt` — the failing
  tests settle them; do not design them in prose first.
- **Ask before:** changing the decision table's rows, adding a rung, or weakening the
  zero-loss assertion. Everything else is in the plan.
- The `TextInjector` seam's second-implementation story is `LadderInjector` (orchestration)
  + the rung strategies (adapters aspect) — do not add a second fake implementation to
  satisfy seam discipline; the real rungs are that.
