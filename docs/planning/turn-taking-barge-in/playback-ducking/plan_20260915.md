   ("Playback/ # duckable output for barge-in"). So this aspect ships a seam with **one real
   implementation at ship**; that interim state is **recorded, not papered over** (the C9
   first-half discipline). A second real implementation (e.g. a pure-software renderer) is a
   future concern; test doubles do not count as implementations.
6. **The producer→renderer transport already exists.** `AudioRingBuffer` is a preallocated
   lock-free SPSC ring of `Float` (`AudioRingBuffer.swift:17`, `:44`) — exactly one
   producer (the play task) and one consumer (the render block). The capture path's ring is
   a different instance and is byte-for-byte untouched (G5); the SPSC warrant holds per
   ring. Playback never drops a frame: when the ring is full the producer **waits for
   room** (a bounded poll), it does not overrun.
7. **Chunk payloads.** `AudioChunk` names `sampleRate` and `channelCount` but not the bit

   22050 Hz mono; Kokoro's CoreML output is Float32), so the playback adapter interprets
   bytes as Float32 interleaved at `sampleRate × channelCount` and **downmixes to mono by
   arithmetic mean** (the `AudioFormatConverterTests` downmix discipline, including the
   silent-channel-0 killer). A chunk whose format differs from the session's first chunk is
   a **stream failure** (the synthesizers ship uniform-format streams; a differing chunk is
   corruption, not something to guess at).
8. **Time enters through the seam.** `MonotonicClock` (`MonotonicClock.swift:65-68`) is

   real clock at the composition root (the `SessionMachine` precedent); tests move a
   hand-moved clock. A frozen clock must not disable the halt: the wait loop is bounded
   (`SessionWatchdogTests.testAClockThatNeverAdvancesDisablesTheCeilingButNotThePoll` is
   the discipline).
9. **No new dependency, no new network surface.** `AVFAudio`/`Foundation`/`Synchronization`
   are system/stdlib; `AudioRingBuffer` and the seam types are in-repo. The zero-network
   invariant (interposer over `connect(2)`) and the `VoccaNetworkProbe` coverage
   cross-check are untouched by this aspect.

## The pinned seam shape (integrator-review item — see Agent notes)

Four operations, no handle type. Rationale recorded here so the `barge-in-loop` aspect
consumes a frozen contract:

```swift
// Sources/VoccaCore/PlaybackEngine.swift
public protocol PlaybackEngine: Sendable {
    /// Plays `stream` to the output. Returns when every chunk has been rendered to silence
    /// (drained), when ``cancelToSilence()`` halts it, or — throwing — when the stream fails
    /// or the output cannot start. `play` with an empty stream returns without starting the
    /// output. A second `play` while one is active supersedes it (the first is halted).
    func play(_ stream: AsyncThrowingStream<AudioChunk, Error>) async throws

    /// Ramps the output level to the duck target; playback continues. Idempotent; a no-op
    /// when no session is active (it never pre-arms the next session).
    func duck() async

    /// Halts to silence within the barge-in budget: ramps the level down (the duck) and stops.
    /// Idempotent; a no-op when no session is active. Cancel-then-play is safe: the next
    /// `play` renders fully (the `SpeechSynthesizer` twin of "cancel-then-reinvoke is safe").
    func cancelToSilence() async

    /// Releases the output device. Idempotent, synchronous, non-throwing — the
    /// `CaptureGraphSeam.stop()` release contract ("do not return until it is released").
    /// A later `play` reopens.
    func tearDown()
}
```

Why no `PlaybackHandle` (decided, not deferred): the only thing a handle could carry is
completion observation, and the awaited `play` already carries it; a handle adds a type to
the vocabulary the `barge-in-loop` aspect must learn for no gain. `play` returns **after
drain**, not after enqueue — the reply's tail must not still be sounding when the loop goes
back to listening (echo). The seam is `Sendable`; the implementation is
`@unchecked Sendable` with one `Mutex` (the `SystemSynthesizer` precedent,
`SystemSynthesizer.swift:36-44`).

Plain data (N2 — the knob C11 can tune without touching the loop):

```swift
// Sources/VoccaCore/PlaybackLevel.swift
public struct PlaybackLevel: Sendable, Hashable {
    public var duckGain: Double        // 0...1; 0.5 ≈ −6.02 dB (the N2 "−6 dB-ish")
    public var rampDuration: Duration  // > 0; default .milliseconds(20)
    public static let `default` = PlaybackLevel(duckGain: 0.5, rampDuration: .milliseconds(20))
    public var isValid: Bool { duckGain.isFinite && (0...1).contains(duckGain) && rampDuration > .zero }
}
```

`SystemPlayback.init` traps on an invalid level (the `AudioBuffer` "loud by construction"
precedent); `isValid` is the tested predicate.

## Testing strategy

- **The state machine is the headless proof.** Every branch of the contract runs in CI
  over the injected clock and `FakePlaybackOutput`: the pure ramp schedule as a function
  of the clock; the halt at exactly `rampDuration` (and not before); the frozen-clock
  liveness bound; idempotent duck; the no-op out-of-order calls; cancel-then-replay;
  the hammer; stream error; format change; teardown/reopen. The fake is a **ledger** —
  assertions are made against what it recorded (start format, enqueue order, gain
  targets with clock stamps, stop count), never against a call believed to have happened.
- **The pure pieces are tested directly**: `PlaybackLevel.isValid` by near-miss,
  `LevelRamp.gain(at:)` by exact values at t0 / mid / end / beyond, `monoFrames(from:)`
  by the downmix killers including the silent-channel-0 case.
- **The offline manual-rendering tests** execute the real adapter (source node, ring,
  render-block envelope) headlessly — the strongest CI evidence available for the output
  path — with the environmental fallback pinned in Vetted fact 3 and Phase 2 step 4.
- **The lint controls**: the planted violation (both family prefixes, in the shapes a leak
  would use) and the comment-strip control, so "no offenders" cannot be a vacuous green;
  the directory-missing and no-files-scanned guards make measuring nothing a failure.
- **What is deliberately not tested (stated, not hidden):** the realtime device path
  (engine start against real hardware, device-rate conversion, audible click-freedom of
  the envelope, realtime thread discipline under load). SMOKE 132 (`barge-in-loop`) is its
  first real execution; this plan does not add a SMOKE row and does not claim one.

## Environment & privacy

- **Zero network.** No new dependency; `AVFAudio`/`Foundation`/`Synchronization` are
  system/stdlib and were already loaded by `VoccaAudio`. Nothing here hands a URL to
  anything; no model bytes, no downloads, no egress. The zero-network invariant suite and
  the probe coverage cross-check must stay green (run them in the Phase 2 full suite).
- **No audio or text leaves the process.** The seam moves PCM only; it never sees a
  transcript. The output engine starts on the first chunk of a session and stops when the
  session ends — no idle engine, matching the capture doctrine's start-on-demand rule
  (the mic-indicator argument does not apply to output, the discipline does).
- **The capture path is untouched** (G5): a separate `AVAudioEngine` instance, a separate
  ring, no shared state with `AudioCaptureGraph`/`MicrophoneSource`.
- **No user-visible surface** (PRODUCT_SPEC's mic-truthfulness principle by
  construction): nothing constructs `SystemPlayback` in the app this aspect; the
  composition root's recipe and `PROBE-TURN` are `barge-in-loop`'s.

## Edge cases (each has a Phase 1 pin unless marked)

- **Empty stream** — returns without starting the output, never throws (test 8).
- **Stream failure mid-play** — the halt path runs, `play` rethrows the stream's error
  (test 17).
- **A chunk whose format differs from the session's first** — a stream failure, not a
  silent conversion (test 18; the producers ship uniform streams).
- **Duck before play** — a no-op; no state leaks into the next session (test 14).
- **Halt without play** — a no-op, prompt return (test 13).
- **The barge-in hammer** (rapid duck/halt/play) — bounded, stable, last session intact
  (test 16).
- **Cancel-then-replay** — the second stream renders fully (test 15).
- **A frozen clock during the halt** — the bounded poll still halts (test 12).
- **Play while playing** — supersede: the first session is halted, the second renders
  (covered by test 16's sequence; document it in the protocol).
- **Teardown during play / after teardown** — release, idempotent, reopen (test 19).
- **A frame enqueued after the cancel** — prevented by the check-and-enqueue atomicity;
  the fake's `enqueue`-while-stopped is asserted absent (tests 11/15/16).
- **Ring full (producer outpaces the renderer)** — wait for room, never drop (the 3 s
  offline test, or recorded as not-CI-executed if the offline fallback applies).
- **Invalid `PlaybackLevel`** — refused loudly at construction (`isValid` tested; the
  trap documented).
