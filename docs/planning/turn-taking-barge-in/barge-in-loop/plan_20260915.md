## Vetted facts (recorded — do not re-research)

1. **The barge-in signal path is the budget** (`ARCHITECTURE.md:571-578`): VAD fires
   (~30 ms frame) → coordinator receives the interrupt → `synthesizer.cancel()` (≤50 ms, the
   shipped contract) → output ducked and stopped → interrupted reply discarded → capture
   already running, so the interrupting words are **already in the buffer** — capture is
   continuous, never started at interrupt time. The **200 ms gate** (`ROADMAP.md:210`) is the
   whole composed path; headless assertions run over the **injected clock at the contract
   thresholds** (30 + ≤50 + duck ≤20 + margin), and the real number is SMOKE 132 (recorded,
   never gated). O5's note is recorded: the stub's cancel measured 70-90 ms on a loaded CI
   runner — that is why headless assertions assert the *contract* thresholds, not CI wall
   time.
2. **The ≤50 ms cancel contract is consumed, not re-litigated**
   (`Sources/VoccaCore/Speech/SpeechSynthesizer.swift:36-38`): "a barge-in that leaks the
   tail of the utterance is a barge-in that does not work"; `cancel()` is async, safe with
   nothing in flight, and cancel-then-reinvoke is safe. The `PlaybackEngine` seam
   (`playback-ducking`'s pinned four-op shape) contributes `duck()` + `cancelToSilence()`
   with `rampDuration` default **20 ms** (`PlaybackLevel.default`) — a duck, never a click.
3. **The review-gate fixes (binding — founder-approved with the PRD):**
   (1) *"Interrupting audio fully preserved" is **stream continuity*** — contiguous
   fed-frame sequence numbers, no dropped-chunk window across the interrupt boundary,
   asserted over the injected clock; (2) *the reply-end race is pinned in the state
   machine* — user speech onset exactly as the last reply chunk lands is a **NEW utterance
   immediately**, never a dropped first syllable, never a stale commit; (3) *the seam-level
   tests hard-assert the ownership contract* — one consumer at a time, a second consumer is
   refused.
4. **The echo gate** (`ARCHITECTURE.md:573`): a hard gate discarding capture whose energy
   correlates with the synthesizer's output within the playback window, plus known-output
   reference cancellation as the second line. Pure + headless: synthetic overlapped signals
   gate deterministically; **silence during playback never gates**. Open question 4
   (`ARCHITECTURE.md:727`): speakers may need more than reference cancellation on some
   hardware — SMOKE 133's job, never this aspect's claim.
5. **Turn scoring** (`ROADMAP.md:211`, `ARCHITECTURE.md:575`): false cutoffs weighted
   **5× worse** than late commits; ≥95% correct turn commitment on the recorded
   conversational set. The scorer is a pure function; the exact formula is pinned in Phase 4.
   A planted-false-cutoff corpus must **genuinely fail** — a gate that cannot fail proves
   nothing.
6. **The `SessionMachine` precedent** (`Sources/VoccaCore/SessionMachine.swift:41-55`):
   synchronous, **not** `Sendable`, isolation belongs to the owner; everything handed back
   (`SessionEffect`/`SessionOutcome`) is `Sendable` so it can cross. The `TurnTakingLoop`
   follows this shape exactly; the dictation machines are byte-for-byte untouched (the G5
   pin). The machine's own seam-custody words (`:571-577`) — a component which cannot
   classify its own state must fail closed — are the loop's `start()`-refusal doctrine.
7. **The seam signatures this aspect compiles against (frozen by the sibling plans):**
   - `VoiceActivityDetector` (mutating, stateful): `var configuration: VADConfiguration
     { get }`, `mutating func classify(_ frame: AudioBuffer) -> SpeechActivity`

**Files.**

1. `Sources/VoccaCore/TurnTaking/TurnState.swift` — the five cases with the PRD's transition
   doc (`prd.md:136-142`). `Sendable + Equatable`.
2. `Sources/VoccaCore/TurnTaking/TurnEffect.swift` — the seven cases, `Sendable + Equatable`.
   Doc comment: the owner applies effects; `.bargeIn` is defined by the ≤50 ms cancel
   contract (the owner must call `synthesizer.cancel()` within the budget, duck via
   `playback.cancelToSilence()`, and discard the reply — "a barge-in that leaks the tail of
   the utterance is a barge-in that does not work").
3. `Sources/VoccaCore/TurnTaking/EchoGate.swift` — **the hard gate ships here (Phase 2),
   recorded**: the loop's feed path owns the gate's composition (`ARCHITECTURE.md:573`'s
   capture-side filter sits between capture and VAD, which in this design is inside `feed`),
   so the loop cannot ship without the gate's discard decision. Pure struct, stdlib only:
   - `enum EchoGateDecision: Sendable, Equatable { case discard; case accept(samples:
     [Float]?) }` — nil = classify the raw frame.
   - `static func decision(capture: [Float], reference: [Float]) -> EchoGateDecision`:
     1. **Silence floor first:** `rms(capture) < 0.02` → `.accept(nil)` — silence during
        playback **never gates** (and never invokes cancellation).
     2. **Correlation:** `ρ = Σ(c·r) / (√Σc² · √Σr²)` over the trailing `min(c.count,
        r.count)` samples (tail-aligned — the freshest reference; acoustic-latency alignment
        is O3/SMOKE-133 territory, recorded in the doc). Empty/zero-energy reference →
        `.accept(nil)` (the vacuous accept).
     3. `ρ >= 0.90` → `.discard` (a scaled copy of the reference correlates at 1.0 whatever
        the gain — the pure-echo case). `ρ < 0.90` → `.accept(nil)` (Phase 3 adds the
        residue path).
   - Doc comment pins the numbers and the margin doctrine: every synthetic fixture row
     carries ≥0.05 margin against ρ = 0.90 and the 0.02 floor; boundary equality is Float-ulp
     territory and deliberately not pinned.
4. `Sources/VoccaCore/TurnTaking/TurnTakingLoop.swift` — the coordinator, the
   `SessionMachine` shape exactly (synchronous, not `Sendable`, `public final class`,
   isolation belongs to the capture feed's owner — documented, never an actor):
   - Injected at init: `var vad: any VoiceActivityDetector` (the owner-holds-`var` shape the
     voice-detection plan blessed), `let turnDetector: any TurnDetector`, `let clock: any
     MonotonicClock`, `let gate: EchoGate` (pure value), `let onEffect: @escaping
     (TurnEffect) -> Void`, `let onStateChange: @escaping (TurnState) -> Void` (N1 — present
     in the loop, wired by nothing).
   - Internal state: `state`, `fedFrameCount`, `gatedFrameCount` (public private(set)),
     utterance accumulator (`[AudioBuffer]` — speech frames only), pause accumulator
     (samples since the last speech frame), the pending speech seed (accepted speech frames
     seen during `.playing`), the playback window (`(start, end)` from `clock.now`, opened
     by `reportPlaybackStarted()`, closed by `reportPlaybackEnded()`), and the trailing
     reference buffer (`[Float]`, ≤ 16 000 samples ≈ 1 s, fed by `reportPlaybackChunk`).
   - **The transitions (each a private func; the public methods are thin funnels):**
     - `start()`: `.idle` → `.listening`, emit `.started`. **Second start while not `.idle`
       is refused** (state unchanged, nothing emitted) — the ownership pin, the
       `isOpeningTheMicrophone` doctrine ("a component which cannot classify its own state
       must fail closed"). `stop()`: any state → `.idle`, emit `.stopped`; capture teardown
       is the owner's (the loop holds no mic seam).
     - `feed(_ frame:)`: `.idle` → refused (no-op, documented — the machine does not
       fabricate decisions for frames it did not ask for). Otherwise `fedFrameCount += 1`
       and:
       - `.listening`: VAD classify → `.speech` evidence flips (hysteresis is the VAD's own)
         → `.uttering`, emit `.speechBegan`, accumulate the frame; `.silence` → nothing.
       - `.uttering`: VAD `.speech` → **clear the pause accumulator**, accumulate the
         frame (a speech frame restarts the candidate pause — the veto-tolerance rule).
         VAD `.silence` → extend the pause accumulator and call
         `turnDetector.decide(pause:, utterance:)` (the utterance = the accumulated speech
         frames concatenated at 16 kHz) **on every silence frame** (below threshold keep
         listening — R3's scored decision, not a timer); first `.commit` →
         `.committed`, emit `.turnCommitted(utterance: [AudioBuffer])` with exactly the
         speech frames (never the pause frames); accumulators freeze until the next
         `.speechBegan`.
       - `.committed`: VAD `.speech` → a **fresh** `.uttering` (accumulators reset — the
         owner's pending reply is superseded; the machine reports `.speechBegan`, the
         "hold the reply while the user talks" policy is C11's, recorded in the doc).
       - `.playing`: **gate first.** Window open AND reference non-empty →
         `gate.decision(capture: frame.samples, reference: trailingReference)`;
         `.discard` → `gatedFrameCount += 1`, return (frame never classified — echo zero).
         `.accept(let samples)` → VAD over `samples ?? frame.samples`. VAD `.speech` →
         **barge-in**: append the accepted speech frames seen during this `.playing`
         window (the seed) plus this frame to the new utterance accumulator, transition
         `.playing → .uttering`, emit `.bargeIn` exactly once per reply, and the new
         utterance is immediately accumulating — **the interrupting words are preserved
         from the first syllable** (the review-gate fix; the PRD's "→ listening" is the
         continuity fact — capture never stopped — while the machine's utterance state is
         `.uttering`, recorded in the doc). VAD `.silence` → the frame joins the seed
         buffer (silence during playback never gates and never barge-ins).
       - **`scheduleReply(_ text:)`:** `.committed` or `.listening` → `.playing`, emit
         `.speakReply(text:)`, reset accumulators; `.uttering` → refused (never speak over
         the user); `.playing` → refused (a second reply is a driver bug — no double
         speech, recorded); `.idle` → refused.
     - `reportPlaybackStarted()`: open the window at `clock.now` (only while `.playing`;
       else no-op). `reportPlaybackChunk(_:)`: decode the chunk (Float32
       little-endian bytes → frames, mono by arithmetic mean, decimated to 16 kHz by
       nearest-neighbour — pure Float math; a chunk rate `< 16000` traps loudly, the
       `AudioBuffer` "loud by construction" precedent — the producers ship uniform-format
       streams) and append to the trailing reference. `reportPlaybackEnded()`: close the
       window; `.playing → .listening` (the natural end; no stale accumulator). A
       barge-in that already left `.playing` makes this a no-op.
     - `reportCaptureFailed()`: any state → `.idle`, emit `.captureFailed`. **No trap —

**Files.**

1. `Sources/VoccaCore/TurnTaking/EchoGate.swift` — **amended** (the file exists): add
   - `static func residue(capture: [Float], reference: [Float], gain: Double) -> [Float]` —
     `capture − gain·reference`, elementwise (the known-output reference cancellation;
     `gain` is the loop's injected estimate of the echo path gain, default 0.90).
   - `decision`'s `ρ < 0.90` branch completes: compute the residue, and accept it as the
     classification signal **iff both** `rms(residue) >= 0.02` (the EnergyVAD offset twin —
     a silence-floor residue is not speech) **and** `rms(residue) >= 0.15 · rms(capture)`

     gain-mismatched echo (echo at 0.30 against α = 0.90) leaves a residue of −0.60·r, which

**The clock-injected budget tests** — the injected clock is the only time source; the

measurement is why).

**The corpus fixtures** — the JSON format pinned in Phase 4; the harness renders and

- **Zero network, zero model bytes in CI.** The loop/gate/scorer are stdlib-only in a
  module that imports nothing; the probe's turn drive runs the fallback implementations only
  (G6 — no SDK, no artifact, no URL; the `sdk-adapters` real adapters provision through the

  covers the whole package and stays green.
- **Mic-truthfulness by construction** (`PRODUCT_SPEC.md:11`): nothing wires the loop into

  the `.started`/`.stopped` effects) — no silent listening state can exist from this

- **The realtime conversation is executed by nothing in CI** (O4, the tap-adapter

  behavior not numbers, its halt/echo numbers are recorded-never-gated (SMOKE 132/133's

- **No egress, no secrets**: no URL is constructed anywhere in this aspect; the corpus
  fixtures are committed text; the digests pin the dictation path, they do not move it.

## Edge cases (each has a pinned test)

- **The reply-end race** (review-gate fix 2): both orderings at one injected instant — the
  frame is retained, a new utterance starts immediately, no stale commit (T14 + the
  composed row).
- **Barge-in during the duck**: one `.bargeIn` per reply, no double-cancel; frames during
  the halt are classified normally (T19).
- **Barge-in during the final chunk**: the cancel contract consumes the tail — never a
  leaked tail (T20; the seam contract is the owner's to honour, asserted in the composed
  row).
- **EOU veto after a long pause** (late-commit tolerance): the pause accumulator resets on
  every speech frame; a vetoed pause never becomes a cutoff; the utterance extends (T6).
- **Silence-only sessions**: never commits, never gates, quiescent (T22).
- **Capture failure mid-turn** (the trap precedent): no trap — the loop owes no transcript
  hand-over; `.captureFailed`, state entered, fresh start afterwards (T18). The trap is
  deliberately **not** inherited, and the doc says why.
- **The interrupt-window boundary** (review-gate fix 1): contiguous fed-frame counts,
  no dropped-chunk window, the barge-in frame is the new utterance's first frame (T15).
- **Cancel-then-reinvoke hammering** (the C9 contract): rapid speak/barge-in cycles stay
  stable; cancel-then-reinvoke is safe by the synthesizer's own contract — consumed, never
  re-litigated (T21).
- **No-reference window**: vacuous `.accept` — barge-in works before any chunk is reported
  (the honest un-gated path, pinned in Phase 1).
- **Silence during playback**: never gated, even with a hot reference (the PRD pin, T11 and
  the gate's unit row).
- **Reference format**: a chunk below 16 kHz traps loudly (the producers ship uniform
  streams); a chunk whose decode fails is a stream failure the owner reports — the loop
  never guesses.
- **`scheduleReply` out of order**: refused in `.uttering` (never speak over the user),
  refused in `.playing` (no double speech), refused in `.idle`.
- **Speech in `.committed`**: a fresh utterance; the owner's pending reply is superseded
  (the machine reports the state change — the hold-the-reply policy is C11's, recorded).
- **Double stop / feed after stop**: no-ops, documented; the machine fails closed, never
  fabricates decisions.
- **Overwhelming mixed echo** (ρ ≥ 0.90): the deterministic gate discards — the honest
  limit, recorded in the gate's doc, SMOKE 133's question (O3), never silently "improved".
