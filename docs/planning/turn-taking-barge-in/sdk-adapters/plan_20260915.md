## The pinned adapter design (read before Phase 1)

**The conversion question — resolved: there is no conversion.** The seam's carrier
`AudioBuffer.samples` is already `[Float]` **16 kHz mono** (`Sources/VoccaCore/AudioBuffer.swift:36-88`,
asserted at init; the voice-detection plan's own carrier fact), and the SDK's
`processStreamingChunk(_:state:config:)` takes `[Float]` at `VadManager.sampleRate` (16000).
The instruction's Int16 concern does not arise. The `AudioFormatConverter` precedent lives in
`VoccaAudio` and is **not needed**: `VoccaASR` cannot import `VoccaAudio`, and nothing in this
aspect requires it. **The adapter's whole job is: (a) accumulate frames to the SDK's 4096-sample
chunk boundary, (b) map the seam's plain-data config onto the SDK's plain-data config, (c)
bridge the seam's synchronous `classify` onto the SDK actor's async chunk call, (d) map the
SDK's hysteresis events onto the seam's `SpeechActivity`.** A test-local resampler exists only
in the env-gated suite's fixture construction (the TTS renders at ~22050 Hz; see Testing
strategy) — a test artifact, never production code.

**The adapter's shape (`Sources/VoccaASR/VAD/SileroVAD.swift`, one file per seam, the H8b
family's second permitted file):**

```swift
public struct SileroVADConfiguration: Sendable, Hashable {
    public var speechThreshold: Float          // = VadConfig.defaultThreshold (0.85) — SDK default, pinned by test
    public var negativeThresholdOffset: Float  // = VadSegmentationConfig default (0.15)
    public var speechPadding: Double           // = VadSegmentationConfig default (0.1)
    public init(speechThreshold: Float = 0.85, negativeThresholdOffset: Float = 0.15,
                speechPadding: Double = 0.1)
}

/// The seam/SDK boundary mapping, as a pure function over plain data — the only part of the
/// adapter headless CI can execute.
public struct SileroVADDerivedConfig: Sendable, Hashable {
    public let speechThreshold: Float
    public let negativeThresholdOffset: Float
    public let speechPadding: Double
    public let minSpeechDuration: Double
    public let minSilenceDuration: Double
}

public final class SileroVAD: VoiceActivityDetector {   // Sendable, the KokoroEngine warrant shape
    public let configuration: VADConfiguration
    public init(configuration: VADConfiguration, modelDirectory: URL,
                sdkConfiguration: SileroVADConfiguration = .init())   // pure: stores plain data, touches nothing
    public func classify(_ frame: AudioBuffer) -> SpeechActivity     // synchronous, blocks on the SDK actor bridge
    public var loadFailureDescription: String?                       // the clear-error surface; nil until a load attempt failed
    public static func derivedConfig(from configuration: VADConfiguration,
                                     sdk: SileroVADConfiguration) -> SileroVADDerivedConfig
    public static func chunked(_ accumulator: [Float], frame: AudioBuffer,
                               chunkSize: Int = 4096) -> (chunks: [[Float]], remainder: [Float])
}
```

- **Init is pure** (the KokoroEngine precedent, `KokoroEngine.swift:52-91`): stores the config,
  the model directory as plain data, and the SDK config. The `MLModel` load and the
  `VadManager(config:vadModel:)` construction are **lazy**, on the first classify that
  completes a 4096-sample chunk. This is what makes the probe's construct leg possible: no
  model bytes, no network, nothing touched.
- **`classify`** (under one `Mutex`, the SystemSynthesizer/KokoroEngine warrant — all mutable
  state in `Mutex<SileroVADState>`: `accumulator: [Float]`, `streamState: VadStreamState?`,
  `manager: VadManager?`, `currentActivity: SpeechActivity = .silence`, `loadFailure: String?`):
  1. Empty frame (`samples.isEmpty`) → return `currentActivity` — **no model touch** (the
     voice-detection empty-frame rule, made load-bearing for the probe).
  2. `chunked(accumulator, frame)` → zero or more exact-4096 chunks + remainder. No completed
     chunk → return `currentActivity` — **no model touch** (the real adapter's decision
     granularity is the model's 256 ms chunk; recorded).
  3. First completed chunk: ensure `ModelHub.offlineMode = true` (the Parakeet precedent), load
     `MLModel(contentsOf: modelDirectory.appendingPathComponent(ModelNames.VAD.sileroVadFile))`,
     construct `VadManager(config: VadConfig(defaultThreshold: sdk.speechThreshold),
     vadModel: model)`. On failure: record `loadFailureDescription`, return `.silence` —
     **memoized** (the Kokoro memoized-failure precedent: the same recorded error fails every
     subsequent classify; never a retry, never a download).
  4. Per chunk, bridge `manager.processStreamingChunk(chunk, state: streamState ??
     .initial(), config: segmentationConfig)` (the sync→actor bridge below); store the returned
     state; map the event: `.speechStart` → `.speech`, `.speechEnd` → `.silence`, `nil` → keep
     `currentActivity`.
- **The sync→actor bridge** (the seam is synchronous by contract; the SDK is an actor):
  `DispatchSemaphore` + a `Mutex` result box + `Task { do { box = try await
  manager.processStreamingChunk(...) } catch { box = failure }; semaphore.signal() }`, then
  `semaphore.wait()` and read the box once. Written once by the Task, read once after the
  signal — the `SpeechDriveBox` discipline (`SpeechDrive.swift:88-90`) expressed with the
  house's `Mutex` (no `@unchecked` needed for the box). Doc comment records the cost honestly:
  `classify` blocks its caller for the model's per-chunk processing; the seam and the loop are
  synchronous by design, and the env-gated suite measures and records `VAD-CLASSIFY-LATENCY`
  (recorded, never gated — the 200 ms budget decomposition is the barge-in-loop aspect's).
- **Config mapping (F2 applied)** — `derivedConfig(from:sdk:)` is the pure, headless-testable
  half: `minSilenceDuration = configuration.minimumSilence`,
  `minSpeechDuration = configuration.minimumSpeech`,
  `speechThreshold = sdk.speechThreshold`, `negativeThresholdOffset = sdk.negativeThresholdOffset`,
  `speechPadding = sdk.speechPadding`. The adapter builds the SDK configs from it at the
  boundary (`VadConfig`, `VadSegmentationConfig` with the remaining fields at SDK defaults).
  Recorded nuances (the doc comment carries them): `onsetRMS`/`offsetRMS` are energy-domain
  evidence levels with **no Silero analogue** — the model's probability thresholds
  (`speechThreshold` / `negativeThresholdOffset`) are the real hysteresis pair; the SDK's
  streaming state machine flips onset on the first above-threshold chunk (no min-speech hold in
  that path), so the real adapter's onset is SDK-timed — the adapter does NOT re-implement the
  seam's hold on top of the SDK's state machine (double state machines would drift, and a
  hold would delay the barge-in-critical onset). The env-gated rows carry margins accordingly.
- **The EOU half** — decided at the Phase 2 checkpoint (both branches, with record wording, in
  Agent notes). Branch B (prescribed): no `EOU/ParakeetEOU.swift` exists; `ParakeetEOU` is a
  recorded-pending conformance; `SilenceThresholdDetector` is the shipped `TurnDetector`
  implementation. Branch A (only if the worktree's checkout contradicts F3 and a standalone
  scored EOU surface exists): the adapter conforms under the recorded semantic correction, with
  the EOU artifacts' provisioning recorded as a future unit's debt.

## Testing strategy

- **Written first (Phase 1, RED):** `SileroVADAdapterTests` — the only headless suite for the
  adapter. Its rows pin the three things CI can reach: the pure init (the probe contract), the
  short-circuit rules (empty frame, sub-chunk frame — no model touch, observable precisely
  because the model is absent), and the two pure functions (`derivedConfig`, `chunked`).
- **Mapping round-trips:** `chunked` pins that `frame.samples` reach the SDK boundary
  sample-for-sample (the identity conversion, `AudioBuffer.swift:36-45` ↔ `VadManager.swift:22-26`),
  chunked at exactly 4096, remainder kept, `missingSampleCount` never affecting the decision.
  `derivedConfig` pins the seam→SDK config mapping field-for-field, with the SDK-defaults row
  (0.85 / 0.15 / 0.1) comparing against the SDK's own `VadConfig.default` and
  `VadSegmentationConfig()` so neither side can drift.
- **Threshold/classify mapping (SDK hysteresis → `VADConfiguration`):** the SDK's hysteresis
  pair is `speechThreshold` (onset) / `negativeThresholdOffset` (offset, via
  `effectiveNegativeThreshold`); the seam's `minimumSilence` maps onto
  `minSilenceDuration`; `minimumSpeech` rides into `minSpeechDuration` with the recorded
  nuance (the streaming path flips onset on the first above-threshold chunk — the adapter does
  not re-implement the hold); `onsetRMS`/`offsetRMS` are recorded as no-Silero-analogue. The
  env-gated rows carry margins against all of it; nothing is asserted at Float equality.
- **The EOU adapter's honest state:** Branch B (prescribed) — no adapter exists; the record

- **The env-gated real rows:** Row 1 asserts only "classifies a speech fixture as speech and
  silence as silence" — no WER-style claims, no timing claims; Row 2 is a measured-and-recorded
  latency line, never gated. Both skip visibly in CI (two-variable gate) and count as executed.
- **The lint controls:** the planted-violation control gains the VAD/EOU/ModelNames/MLModel
  names (the leading-word lesson: `StreamingEouAsrManager` is caught by its own prefix — the

## Environment & privacy

- **Zero network at runtime** (the permanent release blocker). `swift package resolve` at plan
  time and dependency fetch at CI build time are not app code — fine.
- **No URL is ever handed to any SDK surface** (the port-downloader-suppression pin precedent):
  the adapter calls only the pre-loaded init `VadManager(config:vadModel:)`; the SDK's
  directory/download inits (`init(config:modelDirectory:)`, `init(config:progressHandler:)`,
  `loadModels(to:)`) are never reachable from our code, and `ModelHub.offlineMode = true` is set
  at adapter construction so even a hypothetical miss throws `networkDisabled` instead of
  egressing. The model directory URL goes only to `MLModel(contentsOf:)` — a local file read.
- The staging path is injected as **plain data** from the composition root / env-gated suite;
  the adapter never resolves a store path, never touches the C2 store (that is
  `kokoro-binding`'s store integration; the silero store integration is a future unit's —
  recorded), and never runs inside `AppBootstrap.configure` (the probe contract).
- The probe's settle window and interposer cover the new construct leg: the drive constructs the
  adapter over a fresh empty temp dir and classifies an empty frame — no model bytes, no
  download path, no network name reachable. `VadManager` is not even constructed.
- The env-gated suite's fixture renders speech locally (AVSpeechSynthesizer) — no fixture bytes
  are committed, no network is touched; the model bytes are read from the provisioned directory
  only.
- `Package.resolved` is gitignored; the resolved revision (0.15.5) is a recorded fact, not a
  committed pin.

## Edge cases

- **Missing model dir** → pure init succeeds (the probe contract); the first chunk-completing
  `classify` records a **clear error** (`loadFailureDescription` names the expected model path)
  and returns `.silence` — never a silent fallback to the SDK's download path (the only inits
  reachable are the pre-loaded one), never a fabricated speech decision.
- **Stale model dir** (present but corrupt, renamed, or a half-extracted `.mlmodelc`) → the
  `MLModel(contentsOf:)` load throws → the same memoized failure path; no re-download, no
  retry-per-frame (a retry policy is the composition root's concern, recorded). The
  provisioning truth is the env-gated digest row, not the adapter.
- **Empty frames** → no evidence, no accumulation, no model touch, current state retained (the
  probe's empty-frame pin depends on this).
- **Sub-chunk frames** → current state (the real decision granularity is the model's 256 ms
  chunk — recorded in the adapter's doc comment; the seam's per-frame vocabulary is served at
  that granularity, and the loop's barge-in path runs on the continuous capture stream where
  chunks complete every 256 ms).
- **The EOU-integrated-manager reality** → Branch B's verdict: the seam's scored pause decision
  has no standalone SDK surface; a "conformance" that fed the pause to the model as silence
  would be a bare silence timer with a model debounce — the exact shape the seam's doctrine
  rejects — and a decode-the-utterance variant would ignore the pause argument, score a boolean
  (the SDK exposes no probability), need unprovisioned artifacts, and cost a full streaming
  decode per decision. Recorded pending, amended by a future aspect; never fabricated.
- **Engine attribution** → the seams never name an engine (`VoiceActivityDetector` /
  `TurnDetector` carry no identity — the voice-detection plan's pin; if the loop needs
  attribution it adds it in `barge-in-loop`, recorded). The adapter's `SileroVAD` name is
  confined to its one file by the family lint; callers cannot branch on it.
- **Beta-status SDK doc comment** (F1) → recorded as an adapter risk note, not a blocker.
- **0.x version drift** → a silent 0.16+ resolve (0.x: minor is breaking) surfaces in the family
  lint (renamed SDK types), the adapter suite, and the vetting pin family — the kokoro
  precedent, recorded.
- **Float equality at boundaries** → deliberately not tested headlessly (the model's threshold
  semantics are its own; the env-gated rows carry margin; the derivation tests compare exact
  plain-data fields, which is exact by construction).
