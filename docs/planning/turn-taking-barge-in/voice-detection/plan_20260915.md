## Phase 2 — GREEN: the seams and the two fallback implementations

**Goal.** The four production files under `Sources/VoccaCore/` make every Phase-1 test green.
The signatures pinned here are the contract the `sdk-adapters` and `barge-in-loop` aspects
compile against — they are final after this phase.

**Files:**

1. `Sources/VoccaCore/VoiceDetection/SpeechActivity.swift` — the enum. Doc comment names the
   seam's contract and its two implementations.
2. `Sources/VoccaCore/VoiceDetection/VADConfiguration.swift` — the plain-data config:
   `onsetRMS: Float` (≥ → speech evidence), `offsetRMS: Float` (< → silence evidence),
   `minimumSpeech: Double` (seconds of continuous speech evidence to flip silence→speech),
   `minimumSilence: Double` (seconds of continuous silence evidence to flip speech→silence).
   `precondition` pins: `onsetRMS > offsetRMS`, `onsetRMS > 0`, `offsetRMS >= 0`,
   `minimumSpeech > 0`, `minimumSilence > 0`. `Sendable + Hashable`.
3. `Sources/VoccaCore/VoiceDetection/VoiceActivityDetector.swift` — the protocol:
   `var configuration: VADConfiguration { get }` and `mutating func classify(_ frame:
   AudioBuffer) -> SpeechActivity`. Doc comment pins the contract: synchronous (no actor hop
   on the per-frame path), the decision is over the present samples only, callers never
   branch on implementation.
4. `Sources/VoccaCore/VoiceDetection/EnergyVAD.swift` — the fallback, a `struct` conforming to
   the seam:
   - `rms` = `sqrt(mean(samples²))` via `Float.squareRoot()` — stdlib only.
   - Evidence rules: `rms >= onsetRMS` → speech evidence; `rms < offsetRMS` → silence
     evidence; `offsetRMS <= rms < onsetRMS` → dead zone, no evidence accumulates.
   - Hold times in **samples**, converted from the config at init
     (`Int((seconds * 16_000).rounded())`) — duration-based, so flips are chunk-shape-
     invariant. A flip resets both accumulators. Initial state: `.silence`.
   - Empty frame: no evidence, no accumulation, returns the current state.
   - `mutating func classify` — a struct with mutating state is `Sendable` by construction
     under strict concurrency (no `@unchecked`, the house's documented aversion —
     `StubSynthesizer`'s doc at `SpeechSynthesizerSeamTests.swift:196-199`). The owner holds
     `var vad: any VoiceActivityDetector`; a future class adapter satisfies a `mutating`
     requirement vacuously.
5. `Sources/VoccaCore/TurnDetection/TurnCommitment.swift` — the enum.
6. `Sources/VoccaCore/TurnDetection/TurnScore.swift` — the struct (`score: Double`,
   `commitment: TurnCommitment`). Doc: the score is the implementation's P(user-finished)
   proxy; the 5×-weighted harness consumes `commitment`.
7. `Sources/VoccaCore/TurnDetection/SilenceThresholdConfiguration.swift` — the plain-data
   config: `commitAfterPause: Double` (seconds; pause ≥ commits, inclusive) and
   `minimumUtteranceDuration: Double` (seconds; an utterance below this never commits).
   Preconditions: both `> 0`. `Sendable + Hashable`.
8. `Sources/VoccaCore/TurnDetection/TurnDetector.swift` — the protocol:
   `func decide(_ pause: AudioBuffer, utterance: AudioBuffer) -> TurnScore`. Synchronous,
   `Sendable`, stateless-by-signature (the decision is over the two buffers passed in; the
   real EOU adapter's internal history is its own business). Doc comment pins: below
   threshold keep listening, above threshold commit; the seam never names an engine.
9. `Sources/VoccaCore/TurnDetection/SilenceThresholdDetector.swift` — the fallback:
   - `pauseDuration = pause.audioDuration`; `utteranceDuration = utterance.audioDuration`
     (both `Double`, samples ÷ 16 000 — exact for the fixture durations, including 0.5 s).
   - Guard: `utteranceDuration < minimumUtteranceDuration` → score `0`, `.keepListening`.
     This is what makes it **not a bare silence timer** in a headless-testable way.
   - Otherwise `score = pauseDuration / commitAfterPause` and
     `commitment = pauseDuration >= commitAfterPause ? .commit : .keepListening`.
   - Doc pins the semantics: the guard is **duration-only** (speech-existence is the
     caller's/loop's responsibility — the loop only calls `decide` after VAD speech), the
     commit boundary is inclusive, and the real EOU (sdk-adapters) replaces this score.

**Why these signature choices (pin the reasoning in the seam doc comments):**

- **Synchronous, not async.** The barge-in loop is synchronous and owner-isolated (the
  `SessionMachine` precedent, `SessionMachine.swift:41-55`). VAD runs per frame on the
  capture path — a 30 ms frame decision cannot afford an actor hop; `TurnDetector` runs once
  per candidate pause, at a decision point, not over a stream. The ≤50 ms cancel contract is
  the TTS seam's and stays async — not re-litigated. If the SDK forces an async adapter
  surface, that is the `sdk-adapters` aspect's problem at its seam, not this one's.
- **`AudioBuffer` as the frame carrier, not a samples view.** The loop already holds
  `AudioBuffer` chunks; it carries rate (asserted 16 kHz) and the completeness link; it is
  `Sendable + Hashable`. A raw `[Float]` view would drop all three.
- **`mutating` on the VAD seam only.** Hysteresis (S1) is inherently stateful; a struct keeps
  it `Sendable` honestly. `TurnDetector` needs no state by signature.
- **No identity on either seam.** They answer yes/no questions; attribution lives on the
  ASR/TTS seams. If the loop needs attribution it can add it in `barge-in-loop` — recorded,
  not added (see Agent notes).

## Edge cases

- **Empty chunks** → `.silence`-state retention: no evidence, no accumulation, no flip.
  Pinned for both the empty frame and the empty pause/utterance.
- **`missingSampleCount > 0`** → the decision is over the present samples only; a buffer
  with `N` missing samples classifies identically to the same samples with `0`
  (pinned by a same-samples/different-missing-count test). Completeness is the ASR seam's
  concern (`AudioBuffer.swift:50-58`), not VAD's.
- **All-silence runs** → silence throughout; absence of evidence never flips.
- **Constant-amplitude runs** → stable classification at the configured level; the
  `constant-at-margin` row pins it. **Boundary equality is Float-ulp territory and is
  deliberately not pinned** — the documented semantics are `>= onset` evidence, `< offset`
  silence evidence, `[offset, onset)` dead zone, and every fixture carries ≥ 10% margin.
- **Threshold hysteresis (onset vs offset)** → two levels plus hold times; the dead zone
  freezes evidence accumulation (no drift toward either state), pinned by
  `onset-offset-hysteresis`.
- **Chunk-size invariance** → evidence accumulates in samples (hold times converted from
  seconds at init), so any chunking of the same waveform flips at the same cumulative sample
  count. Pinned by a split-vs-merged replay test: same total samples as one chunk vs four,
  record the cumulative sample count at the first `.speech` flip — equal.
- **Non-finite samples** → producer-bug territory (the producer's -1.0…1.0 contract,
  `AudioBuffer.swift:43-45`); a NaN/±inf RMS satisfies neither comparison, falls in the dead
  zone, and the state is retained. Pinned once so the behavior is explicit, not accidental.
- **Oversize frames** → capture chunk size is whatever the source yields; duration-based
  hold times make flips chunk-shape-independent (the invariance test's other half).
- **Duration-only guard semantics** → the fallback commits on a silent-but-long enough
  utterance with a long pause; pinned by `duration-guard-only` with the doc comment saying
