# Implementation Plan: provision-and-verify

**Date:** 2026-09-01 · **Feature:** p2-gate-measurement · **Spec:** `docs/planning/p2-gate-measurement/provision-and-verify/spec.md`

## Context for the executing agent

This is a Swift 6 package (not Python). The suite command is `Scripts/test-with-floor.sh`
(floor 1731); filters use `swift test --filter <Class>`. Real-engine tests are env-gated
and executed by nothing in CI — visible `XCTSkip` is the CI state, and the skip is the
tell-tale that the gate is unset. The founder's machine is the only execution
environment. All work happens in the worktree
`.claude/worktrees/feat-p2-gate-measurement` on branch `feat/p2-gate-measurement/aliz`.

## Goal

Provision real model bytes for both engines into the `ModelStore` layout and run the
manifest verification (SMOKE step 102) for the first time. Fix any digest mismatch
test-first.

## Prerequisites

- Founder's machine has the model artifacts (Parakeet: 4 `.mlmodelc` + `config.json` +
  parakeet_vocab; whisper: `ggml-large-v3-turbo.bin`, `-q5_0.bin`) downloaded per the
  manifests; disk has ~2.7 GB free. **If the artifacts are absent, stop and ask the
  founder where they are** — do not download anything.
- `VOCCA_MODEL_DIR` is not set in the shell.

## Phase 1 — Provision both engines

- **Commands:**
  - `Scripts/provision-asr-fixtures.sh <path-to-parakeet-artifacts> <path-to-whisper-artifacts>` — read the script's usage first (`--help`); it writes artifacts under `<root>/<engineID>/<version>[/<sdkDirectory>]`, touches the `verified` marker, writes the SHA-256 manifest, and prints `VOCCA_MODEL_DIR=<version_dir>`.
  - Record the printed path — every later run uses it.
- **Files to create/modify:** none in the repo unless a digest mismatch is found (Phase 2).
- **Validation:** the script exits 0; the printed `VOCCA_MODEL_DIR` path exists and
  contains the verified marker.
- **Commit message:** none yet (no code change unless Phase 2 fires).

## Phase 2 — Manifest verification (SMOKE step 102)

- **Command:**
  - `VOCCA_MODEL_DIR=<printed path> Scripts/test-with-floor.sh --filter ManifestDigestVerificationTests`
- **Expected:** skip lifted, all shipped manifests verify against provisioned bytes; the
  run names any unprovisioned tier.
- **On digest mismatch (expected enough to be planned for):**
  1. RED — write the failing assertion as the regression test (the manifest's wrong
     digest vs the actual bytes).
  2. Fix the manifest entry in `Sources/VoccaASR/Models/Manifests/<engineID>.json` with
     the real SHA-256 + byte count from the provisioning script's output.
  3. GREEN — full suite via `Scripts/test-with-floor.sh` (floor 1731 holds).
  4. Record the provenance in the manifest file's commit message and in the aspect's
     smoke rows (per `STATUS.md:820-825`'s open item: no digest may claim "verified"
     without a recorded run).
- **Commit message (only if a digest was wrong):** `correct the whisper/parakeet manifest digests against provisioned bytes (SMOKE 102 first run)`

## Phase 3 — Record

- Update the SMOKE checklist rows for step 102 (and step 17/18 provisioning rows) with
  the outcome, following the house convention (pass / "not performed" with reason —
  never an invented criterion). Commit:
  `record the first manifest-verification run (p2-gate-measurement aspect 1)`

## Testing strategy

- No new unit tests unless a defect is found (then RED→GREEN as above).
- The regression bar is the floor: 1731.

## Environment & privacy

- Env: `VOCCA_MODEL_DIR` set per-run only, never exported globally in the shell.
- Local-first: model bytes stay on the machine; nothing leaves it; the zero-network
  invariant is untouched (no network call happens in this aspect at all).

## Edge cases

- Script path/usage differences: read `--help` first.
- A tier's artifacts missing (e.g. q5_0): the verification run names it; record as
  skipped-with-reason, ask the founder whether to defer that tier.
- `VOCCA_MODEL_DIR` already set in the environment: unset it in the run's shell to avoid
  pointing at a stale path.

## Agent execution notes

- Checkpoint for the founder: after Phase 1, confirm the printed `VOCCA_MODEL_DIR`
  matches expectations before the verification run.
- Ask before downloading anything — provisioning is founder-owned; the script only
  stages what the founder provides.
