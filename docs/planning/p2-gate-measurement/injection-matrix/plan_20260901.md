## Testing strategy

- Regression tests only for fixed defects; the floor is the bar.
- The 7-day re-probe window is provisional — step 90's observation is recorded, never
  gated (`tolerances_20260810.md`-style note in the smoke rows).

## Environment & privacy

- No env vars; zero network; strategies.json is local app-support data, and its
  deletion/reset is the point of the fresh-memory runs.

## Edge cases

- A denied Automation grant for a specific app: VOID row (the sentinel), recorded, not
  a failure.
- Slack/1Password absent on the founder's machine: skipped rows with the reason; the
  guessed ids stay guessed until a machine with them installed runs the verification.
- Google Docs in Chrome: bundle id is `com.google.Chrome` (no `com.google.docs`
  exists) — the seeded entry is the host app, by design.
