## Context for the executing agent

Swift 6 package; suite via `Scripts/test-with-floor.sh` (floor 1731). This aspect is the
loop's **first real execution** — the founder performs the gestures on the machine; the
agent drives the runs, records rows, and fixes defects test-first. The steps are

## Goal

with the shipped reason); every surfaced defect fixed RED→GREEN; day 1 of the 7-day

## Phase 1 — Steps 62–68, in order

For each step, the founder performs the gesture from the checklist; the agent records
the outcome against the step's Pass/Failure text **verbatim**. Record pass or
"not performed" with the shipped reason — never an invented criterion. One commit at
the end of each row (or one per step where fixes intervened):

- **62** first dictation, Notes + TextEdit byte-compare (`pbpaste` discipline).
- **63** Secure Input over a Safari/Chrome password field: no session starts; the
  `.secureInput` held copy reachable via the ⏎-retry route of step 27.
- **64** Esc during RECORDING and TRANSCRIBING (+ the OPENING mic-flash variant as
  expected behavior).
- **65** shortest session (~80 ms): IDLE, no text, no failsafe, no failure notice.
- **66** model-unavailable: move the model dir aside, launch, press — `.modelUnavailable`
  notice, mic never lights; restore and relaunch.
- **67** toggle triggers + backstops (`.toggledOff`, audio-config change, 120 s ceiling).
- **68** 20 cycles mixed lengths; `~/Library/Application Support/Vocca/recovery/`

## Testing strategy

- Existing suite is the regression bar (floor 1731). New tests only for fixed defects.
- The byte compare is against the engine's transcript, not intention — an ASR mishearing
  is step 19's matter (aspect `real-engine-runs`), not an injection failure.

## Environment & privacy

- Grants + model + mic only; no env vars beyond the already-set ones; zero network.
- The recovery journal is the invariant's on-disk half — step 68's inspection checks it.

## Edge cases

- A row the shipped app cannot yet produce: record "not performed" with the shipped
  reason (step 47 convention) — do not invent a passing criterion.
- Secure Input state cannot be entered by a test; step 63 is its only real confirmation.
- Esc-during-OPENING: mic flash is expected, not a failure (`SessionMachine.swift:240`).
