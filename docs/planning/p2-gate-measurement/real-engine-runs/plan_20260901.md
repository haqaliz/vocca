# Implementation Plan: real-engine-runs

**Date:** 2026-09-01 · **Feature:** p2-gate-measurement · **Spec:** `docs/planning/p2-gate-measurement/real-engine-runs/spec.md`

## Context for the executing agent

Swift 6 package; suite via `Scripts/test-with-floor.sh` (floor 1731); filters via
`swift test --filter <Class>`. Every run below is env-gated and executed by nothing in
CI — visible `XCTSkip` is the CI state and the tell-tale that the gate is unset. The
house discipline is "records, never gates": a real run prints numbers, never throws on
a blown tolerance; a FAIL equivalence verdict is a successful unit outcome
(`tolerances_20260831.md:22-23`). Re-baselines follow measure → margin → founder-signed
row → land-in-exactly-one-file; the single-source scans stay green.

## Goal

latency/warm-start/re-warm rows, the equivalence verdict, and the Parakeet streaming
WER row — each recorded against its provisional tolerance, re-baselined founder-signed.

## Testing strategy

- No new tests except for fixed defects; the floor is the bar.
- Recorded numbers are rows in the smoke checklist + tolerance files — never gate
  assertions (the "guard-the-guard" tests already prove the gates can fail).

## Environment & privacy

- Env per-run only: `VOCCA_MODEL_DIR`, `VOCCA_LATENCY_BENCH=1`. Nothing exported
  globally. Zero network; models local.

## Edge cases

- Suppression state "not suppressed" expected (2000/2000 samples on the authoring
  machine) — record what the run prints; a suppressed row is a fact, not a failure.
- Sub-13 s utterances produce no Parakeet partials (SDK default windows) — the key-up
  row says so with numbers where the run produces them; never claim a win unmeasured.
- Whisper's short-audio rows record pad-vs-refuse for the first time — "reasoning about
  the C library" ends here.

## Agent execution notes

  record the reason (SMOKE rule 1) — it is not a failure.

  don't relax it.
