# Implementation Plan: cleanup-eval-f2

**Date:** 2026-09-01 · **Feature:** p2-gate-measurement · **Spec:** `docs/planning/p2-gate-measurement/cleanup-eval-f2/spec.md`

## Context for the executing agent

Swift 6 package; suite via `Scripts/test-with-floor.sh` (floor 1731). The cleanup eval
harness (`CleanupEvalHarnessTests`, gated by `VOCCA_CLEANUP_EVAL`) scores a checked-in
stand-in corpus in CI; the P1 gate's number comes from the founder's real F2 corpus
(`SMOKE_CHECKLIST.md:1365-1399`, step 73). F2 is ownerless beyond that step
(`STATUS.md:362-364`). The corpus lives at `~/Vocca/f2-pairs/` — **never in the repo,
never uploaded**.

## Goal

A complete F2 corpus (≥40 utterances, ≥5 per class), a ballot produced and answered
blind, the verdict recorded against `ProvisionalCleanupTargets.preferenceMinimum`
(0.80), and the founder-signed re-baseline chain followed.

## Prerequisites

- `provision-and-verify` done (the eval transcribes `.wav` pairs with the real Parakeet
  engine — requires `VOCCA_MODEL_DIR`).
- The founder's recording session is the long pole (~1 focused session) and overlaps
  aspects 2–4.

## Phase 1 — Corpus recording (founder)

- Founder records ≥40 utterances, ≥5 per class (the six `Tests/CleanupPairs/` classes),
  saved per step 73's convention: `<name>.wav / <name>.raw.txt / <name>.clean.txt /
  <name>.class.txt` + `dictionary.json` under `~/Vocca/f2-pairs/`. Discovery requires a
  `<name>.raw.txt` per pair (the loader keys on that suffix only — a wav-only corpus
  loads 0 pairs); the raw side loads from `.raw.txt` first and is replaced by the engine
  transcript for `.wav` pairs when `VOCCA_MODEL_DIR` is set.
- The agent verifies the layout (counts per class, file triplets complete) and records
  provenance (machine, date, corpus path) in the smoke step's note.
- **No repo file is created in this phase.**

## Phase 2 — Ballot

- **Command:**
  - `VOCCA_CLEANUP_EVAL=1 VOCCA_MODEL_DIR=<dir> Scripts/test-with-floor.sh --filter CleanupEvalHarnessTests`
- **Expected first run:** missing `answers.tsv` → skip path; the run prints the ballot
  (seeded presentation order; blindness is mechanical).
- Founder answers `left|right|tie|noPreference` per pair into `answers.tsv`
  (`tie`/`noPreference` excluded from the denominator by design).

## Phase 3 — Verdict + re-baseline

- **Command:** same as Phase 2 (second run).
- **Expected:** per-pair verdicts, `preference=NN.N%`, per-class tallies, the
  `RECORDED, not gated` line vs 0.80.
- **Re-baseline:** if the number clears 0.80 with the founder's margin, record it (no
  code change). If it misses: measure → margin (founder decision) → founder-signed row
  in `tolerances_20260815.md` → land in exactly one file
  (`ProvisionalCleanupTargets.swift:30,33`) — never silently relaxed.
- **Commit message (if code changed):** `re-baseline the cleanup preference target from the F2 run (SMOKE 73)`
  — else: `record the F2 cleanup eval verdict (p2-gate-measurement aspect 5)`

## Phase 4 — Defect fixes

- A harness failure is a defect (RED→GREEN, floor holds, M5 escalation). A low
  preference number is not.

## Testing strategy

- The `CleanupPairwiseScorer` and the 0.80 pin are already tested; the F2 run adds no
  unit tests unless a defect appears. Floor 1731 is the bar.

## Environment & privacy

- `VOCCA_CLEANUP_EVAL=1` + `VOCCA_MODEL_DIR` per run.
- **Privacy:** the corpus is founder voice data on the founder's disk; never committed,
  never copied into worktrees, never transmitted. The eval runs fully local.

## Edge cases

- Missing corpus dir: the harness fails loud (never skips) — check the path before
  running.
- Missing `answers.tsv`: skip path is expected on first run — the ballot must be
  answered before the second run.
- Wav sidecar without `VOCCA_MODEL_DIR`: hard fail — set both vars.
- The TTS stand-in corpus is "unnaturally clean" — the F2 number is the first real one
  and may differ materially from the 23/24 stand-in result; that difference is the
  point, recorded not gated.

## Agent execution notes

- Checkpoint: before Phase 2, confirm the corpus layout with the founder (counts +
  provenance).
- The founder answers the ballot; the agent must not peek at labels while presenting —
  blindness is the metric's foundation (`CleanupPairwiseScorer`).
