Spec: `docs/planning/action-safety-spine/audit-log/spec.md`
PRD: `docs/planning/action-safety-spine/prd.md` (§5 is the entry's data model)
Predecessors: `action-seam` (2500), `confirmation-gate` (2517, `b6b54cc`)

**This is the first aspect to create a module, touch `Package.swift`, and touch the
filesystem.** Three conventions bite here that did not bite before.

---

## 0. The three conventions that bite

**(a) The module directory and the `Package.swift` target must land in the SAME commit.**
`VoccaContextTargetTests.testTheModuleDirectoryExistsWithSwiftFiles` and the manifest-text pin
fail together otherwise. This is the C12 precedent (`9e076e3`) and it is not negotiable.

**(b) Target dependencies are asserted by EQUALITY, not containment.**
`VoccaContextTargetTests.swift:73` does `XCTAssertEqual(target.dependencies, ["VoccaCore"])`
against `swift package dump-package`. One extra declared dependency fails before any `import`
exists. `VoccaActions` must declare **exactly** `["VoccaCore"]`.

**(c) Nothing in this repository appends to a file.** Append-only is **by directory**:
one file per event, zero-padded 8-digit ordinal, `.tmp` mid-commit, `replaceItemAt` rename-over.
Follow `Sources/VoccaInject/Journal/FileSystemJournalStore.swift` exactly — do not invent a
different scheme, and do not reach for `FileHandle.seekToEnd`.

## 1. Phases

### Phase 1 — RED: the entry and the store contract

**Files:** `Tests/HarnessTests/ActionAuditStoreTests.swift`

RED is a compile failure against types that do not exist (the established precedent).

Tests, from the spec's acceptance list:
1. **Reconstruction** — a sequence of executed actions driven through `RecordingActionProvider`
   is recoverable **in order**, with decision and outcome intact. Non-empty domain (PRD C1).
2. Ordinals are monotonic and **survive a reload** — the counter is rebuilt from entries on
   disk, not held only in memory.
3. A `.tmp` file mid-commit is neither readable nor listable as an entry.
4. Tolerant decode: a corrupt entry is skipped, the injected `onInvalidElement` callback fires,
   the store still loads. **It never throws.**
5. The cap evicts oldest-first by ordinal; clearing empties the directory.
6. **The byte-level pin** — see Phase 3, written here as a failing test.
7. `summary` is bounded at 1 KB UTF-8 **in exactly one place**, asserted at the boundary and one
   byte over it.
8. A **refused** action and a **failed** action are distinguishable in the persisted entry
   (carried from `confirmation-gate` — R8 turns on this distinction).

**Commit.** `audit-log: pin the ActionAuditEntry and store contract — RED reconstruction, ordinal, tolerant-decode and byte-pin tests against a module that does not exist`

### Phase 2 — GREEN: the module and the store

**Files (module directory + manifest in ONE commit, per §0a):**

| File | Purpose |
|---|---|
| `Package.swift` | product line + target stanza, `dependencies: ["VoccaCore"]` exactly, `swiftSettings: [.swiftLanguageMode(.v6)]`, with the reviewed rationale comment (the `VoccaContext:126-135` shape) |
| `Sources/VoccaActions/Audit/ActionAuditEntry.swift` | The entry (PRD §5) |
| `Sources/VoccaActions/Audit/ActionAuditFileSystem.swift` | The `*FileSystem` protocol seam + the one `FileManager` implementation |
| `Sources/VoccaActions/Audit/FileSystemActionAuditStore.swift` | The deciding actor |
| `Tests/HarnessTests/ModuleBoundaryTests.swift` | add `"VoccaActions"` to `adapterModules` **with its required doc-comment paragraph** naming the seam it implements and the lints confining it |
| `Tests/HarnessTests/VoccaActionsTargetTests.swift` | the manifest/dependency-equality pins (the `VoccaContextTargetTests` shape) |

**The entry's fields (PRD §5 — do not add any):** `id`, `instantSeconds`,
`instantAttoseconds`, `providerID`, `toolID`, `blastRadius`, `decision`, `outcome`, `summary`.

- The instant is **monotonic `Duration` components, never a wall clock** — `JournalEntry`'s
  stated reason: a wall-clock reading lies across an NTP step or a DST change.
- `blastRadius` recorded is the **effective** radius (after escalation), not the provider's
  claim — `confirmation-gate` already established that a carried summary reports the effective
  value.
- The store follows the three-part idiom verbatim: protocol seam (no decisions) → one
  `FileManager` implementation → actor that decides. `persist()` is create-dir → encode
  `.sortedKeys` → temp-write → `replaceItemAt`.
- **Use `replaceItemAt`, not `moveItem`** — `PersistentConsentStore:61-65` records that
  `moveItem` refuses an existing destination and made every save after the first fail.

**Commit.** `audit-log: the VoccaActions module and the append-only audit store (GREEN)`

### Phase 3 — the byte-level pin and the permit rows

**Files:** `Tests/HarnessTests/ActionAuditStoreTests.swift` (pin),
`Tests/HarnessTests/InjectionSeamBoundaryTests.swift` (permit rows at `:1186` and `:1201`)

**The byte pin** — the `PersistentConsentStoreTests.swift:469` pattern, with one deliberate
difference:

- Exact **key-set equality** on the encoded entry, so any field added later fails on the day it
  is added.
- **No** `HH:MM`, ISO-8601 (`[0-9]{4}-[0-9]{2}-[0-9]{2}T`), Zulu (`[0-9]Z`), or epoch-shaped
  (`[0-9]{10}`) values.
- **`summary` is permitted to carry text** — this is the deliberate difference from the consent
  and usage pins, and the test must say why in a comment: a summary with no content would defeat
  the log's purpose. Raw tool arguments are still absent (PRD §5).
- **Vacuity guards:** assert the entry under test is genuinely populated, and that the fields
  being checked are non-empty, before asserting what is absent.

⚠️ **Watch the epoch-shaped regex.** `instantSeconds` is a monotonic uptime, not an epoch, but a
long-running machine could produce a 10-digit value and trip `[0-9]{10}`. If that fires,
**do not delete the check** — scope it (e.g. assert no 10-digit value appears outside the two
instant fields) and record why in a comment.

**Permit rows:** add `VoccaActions`' `FileManager` surface to both the seam table (`:1186`) and
the module-root map (`:1201`).

**Commit.** `audit-log: the entry's byte-level pin and the VoccaActions FileManager permit rows`

## 2. Edge cases

- **Directory name:** `actions/` under Application Support, beside `recovery/`. Pin it.
- **Eviction on write, not on load** — the cap is a fact about the directory, not about a reader.
- **A store whose directory cannot be created** must fail loudly to its caller, not silently
  drop a record. An audit log that silently loses entries is worse than none.
- Path injection: pure `static defaultDirectory(applicationSupport:home:)` on the store, with the
  URL passed in — the C12 pattern (`PersistentUsageStore:200-209`). **Do not resolve paths inside
  the store.**
