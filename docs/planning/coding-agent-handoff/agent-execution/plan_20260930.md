configurations, with zero new transport-family spellings.

## Steps

1. **RED** — write the suite:
   - real executor + `/bin/echo` with agent-shaped argv and a configured env entry →
     completion, bounded capture, exit mapping (the `ShellExecutionResult` shape).
   - injected clock: a 120 s configuration does not die at 30 s (advance the clock in
     steps; the counted wait honors the configured timeout).

     `kill(pid, 0) == -1 && errno == ESRCH` via the executor's `lastProcessIdentifier`.
   - a child that prints > 4 KB: truncated, reported, never fatal.
   - env pin: a test child that prints `env` receives exactly the configured entries.
