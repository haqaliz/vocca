## 2. Phases

### Phase 1 — RED: the digest check that can fail

**Files:** `Tests/HarnessTests/ManifestDigestVerificationTests.swift` (new).

An env-gated test that, given a directory of real downloaded artifacts, verifies every shipped
manifest's declared SHA-256 **and** byte count against the bytes on disk.

- Gate on `VOCCA_MODEL_DIR` with `XCTSkip` — **skips visibly**, never a silent pass. A silent pass
  is precisely what let the Parakeet placeholder survive.
- **The gate must be able to fail:** a planted digest mismatch fails loudly. Prove it in a test that
  runs unconditionally (synthesise files in a temp dir), so CI covers the *mechanism* even though
  it cannot cover the *artifacts*.
- Report every mismatching file, not just the first — a manifest with two wrong entries should say
  so in one run.

**Commit:** `Verify shipped manifest digests against real bytes, behind an env gate`
