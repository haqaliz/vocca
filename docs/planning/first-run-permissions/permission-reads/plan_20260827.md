status read + request, the settings-pane opener, and the relaunch. Translation only — no

their first execution.

## Implementation steps

1. **Core seam**: `OnboardingPermissionReads` — `accessibility: OnboardingAccessibility`,
   `microphone: OnboardingMicrophone`; the reducer's entry/refresh input. Tests first (RED):
   the mapping from (trusted: Bool, tapArmed: Bool) → the three accessibility states is
   pure and lives here or in the reducer — decide in the test: `grantedNotArmed` = trusted
   && !armed; `armed` = trusted && armed; `notGranted` = !trusted. (The `tapArmed` fact
   comes from `TapHealth != .permissionMissing` — the root feeds it in; A2 only defines the
   mapping, A5 wires the real reads.)
2. **AX status read** in `AXSource.swift`: a single function returning `Bool`
   (translation; no policy). No CI execution.
3. **Microphone auth** in `MicrophoneAuthorization.swift`: `authorizationStatus()`
   (notDetermined/denied/granted → `OnboardingMicrophone` mapping is the Core seam's job —
   the adapter returns the raw enum) + `requestAccess() async -> Bool` (translation).
   Amend `ModuleBoundaryTests` expected-importers to admit the file (reviewed, with a
   comment naming the PRD decision).
4. **Pane opener**: move the two URL constants out of `AppBootstrap.swift` into
   `SystemSettingsPane` (accessibility, microphone — private in the root today, now public
   seam functions); tests pin both strings byte-for-byte (they are user-visible navigation
   targets and the smoke rows check them).
5. **Relaunch**: `AppRelaunch.relaunch()` — terminate then launch the same bundle; no
   argument replay; must be safe to call once (guard against double-invocation in the
   window glue, not here). No CI execution; smoke row in A6.
6. Raise floor; run `Scripts/test-with-floor.sh`.
