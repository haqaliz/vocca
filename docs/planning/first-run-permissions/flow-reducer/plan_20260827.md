## Vocabulary (stdlib-only — no Foundation, no system imports)

```swift
public enum OnboardingStep: Sendable, Equatable { case welcome, permissions, model, tryIt, done }

// M5c — three states, never a ✓ that hides a dead tap
public enum OnboardingAccessibility: Sendable, Equatable {
    case notGranted          // AXIsProcessTrusted() == false
    case grantedNotArmed     // grant present, tap dead (mask cleared at launch)
    case armed               // tap health reports non-permissionMissing
}

public enum OnboardingMicrophone: Sendable, Equatable {
    case notDetermined, denied, granted
}

// Wraps the MODEL step; mirrors DownloadState's terminal shapes (DownloadState.skipped precedent)
public enum OnboardingModel: Sendable, Equatable {
    case absent, downloading(Double), committed, failed, skipped
}

public struct OnboardingState: Sendable, Equatable {
    public var step: OnboardingStep
    public var accessibility: OnboardingAccessibility
    public var microphone: OnboardingMicrophone
    public var model: OnboardingModel
    public var tryItUnavailableReason: TryItUnavailable?   // M7: nil = ready
    public var restartOffered: Bool                        // M3: only on grantedNotArmed
    public var deliveredTranscript: String?                // TRY IT success payload
    public var completed: Bool                             // only TRY IT success sets it (M4)
}
public enum TryItUnavailable: Sendable, Equatable { case modelUnavailable }  // M7, closed
```

Closed action set (house pattern — exhaustive switch, no time-based transitions):

```swift
public enum OnboardingAction: Sendable, Equatable {
    case begin
    case accessibilityStatusChanged(OnboardingAccessibility)
    case accessibilityGrantSignal                  // com.apple.accessibility.api arrived (M5)
    case microphoneStatusChanged(OnboardingMicrophone)
    case microphoneRequestResulted(Bool)           // requestAccess callback (M5b)
    case modelStatusChanged(OnboardingModel)
    case modelDownloadCancelled                    // Skip → .skipped, terminal
    case tryItPressed
    case tryItSucceeded(String)                    // real transcript delivered (G5)
    case tryItFailed                               // surfaces failure, not a dead end
    case restartRequested                          // M3 button, only on grantedNotArmed
    case restartDismissed
    case windowClosed                              // S3 — flow resumes at first incomplete step
}
```

Reducer rules (every one of these gets a test):

1. `begin`/`windowClosed` → `initialState(accessibility:microphone:model:)` — a pure entry
   function that resumes at the first incomplete step: accessibility not armed → permissions;
   else model absent/skipped → model; else not completed → tryIt; completed → done.
2. `accessibilityStatusChanged(.grantedNotArmed)` sets `restartOffered = true`; `.armed` or
   `.notGranted` clear it. `restartOffered` is **only** reachable from `grantedNotArmed`.
3. `microphoneRequestResulted` maps the Bool to denied/granted.
4. `modelDownloadCancelled` → `.skipped`, terminal (stragglers rejected, the
   `DownloadStateReducer` rule).
5. `tryItPressed`: if `model` is `.absent`/`.failed`/`.skipped` → `tryItUnavailableReason = .modelUnavailable` (M7, never a dead end — the step still offers download-now/continue); if `.committed`/`.downloading(.completed)` → ready.
6. `tryItSucceeded` is the **only** transition that sets `completed = true` (M4) and moves to `.done`. `tryItFailed` keeps the step, shows failure, sets `tryItUnavailableReason = nil` equivalent.
7. `accessibilityGrantSignal` re-derives armed status from the injected read (M5 live ✓/✗);
   it must not fabricate `.armed` from nothing — it needs the status input, else no-op.
8. No time-based transitions exist anywhere (the never-auto-dismiss rule).

## Testing strategy

- `OnboardingReducerTests`: table-driven over the closed action set — every rule above,
  plus: restart offered only on grantedNotArmed; completed only via tryItSucceeded; resume
  matrix (close on each of the five steps × each status combo); straggler rejection after
  terminal states; grant-signal no-op without a fresh status input.
- `OnboardingCopyTests`: byte-for-byte pinning against `PRODUCT_SPEC.md` quoted lines;
  the accessibility three-state and model-unavailable copy pinned to their own documented
  sources.
- Validation: `Scripts/test-with-floor.sh` (compiles the suite, enforces the raised floor).
- The zero-network probe is untouched by this aspect (no network-adjacent code; run
  `swift test --filter ZeroNetworkTests` to confirm it still passes).

## Edge cases

- `accessibilityStatusChanged(.grantedNotArmed)` arriving while on a later step → the
  flow does not yank the user backwards; the state updates, restart is offered at the
  current step's permission surface. Pin the chosen behavior in a test.
- Double `tryItSucceeded` → second is a no-op (state already `.done`/completed).
- `modelStatusChanged(.downloading(Double))` monotonicity is the downloader's job, not the
  reducer's; the reducer accepts any fraction, the store filters (documented, not tested here).
