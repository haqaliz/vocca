## Rows to add (each with pass/fail criteria, following the checklist's format)

1. **Fresh-install onboarding run**: on a clean account (`tccutil reset Accessibility
   dev.vocca.Vocca`, `tccutil reset Microphone dev.vocca.Vocca`), launch → the welcome
   window appears (no terminal, no config) → WELCOME → PERMISSIONS: the Accessibility row
   shows ✗ with the §6 reason copy and the pane button opens the exact
   `Privacy_Accessibility` pane; the Microphone row prompts via `requestAccess` with the
   `NSMicrophoneUsageDescription` text (not generic) — the two prompts fire one at a time,
   never a wall.
2. **Grant → restart → dictate**: grant Accessibility, return to the window → the row
   shows *granted, restart to arm* (the M5c three-state copy — never a bare ✓ with a dead
   tap) with [Restart Vocca] → pressing it quits and relaunches Vocca → the hotkey works
   from another app's front window within 60 s of first launch (the `ROADMAP.md:80` target).
3. **Mic denial is not a dead end**: deny the microphone on a second fresh account → the
   window names the exact toggle, the flow continues; dictation later presents the honest
   refusal, never a silent no-op.
4. **Skip-model → TRY IT unavailable**: "Skip for now" → TRY IT shows the model-unavailable
   state with [Download now] → DONE still reachable; dictation before the model arrives
   refuses with the `.modelUnavailable` notice, the system mic indicator never lights
   (the step 66 cross-reference).
5. **Menu-bar reopen + completion**: complete TRY IT (words land in the window's field) →
   DONE; the menu bar offers "Welcome…" and reopens the window; relaunch does **not**
   re-show the window (flag set). Close mid-flow on an incomplete account → next launch
   resumes at the first incomplete step.
6. **Timing**: cold install (model download included, or skipped) reaches DONE in under
   60 s on the founder's machine; record the number.
