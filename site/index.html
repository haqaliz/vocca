What it does

Dictation first. The extras stay opt-in.

Dictate into any app

Press ⌥Space, talk, press again, and the words land in whatever app has focus. Prefer holding the key instead? Hold-to-talk ships too, and the shortcut is rebindable in Settings → General.

Two local ASR engines

Parakeet via FluidAudio is the default; whisper.cpp large-v3-turbo is the second, selectable engine. Whisper scored WER 0.0000 on all six fixtures on both tiers (turbo and q5_0) — accuracy only. Whisper's latency is not measured: no Core ML encoder ships, so it runs on Metal/CPU, which affects speed, not accuracy.

Talk back, optionally

A local Kokoro voice loop with real turn-taking and barge-in you can interrupt. In the CONVERSING bubble, the Copy control writes the full reply to the pasteboard on the first click, without the widget taking focus. Voice-driven actions are on the roadmap, not claimed here.

The differentiator

Your audio never has to leave your Mac.

The default configuration makes zero network calls and spawns no child process — asserted by a CI test that is a permanent release blocker. The one download is the speech model, once, at first launch.

  • Cleanup is local by default. Deterministic rules run entirely on your Mac: no model, no network, no wait.
  • Anything that leaves is opt-in — and badged. A local Ollama model or your own BYOK endpoint is a choice you make in the Cleanup tab, and the moment a choice would send text off the machine it is badged “Text leaves your Mac.”
  • You confirm before text leaves. Turning either on asks for confirmation naming exactly what gets sent, before any text may leave the Mac.

Where that claim stops, stated plainly: Vocca's network check watches its own process. It cannot see inside a program Vocca starts on your behalf, so enabling an MCP server is trust you extend to that server's author. The default install configures none.

Status: honest

The loop has delivered. The product is not yet proven.

The P0 dictation loop is wired and tested on a real Mac. That is a narrower claim than “finished”, and here is exactly where it stops.

Measured

  • Press ⌥Space, talk, press again — the words are transcribed locally and typed into the focused app. First real dictations happened on the founder's Mac (docs/SMOKE_CHECKLIST.md steps 62–68).
  • Whisper accuracy: WER 0.0000 on all six fixtures on both tiers (turbo and q5_0), with manifest digests verified against the provisioned bytes.
  • The default configuration's zero-network invariant is asserted in CI and is a permanent release blocker.
  • v0.2.0 is the first installable release: signed, not notarized, so the quarantine command is required.

Not yet measured

  • Whisper latency — no Core ML encoder is in the shipped manifest, so it runs on Metal/CPU.
  • The injection matrix — one recorded row so far.
  • Latency-gate p50/p95 — measured, but on a 60-second fixture rather than the gate's 10-second utterance, so they are not the gate's numbers.
  • LLM cleanup rewrite quality.
  • Notarization — the script has never run end to end; there is no Developer ID yet.

Install

Apple Silicon, macOS 15 or later.

Homebrew is the short path. Run the xattr line before opening Vocca the first time — opening a quarantined copy makes macOS delete the app.

Terminal 
brew install --cask haqaliz/vocca/vocca
xattr -dr com.apple.quarantine /Applications/Vocca.app   # before opening it
open /Applications/Vocca.app

Prefer a download? Grab Vocca-vX.Y.Z.dmg from the latest release, drag Vocca to Applications, then run the same xattr line and open command.

Signed with an Apple Development certificate, not notarized yet. That is why the quarantine line exists; notarization is the next distribution milestone.
